# 決めたこと

ユーザーの確認を待たずに決めたことを、決めたことごとに日付と短い題の小見出しを立て、何を決めたかと、なぜそうしたかを段落で書く。変えてよい。

### 2026-10-25 室内は実寸の 1.5 倍

入れる建物の室内は実寸の 1.5 倍で描く（1 m = 1.5 タイル）。実寸だと通路が歩くマス 1 つに満たず、人が通れないためである。ただし家具の配置と検証は実寸（m）で行う。

### 2026-10-25 平屋の寝台はカーテンで仕切る

1 階建ての家は、寝台を奥の隅に置いてカーテンで仕切る。2 階がない家の寝間をはっきりさせるためである。また、入れる建物で平屋だったもの（道具屋・買取所・木工所・共同の作業場）は、屋根裏を足して 2 階建てにした。そのため外観も 2 階になる。

### 2026-10-25 細い家の炉は壁際

部屋が細い家（4.2 m 未満）は、炉を壁際にし、食卓を部屋の中に出す。炉を真ん中に置くと食卓が入らないためである。「炉の周りに集める」という決まりは、食卓が炉から 1.8 m 以内にあることで守る。

### 2026-10-25 食卓と縫い物の台を足した

道具屋・結晶屋・買取所・倉庫に食卓を足し、仕立て屋に縫い物の台を足した。住む人の食事と仕事の机がなかったためである。倉庫の棚と木箱は、預かり荷の棚として 3 つずつにした。

### 2026-10-25 酒場と宿の炉の位置

酒場は壁の暖炉にし、宿の炉は食堂の側壁に置く。食堂に卓を並べる場所を空けるためである。

### 2026-10-25 画面の間の字

画面の間の字は明朝体の Shippori Mincho（`@fontsource/shippori-mincho`）にする。ゲームの UI の字と分けて、落ち着いて見せるためである。

### 2026-10-25 カメラの回転の向き

カメラの回転は全入力とも逆向きにし、右ドラッグ = Shift+Q（前方が右へ回る、地面をつかんで引く向き）にそろえた。「回転が逆」との指摘を受け、キーとドラッグが互いに逆向きだったのもあわせて直すためである。`world/scene/turn.test.ts` で固定した。

### 2026-10-25 灰はシェーダーで積もらせる

灰は材質のシェーダーで面の向きから積もらせ、物ごとに灰の板を足さない。こうすると町と外の全部の物に一度に効き、物を増やしても描画が増えないためである。地面は描き込みのときに灰を混ぜる。

### 2026-10-25 昼の通りを夜より静かに

昼の通りを夜より静かにするため、洗濯女 3 人を昼過ぎ〜夕方（14:30–17:00、まだ日がある）に、ヴィルヘルムのベンチを 14:30 からに、マルタの店じまいを 10:30 にずらした。あわせて、夜に外へ出る用事（灰掃き・樽の入れ替え・夜更けの見回り・荷車待ち）を 4 人に足した。その結果、オットーとクララの夫婦は夕方に顔を合わせるようになったので、「すれ違いの夫婦」から外した。

### 2026-10-25 道の真ん中に物を置かない

道の真ん中（道の縁から 0.35 タイルより内側）には物を置かない。ただし広場（井戸・ベンチ）と建物の中は除く。これを「通路を塞ぐ物をなくす」の基準とする。家の飾りは道から離して置く。

### 2026-10-25 渡り口は道の端から決める

マップの渡り口は、描かれた道が端に出る位置から決める（道の端点を升目の境で揃えた）。渡り口を道の上に置くためである。これに合わせて、草原の南に砂丘への道、樹海の入り口の南に浜への道、樹海の奥の東にクイニョンの門前への道を引き直した。

### 2026-10-25 TownRoomWs は手で消さない（試して戻した）

void.lock.json の `resolved` から TownRoomWs の束縛だけを消すと、移行の履歴にそのクラスが残っているため、開発サーバーが「Class extends value undefined」で起動しなくなった。束縛は戻した。クラスの削除は、削除の移行と一緒に次のデプロイで `void deploy --atomic` に任せる。

### 2026-10-25 宿の大鍋と家具

宿の大鍋は炉の上に吊るす物として床を取らないことにし、宿の家具は長卓 2 つから長卓・卓・椅子 4 つに変えた。宿の食堂（6.5 × 4.5 m の 1 階）に、売り台・長卓 2 つ・大鍋が入りきらないためである。

### 2026-10-25 地図の昼夜スクショは実際の Chrome で

地図の昼夜スクショは、実際の Chrome（画面あり）で撮る。画面なしの Chromium では WebGL が白紙になり、同じページで次の地図へ移ると読み込みが止まるためである。そこで 1 枚ごとに新しいページを開き、ログとチャットの窓を閉じて撮る。

### 2026-10-25 輪郭の描き方

輪郭は、スプライトの隣の texel を見て、空いている側だけを白く塗る（1 texel 幅）。自分には常時付け、屋根越しの影絵のときは奥行きを無視して上に描く。箱でできた魔物と家畜は、法線方向に押し出した裏面の殻で白く縁取る。

### 2026-10-25 カメラのデッドゾーン

カメラのデッドゾーンは画面の幅・高さの 40% とする。外に出た分だけ注視点を動かし、回転した直後は中央に戻す。マップ移動直後は、もともと中央に置いている。

### 2026-10-25 住民を 94 人に

住民は 37 人から 94 人にした（「100 人ほど」）。空き家 8 軒のうち 7 軒に世帯を入れ（灯り直し・代書屋・ろうそく屋・陶工・籠編み・鋳掛け屋・地図描き）、南門の h-g3 だけを貸家のまま残した。新しく家を 5 軒建てた。職人通りの南に石工と煙突掃除、南門の西に猟師と先生、東に隠居の老夫婦が住む。

### 2026-10-25 増えた人の多くは夜型

増えた人の多くは夜型にした。子どもも町に合わせて夜に起き、21 時から寄り合い所の字の教室に通う（先生のクリスティアン）。昼型は農家・猟師・昼番の衛兵だけである。

### 2026-10-25 宿の客室と店の手伝い

宿の客室は 5 床から 3 床にした。娘のニーナと料理番のゼップが住み込みになったためである。店の手伝い（ニーナ・リリー・エーファ・ロッテ・ルイーゼ）は、二人目の店番としてカウンターに立つ。

### 2026-10-25 関係の種類を足した

関係の種類に「祖母と孫」「兄弟」を足した。

### 2026-10-25 住民の立ち位置に小物を置かない

住民の立ち位置（仕事の場所と一日の予定のマス）には、軒先の小物を置かない（`world/scene/dressing.ts` の `clear`）。

### 2026-10-25 革の入手経路は猟師のファルク

猟師のファルクを革の入手経路にした（皮はルドルフへ、脂はろうそく屋へ）。これが backlog の「革の入手経路」の答えの半分になる。

### 2026-10-25 道はまっすぐに引かない

道はまっすぐに引かない。中心線を低い周波数のノイズで最大 0.45 タイルずらし、幅を ±25% ほど揺らし、縁を細かく崩す。石畳は真ん中にも石の抜けと草を入れ、土の道は轍のあいだに草を入れる。

### 2026-10-25 新しい住民の台詞の書き手

新しい住民の台詞（各 45 行ほど）は、6 人の書き手に分けて書いた（書いたときは lines/e〜j.ts。今は地区ごとの `world/town/lines/` の `square.ts`・`market.ts`・`craft.ts`・`gate.ts` にまとめてある）。


### 2026-10-25 実装を責務ごとに分ける

大きな実装は、行数だけで切らず、会話・通信・描画の各部などの責務で分ける。Game は公開 API とライフサイクルの組み立てを受け持ち、各操作は同じセッションを参照する。セッションの値を別の値へ写したり中継用の getter を重ねたりせず、接続の差し替えが全処理に伝わるようにする。住民と台詞は世帯単位、建物は地区単位にした。公開入口と並び順を保ち、既存の呼び出し側と焼き出し済みスプライトを変えずに分割するためである。生成されたモーションデータは分割の対象にしない。


### 2026-10-25 ブラウザのアイコンとローカル起動

ブラウザのアイコンには新しい図柄を増やさず、ゲーム内のコンパスを使う。`scripts/export-favicon.ts` が既存のピクセル定義から SVG を書き出す。開発サーバーと本番プレビューは、どちらも Portless が渡す接続先を使う。同じ設定から起動し、名前付きの URL が実際の待受先とずれないようにするためである。

### 2026-10-26 革鎧の材料の入手と加工

獣の皮は既存の猟師ファルクから革職人ルドルフへの供給とし、プレイヤーは革職人の店で買う。逃げる野うさぎのドロップには皮を加えない。加工前の皮となめし革を別の品にし、なめしと革鎧の製作を別の依頼にする。既存の革鎧の依頼 ID と完成品は変えず、受注済みの注文はそのまま受け取れるようにする。

### 2026-10-26 生活スキルの専門を変える

生活スキルを忘れる操作は、一度に一段階とし、途中の経験も失う。合計上限を守ったまま専門を育て直せるようにし、一括リセットの誤操作を避けるためである。費用は設けず、育て直す作業を負担とする。装備は勝手に外さず、条件を満たせなくなる場合は操作を断る。

### 2026-10-26 キャラクターの成長上限

キャラクターの上限を次の段階まで引き上げる。上限は `world/core/growth.ts` に置き、必要経験の式と獲得ポイントを維持する。既存キャラクターの振り分けと所持品はそのままにし、旧上限で捨てられた経験は補填しない。高レベル向けの狩場と敵の拡充は別に進める。

### 2026-10-26 森の生き物

開通済みの森を探索と狩りの場にするため、森の入口に既存の生き物、奥の森に落ち葉を食べる苔スライムを置く。人を見つけて襲う性質は追加せず、群れの移動範囲を歩ける小区画に収める。素材は既存のゼリーと薬草を使い、結晶を体内に持つという未決の設定は決めない。

## 2026-10-26 食事の集中は自然回復に加算する

温まり以外の料理の役割として、薬草茶と魚のスープに SP の自然回復を助ける集中を付ける。料理を選ぶ意味を持たせつつ、戦闘能力値やサーバーの定期処理を増やさないためである。既存の経過時間による回復計算で、食べた時刻と期限の間に来た回復だけに加算する。仕様は [[game-system#3.6 スタミナ・満腹・温まり]] にある。
