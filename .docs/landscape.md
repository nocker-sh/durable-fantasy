# 地形と景観

外のマップと町の外まわりを、歩いて楽しい景色にするための決まり。世界観は [[world]]、町の並びは [[town]]。持ち主の指示（2026-10-30）は「細かくて美しく。地形もあって、オブジェクトもあって、世界観とテーマのある地形に。歩いてて楽しいのがいい」。

## 何を美しいとするか

この世界の景色は、女神が去ったあとの、灰の降る静かな土地である。美しさは三つから作る。

1. **地形の形**：平らな草地を広げない。どのマップにも、高いところ・低いところ・その間の段差があり、上から眺めて地形の筋（尾根、谷、川筋、段丘の縁）が読める。段差の縁は岩が顔を出し、斜面は道が折り返して登る。
2. **ものの寄り方**：木も岩も花も、まんべんなく撒かない。木立、岩場、花の群れ、倒木の溜まりのように寄せて置き、その間を空ける。寄せたところと空いたところの差が、絵の密度になる。小さなもの（小石、花、落ち枝、苔）は、大きなものの根元と道の縁に多く置く。
3. **人と時間の跡**：どのマップにも、誰かが今も使っている場所（果樹園、炭焼き場、網小屋）と、人がいなくなった場所（止まった風車、崩れた砦、草に埋もれた機関、誰もいない祭壇）がある。どちらも怖くせず、寂しく静かに描く（[[world#場所]]）。

灰の空気（かすみ、舞う灰、霧、日なた）は全部のマップにかける。灰の薄い日の昼に、雲の切れ間から光が差す場所があると、そこが景色の見せ場になる。

## 歩いて楽しい、とは

- 道は地形に沿って曲がる。坂は道が受け持ち、段差の上へは必ず道か踏み分け道で上がれる。
- 一つのマップに見せ場を二つか三つ置く。道を歩いていると、次の見せ場の頭（風車の羽、塔の先、一本木）が先に見えて、寄り道したくなる位置に置く。
- 見せ場のまわりには小さな物語を置く（倒れた荷車と散らばった籠、祭壇に供えた花、焚き火の跡と腰掛けの石）。拾える物や採集の場所はこの近くに寄せる。
- 行き止まりにはご褒美を置く（眺めのいい岩の上、泉、きのこの群れ）。
- 道の真ん中には物を置かない。道から一歩外れた縁は、どこでも何かがあるくらいに細かくする。

## 地形の作り方

`world/maps/ground-layouts.ts` の `shape` で地形を作る。使う形は次のとおり。

- **段丘**：高さを段に切り、段の縁を急にする。縁は歩けず、絵では岩肌になる（`terrain.ts` が急な所を石で塗る）。段の間は道の坂でつなぐ（`terraced`）。
- **丘と尾根**：見せ場は丘の上に置く。尾根は道に沿わず、道を横切るところで鞍部（低いところ）にする。
- **池とくぼ地**：水面（`WATER_Y`）より低く掘ると池になる。池のまわりは葦と湿った土。
- **道は平らに**：`shape` は道の近くで弱まる（`world.ts`）。段の縁が道にかかるところは坂になる。

地形を変えたら `scripts/export-map.ts` で歩けるマスを書き出し直し、出現位置からすべてのつなぎ目へ歩けることを `maps.test.ts` で確かめる。

## 進め方

1. 南の草原を最初の見本として作る（地形の段丘、池、見せ場三つ、寄せた植生）。
2. 同じ道具で、樹海の入り口と奥、海沿い、砂丘、峠の順に作り直す。
3. 町（ファンティエットの 5 マップ）の外まわり（町の縁の斜面、川岸）を整える。
