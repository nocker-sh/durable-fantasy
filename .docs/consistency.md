# 生活の整合チェック

判定の基準は [[README#完全な生活]] だけ。町のあらゆる物と人について、次の問いに答えられなければ矛盾とみなす。

人については、どこで寝るか、何をどこで食べるか、仕事は何で道具と仕事場はどこにあるか、今の時刻にそこにいる理由は何かを問う。物については、誰の物か、何に使うか、どこから来たかを問う。売り物については、誰が作ったか、材料はどこから来たか、値段の理由は何か、いつ手に入るかを問う。

機械で判定できるものは自動テストにする。それ以外は、節目（マップ・建物・日課・経済を足すたび）に、このチェックリストで観点を変えて何度か横断レビューする。見つけた矛盾の種類は、下の「検査の記録」に短く残す。

## チェックリスト

以下、「自動テストで確かめる」はテストで判定するもの、「レビューで確かめる」は横断レビューで人が読んで確かめるもの、「自動テストにする予定」はまだテストがなく、条件がそろったらテストにするもの。

### 住まい

住民はみな、ちょうど一つの世帯に属する（自動テストで確かめる）。世帯には住まいが一つあり、寝床の数は人数と同じで、宿だけは客室の分だけ多い（自動テストで確かめる）。椅子の数は人数以上（自動テストで確かめる）。人の住む建物にはどれも暖炉があり、階数は部屋のある階の数とする（自動テストで確かめる）。間取りの家具は実寸で並べて、通路を取って入ることを確かめる（`world/town/fit.test.ts`）。間取りの家具が壁の内に重ならずに収まること、炉の近くに食卓があること、扉から炉・食卓・階段へ通れること、床が空きすぎも詰まりすぎもしないこと、入れる建物では一階が仕事場で寝間は二階にあること、どの部屋にも使い道と暮らしの跡があることも自動テストで確かめる（`world/town/floorplan.test.ts`）。

家が暮らしに比べて広すぎないことは自動テストで確かめる（`fit.test.ts`）。部屋の名前と住む人が合っているか（子ども部屋に子どもがいる、など）と、家の大きさと暮らし向き（慎ましい・ふつう・ゆとりがある）が合っているかは、レビューで確かめる。

### 食事

売っている食べ物には、作り手（畑・果樹園・漁・パン焼き・醸造）がいる。これはレビューで確かめる。世帯の生業の説明に出てくる人の名前は、町に実在する住民でなければならず、これは自動テストで確かめる。まだ作っていない場所は「外」として書き、旅のマップを作るときに置く。これはレビューで確かめる。食事の時刻と寝る時刻が重ならないことは、自動テストにする予定。

### 燃料・水・寒さ

暖炉と炉と窯の燃料（薪・炭）には出どころ（木こり）があり、井戸がどの地区にもある。この二つはレビューで確かめる。どの家の暖炉にも薪を届ける人と道があることは、自動テストにする予定。住民はみな首に何か巻いている（[[world#マフラーと糸]]）。これは自動テストで確かめる（`world/town/residents.test.ts`）。

### 仕事

店主は自分の店の地区に住んでいる（店の二階か奥か、同じ地区。昼番の手伝いは隣の地区から来てもよい）。店に入れる建物なら、店主は店の中のカウンターの奥に立ち、通りに残らない。誰も扉の前や青い輪の上に立たない。この三つは自動テストで確かめる。

仕事に要る設備（窯・炉・機織り機・調合台）が、その家か借りる先にあることは、レビューで確かめる。仕事道具のアイテムが家か仕事場にあることは、自動テストにする予定。路上販売の品が町から来ることは自動テストで確かめる。

### 時間

町の大半は夜に暮らし（夜の人出が昼より多い）、昼に働く少数派には理由を書く。誰もが6時間以上眠り、家の全員が眠っている間、その家の窓は暗い。日の光が要る仕事は昼にする。いつ来ても、どこかの店は開いている。酒場の席は、同じ時刻に飲む人より多い。同じ場所に同時に二人の売り手が立たない。ここまでは自動テストで確かめる（`world/town/routines.test.ts`）。台詞が時間帯と合っていること（時間帯の条件は起きている時間に限り、「おはよう」は起きたばかりの時間帯に言う）も自動テストで確かめる（`world/town/lines/lines.test.ts`）。

店番の交代で同じ人が二か所にいないことは、自動テストにする予定。

### 言葉と世界観（[[world]] は読むだけ）

「村」と言わない（町）。「神父」「神の」と言わない（女神と修道士）。「商会」「自治会」「修道会」のような大きな組織を出さない（町の寄り合い）。プレイヤーを「旅の人」と呼ばない。これは自動テストで確かめる（`houses.test.ts`、`lines.test.ts`）。

台詞が説明しすぎず断片で伝えていること、悪人がいないこと、寒さと長い夜に合っていること（冷えた飲み物を勧めない、など）、台詞で物を渡したり、起きていないことを前提にしたりしないことは、レビューで確かめる。

### 物の置き場

扉は両側とも歩ける場所にあり、出た先が扉に重ならない。道の真ん中に物がなく、扉・渡り口・採集場所・住民の立ち位置に道から届く。これは自動テストで確かめる。

どの世帯にも自分の軒先の物があり、どの種類の物も誰かが持っていることは自動テストで確かめる（`world/scene/things.test.ts`）。売り手のいない屋台に品を並べないこと（路上販売の時間まで布をかけておく）、軒先の物がその家の職業と暮らし向きに合っていることは、レビューで確かめる。

## 残っている矛盾（作るときに直す）

寄り合い所と共同の作業場には番をする人がいない。日課を入れるときに、当番の住民と戸締まりの時間を決める。

礼拝堂が建物の台帳にない（入れない）のに、修道士は「いつでも開いている」と言う。台帳に入れて屋内マップを作る。

羊飼いの小屋と牧場が遠い。小屋を牧場の脇へ移す。ゾフィーの菜園も家から遠い。貸し畑として扱うか、家の裏へ移す。

## 検査の記録

どの回も、見つけた矛盾はその場で直し、テストにできるものはテストにした。細かい直し方は git の履歴にある。

### 1周目（2026-10-21）: 世帯・家・店・地区・屋内マップ

自分で一回、別のエージェントが観点（食べ物の連鎖・燃料と水・仕事・住まい・台詞・物の置き場）を変えてもう一回見た。多かったのは、扉や通り道を塞ぐ物、扉の上に立つ住民、町にいない作り手や出どころ（粉屋・炭鉱・狩人・山羊・醸造する人）を前提にした品と台詞、世界観と食い違う言葉（村・神父・大きな組織・竜・冷えた飲み物・女神の加護）、売っていない品を並べた屋台、持ち主のない菜園や物干しだった。

### 2周目（2026-10-21）: 時刻・灯り・住民の一日・店の営業

売り手のいない時間の屋台、人ごとの一日と食い違う窓の灯り、眠る時間のない一日、光らない窓が見つかった。屋台は売り手のいる間だけ品を並べ、窓は世帯の誰かが起きている間だけ点け、全員に眠る時間を入れた。

### 3周目（2026-10-21）: 採集・作るもの・依頼・店の作り手・取引の掲示板

台詞や生業が前提にしている場所や時間が無い（川の釣り場、薬草を摘む時間、木を伐る時間、窯の番、粥を炊く時間）、作り手の名前が説明文に入っていてプレイヤーが作っても出る、レシピの作業場と説明の作り方が合わない、作り置きの量と説明が合わない、掲示板がどの町でも同じ一つである理由がない、が見つかった。仕様書の数字がコードより古かったのも、この回で見つけた（いまは数字を仕様書に写さない）。

### 4周目（2026-10-21）: 頼まれごと・親しさ・台詞の約束・店番

頼みの相手と中身が関係表・一日・口調と合わない、店で買って渡すと得をする報酬、親しさの上がる道のない住民、親しさの台詞で物を渡している、交代制の店でいない店番の親しさが上がる、逃げる野うさぎが毛皮を落とす、が見つかった。報酬は店の値段より安くし、どの住民にも親しさの上がる道を作り、上がるのはそのとき店に立つ店番だけにした。

### 5周目（2026-10-21）: ジョブの廃止・能力値・生活スキル Lv・通れる道

方針の変更（ジョブをなくし、能力値で武器と魔法が決まる、生活スキルは Lv 64 まで・v0.1 は 8、行けるのは町と草原と森だけ）に合わせて突き合わせた。閉じた道の向こうにしかない森、装備すると消える品質と耐久、条件の能力値が名前と合わない杖と首飾り、職業を前提にした決まり、もうない能力値、合計が元を超える経験値の均等分配が見つかった。

### 6周目（2026-10-21）: 家の広さ（家具を実寸で置いて確かめた）

38 棟すべての間取りの家具を実寸で並べ、通路を取って入るかを確かめた（`world/town/fit.ts`、`fit.test.ts`）。7 棟が入らず、1 棟が暮らしに比べて広すぎた。入らない家は広げるか屋根裏を足して寝間を 2 階へ移し、広すぎる小屋は平屋にした。広げた家に合わせて町の歩けるマスを書き出し直し、出入口・扉・住民の立ち位置にすべて歩いて行けることを確かめた。
