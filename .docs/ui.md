# ゲーム画面（UI）仕様

前提は [[README#完全な生活]]。

[[game-system]] のシステムを、プレイヤーが見て操作するための画面の決まりごと。システムにないものは画面に出さない。画面にあるものはシステムのどれかに対応する。寸法と色の値は `components/game/` と `components/hud/` にあり、ここには写さない。

## 1. 原則

**1. ゲームの中の情報だけを出す。** キャラクターが知り得ない情報は出さない。座標、サーバーの状態、内部 ID、FPS がそれにあたる。時間帯の切り替えのように、世界のルールの外から操作するものも出さない。

**2. 開発用の道具は別の層に置く。** デバッグパネル（§8）は `import.meta.env.DEV` のときだけ組み込まれ、本番のビルドには入らない。ゲームの UI とは見た目も部品も共有せず、デバッグパネルは開発用の shadcn をそのまま使う。

**3. 画面の中央は空けておく。** 常に表示するものは四隅と下端に寄せ、開閉するウィンドウは開いたときだけ出す。

**4. 1 つの情報は 1 か所に出す。** たとえば所持金は持ち物ウィンドウと店に出し、ステータスには出さない。マップ名はミニマップの見出しに出す。

**5. ゲーム中の言葉で書く。** 「インベントリ」ではなく「持ち物」と書く。操作の説明はシステムメニューの操作一覧（§4）にまとめ、本文の中で繰り返さない。

**6. 落ち着いた古典的な見た目。** 町の絵（ローポリにドット絵の住民、温かい光）と並んで浮かないようにする。そのため派手な光りもの、ネオン、大きなアニメーションは使わない。

## 2. 画面の層と配置

### 2.1 層（下から順に重なる）

画面は層を下から順に重ねてできている。いちばん下は**世界**で、3D の町を描く。その上に**世界の上の文字**（頭上の名前、発言の吹き出し、ダメージ数字）、さらに上の**固定の表示**（ステータス、パーティの枠、ショートカットバー）がある。

**ウィンドウ**の層には、ミニマップ、チャット、システムログ、持ち物、装備、能力、スキル、頼まれごと、糸をつないだ人、ワールドマップ、店、作業場、依頼、倉庫、取引の掲示板、取引、会話が入る。この層の中では触ったものが最前面に来る。名札のメニューと申し込みの知らせ（§3.18）もこの層に出る。

その上の**一時表示**は通知とツールチップ、**モーダル**はシステムメニューとその先の画面、ロード画面。いちばん上が**デバッグ**（dev のみ）。

### 2.2 固定の表示とウィンドウ

ミニマップ、チャット、システムログも、他と同じウィンドウ（§5）にする。つまり動かせて、閉じて、たためて、位置・大きさ・開閉の状態を覚える。三つとも初めから開いている。

ステータスとショートカットバーだけは固定の表示にする。どちらも遊んでいる間ずっと見て押すもので、閉じる理由がない。いつも同じ場所にあれば、目と手が場所を覚えられる。逆に動かせると、ほかのウィンドウの下に隠れて HP を見落とすおそれがある。パーティの枠も同じ理由で、ステータスの下に固定する。

│                                                    (袋)│

会話ウィンドウは開いたときだけ、下端中央のショートカットの上に出す。開閉ウィンドウの最初の位置は、持ち物・装備が右側、能力が左端、スキルとワールドマップが中央、頼まれごとと糸をつないだ人が中央より右、店・作業場・依頼が中央左、倉庫・取引・取引の掲示板が中央。最初の位置の値は各ウィンドウの `initial` にある。

## 3. 各ウィンドウ

各ウィンドウが表示し操作するものと、それに対応するシステムの節。

### 3.1 ステータス（固定・左上）— §3

パネルを敷かず、世界の上に直接、細い横長のバーを出す。バーは上から HP（赤）、SP（青）、スタミナ（緑、少し細い）の順で、右に白い小さな数値「29 / 48」を添える。HP と SP は自然回復（[[game-system#3.5 HP・SP・自然回復]]）の分を画面の側でも進めて出す。その下に、満腹（満腹・腹八分・小腹・空腹）と温まり（温まっている残りの分、または「冷えている」）を、小さなアイコンと文字で出す（[[game-system#3.6 スタミナ・満腹・温まり]]）。

顔・名前・Lv は出さない。名前は頭上に、Lv は能力の窓に出ているからである。パーティにいるときは、自分の枠の下にパーティの枠を出す（§3.12）。

### 3.2 ミニマップ（ウィンドウ・Tab・右上）— §1

角を丸めた正方形に縁を付け、上に方角の「北」を示す。マップは北が上で固定し、カメラを回しても回さない。

表示するのは、見出しのマップ名、地図の下の町とチャンネル（「町4 ch.1」）と時刻・時間帯、自分（向きのわかる矢印）、同じマップにいる他のプレイヤー、NPC、ワープの位置である。住民の印とは別に店の位置を示し、営業中は塗りつぶした四角、準備中は中を抜いた四角にする。店番が帰っても店の印は残す。室内の店は通り側では入口に示し、同じ場所を時間交代で使う売り手は一つの印にまとめる。印にカーソルを乗せると各店の名前と営業状態を表示し、クリックするとその場所へ歩く。営業状態はサーバーの売買判定と同じ規則を使う。地形の絵は町の地面を縮めたもので、マップと表示サイズが変わったときだけ縮小し直す。

クリックするとその地点へ歩く。タイトルバーの「大／小」で地図の大きさを二段に切り替え、これがウィンドウの大きさ変更の代わりになる。座標、時間帯の切り替え、ズームのボタンは置かない。カメラの操作は §7 の通り。

### 3.3 ワールドマップ（開閉・M）— §1

世界の升目（[[town#世界の升目]]）を 1 枚の地図で見せ、マップどうしを結ぶ道と今いるマップを示す。町の区画は一つにまとめて町の名を添える。通れないマップ（[[game-system#1. 世界とマップ]]）は薄く描き、マウスを乗せると「まだ通れない」と出す。まだ入れない都市は点線の枠で描き、「まだ行けない」と添える。下に現在地のマップ名を出す。

### 3.4 チャットとシステムログ（ウィンドウ）— §12

**チャット**は右下にあり、プレイヤーと住民の発言を「名前：本文」の形で小さな文字で出す。名前の色は、自分・他のプレイヤー・住民で分け、住民の発言は本文も住民の色にする。叫んだ発言には名前の後ろに「（叫ぶ）」と付ける。下に角丸の入力欄（「メッセージを入力…」）があり、押すか Enter で入力を始める。範囲の切り替え（`/s` など）は [[game-system#12. チャット]] の通り。

**システムログ**は左中段にあり、着いた・買った・断られたなどの知らせを白の小さな文字で一行ずつ出す。

どちらも動かせて、たためて、右下のつまみで大きさを変えられる。新しい行が来ると下までスクロールするが、読み手が上へ戻しているときは動かさない。

### 3.5 会話ウィンドウ（開閉・下中央）— §7

ショートカットバーの上に、横長で大きめに出す。NPC の名前と職の札を、枠の上辺にかぶせて付ける。

本文は 1 文字ずつ送る。送っている途中で進める操作をすると、まず全文を出す。全文が出ていれば、同じ操作で次のページに進む。続きがあるときは右下に ▼ を点滅させる。最後のページでは選択肢を番号付きで出し、番号キーで選べる。

開いている間は動けない（[[game-system#7. NPC・会話・クエスト]]）。画面も、地面・ほかの NPC・ミニマップのクリックとワープを受け付けない。歩いて近づいている途中に話しかけた場合は、着いて会話が始まった時点で止まる。閉じる（選択肢の「さようなら」、Esc、×）と動けるようになる。

### 3.6 店（開閉・その間は動けない）— §6

会話の「買い物をする」で開き、閉じると終わる。開いている間は会話と同じく動けない（§3.5）。店主から離れると閉じ、「店から離れた。」と知らせる。

タブは「買う」と「売る」の二つ。**買う**タブは品揃えを並べ、1 行に、アイコン（レア度の縁）、商品名、作られた物なら別行の作り手と品質の札、値段、残りの数（売り切れなら次に並ぶ時刻）、個数の増減、「買う」ボタンを出す。商品名は折り返して表示し、作り手名が長くても品の区別がつくようにする。値段・在庫の表示も必要に応じて折り返す。値段が下がっているときは「値引き」、親しさで安くなるときは「なじみ」と添える（[[economy#4. NPC の店の価格]]、[[economy#6. 住民との親しさ]]）。買えないときはボタンを灰色にし、理由をツールチップで出す。**売る**タブは持ち物をスロット格子で並べる。選ぶと下に名前、売値 × 個数、個数の増減、「売る」ボタンが出る。ただし売れない物（大事なもの）は薄く出し、選べない。

下端に所持金を出す。店を開くと持ち物ウィンドウも開き、持ち物を右クリックすると売るタブでそれを選ぶ。

### 3.7 持ち物（開閉・Alt+E / I）— §5

スロットの格子で、スロットにはアイコン、個数、レア度の縁色を出す。

ドラッグで並べ替え、ショートカットバーへドラッグすると登録する。装備欄からここへドラッグすると外す。ダブルクリックすると、回復品なら使い、装備品なら装備する。店・倉庫・取引の窓が開いているときは、右クリックでそちらへ出す（店なら売る品に選び、倉庫なら預け、取引なら出す物に加える）。倉庫へはドラッグでも預けられる。

下端に所持金と、重さ（今の重さ / 上限）を出す。アイテムにマウスを乗せるとツールチップ（§6.5）を出し、その下に今できる操作を一行で添える。

### 3.8 装備（開閉・Alt+Q / E）— §4.3

人形の絵の周りに装備欄（頭・首巻き・体・足・武器・盾・装飾品 2 つ）を置く。空いた欄は部位の形を暗い影絵で出す。

首巻きの欄に巻いた首巻きは、キャラクター画面で選んだ首巻きの代わりに見える。防御や能力の上乗せが付くものもある。

欄をダブルクリックするか持ち物へドラッグすると外し、持ち物から装備欄へドラッグすると付ける。下に攻撃力と防御を出し、そのうち装備による分を括弧で添える。

### 3.9 能力（開閉・Alt+A / C）— §3

上に名前、Lv（上限付き）、次の Lv までの経験値の帯と割合を出す。その下に 6 つの能力値を並べ、それぞれに「+」ボタンを付け、残りポイントを表示する。横に、能力値から決まる値（[[game-system#3.4 能力値から決まる値]]）を並べる。

見た目と名前は初回のキャラクター作成画面で決める。この窓には置かず、作成後はシステムメニューの「キャラクター」（§3.14）で変える。

### 3.10 スキル（開閉・K）— §9

三つの区切りで出す（[[game-system#9. スキル]]）。

一つめの生活スキルでは、スキルごとの Lv（上限付き）と経験の帯、次の節目で何ができるようになるかを出し、上に合計と合計の上限を置く。合計が上限に届くと赤で出す。経験のある生活スキルには「忘れる」を出し、変更後の Lv と失う経験を確認してから実行する。取り消しも同じ場所に置く。忘れる規則は [[game-system#9.1 生活スキル]] に従う。二つめの動作は座る・応急手当で、ボタンで使える（座っているときは「立つ」）。三つめの戦技と魔法には、いま手に持っている武器の技を、種類（戦技・術・祈り）と SP とともに出し、使える武器と条件（能力値・生活スキル Lv）を並べて、足りないものは赤で出す。祈りはここのボタンでも使える。ほかの武器の技は畳んで一覧にする。

アイコンはショートカットバーへドラッグして登録する。

### 3.11 クエスト（頼まれごと・開閉・J）— §7

クエストの窓は「頼まれごと」の窓で、今日引き受けたことと、その進み（持ってくる数、届ける、済んだ）を出す（[[economy#6.1 実装（日替わりの頼まれごと）]]）。下に親しい人を親しさの順に並べ、親しさの帯と、店で安くなる割合を添える。

### 3.12 パーティ（固定・ステータスの下）— §10

パーティにいる間だけ、ステータスの下に枠を出す。見出しに人数、リーダーが切り替える経験値の分け方（各自・均等）のボタン、「抜ける」ボタンを置く。その下に仲間ごとに、名前（リーダーには ★、自分には「（自分）」）、Lv、いるマップ、HP の帯を出す。しばらく知らせのない仲間は薄く出す（[[game-system#10. パーティ]]）。

誘うのは名札から行う（§3.18）。パーティ専用の開閉ウィンドウはない。

### 3.13 ショートカットと右端のボタン（固定）— §5

**ショートカット**は下中央に丸が 10 個並ぶ。暗い半透明の丸の上部に番号（1〜9, 0）を白で小さく出し、中にアイテムかスキルのアイコンを入れる。アイテムは個数を右下に出し、0 なら灰色にする。戦技は、今の武器や能力値で使えなければ灰色にし、理由をツールチップに出す。再使用待ちの間はアイコンを暗くし、残り秒数を重ねる。ツールチップには消費 SP も出す。時計の更新は登録された技に待ち時間がある間だけ行い、待ち時間中の攻撃技は送信前にも止める。クリックか番号キーで使い、右クリックで外す。

**右端の丸いボタン**は縦一列に並ぶ。暗い半透明の丸に白い線のアイコンを描く。上から 持ち物（袋）・装備（シャツ）・スキル（星のカード）・地図・糸をつないだ人（人二人）・設定（歯車、システムメニュー）の順。マウスを乗せると名前とキーを出す。ボタンのない窓はキーで開く（§4）。

**経験値**は、画面の最下端に、画面幅いっぱいの細い青いバーで出す。

### 3.14 システムメニュー（モーダル・Esc）— §13

Esc で閉じるものが何も開いていないときに開く。

項目は「キャラクター」「操作一覧」「チャンネル」「ゲームを閉じる」「ウィンドウの配置を戻す」「ゲームに戻る」。音量や表示の設定とログアウトはまだなく、ログアウトはアカウントができてから足す。「ゲームを閉じる」は接続を終了するが、所有権を手放すログアウトではない。

**キャラクター**では、名前、姿（用意した見た目から選ぶ）、首巻きの形（マフラー・ストール・スカーフ）と色を選び、選んでいる姿を絵で見せる。年中寒い町なので、だれもが何かを首に巻いており、「なし」はない。**操作一覧**は §4 の操作を表にしたもの。**チャンネル**は §3.25。「ウィンドウの配置を戻す」は、すべてのウィンドウの位置・大きさ・開閉を最初の状態にする。

### 3.15 通知（一時表示・上中央）

売り買い・装備・使用の結果や、断られた理由を 1 行で出し、少しして消す。良い知らせと悪い知らせで文字の色を変える。同じ内容はシステムログにも残す。

### 3.16 ロード画面（モーダル）— §1

画面の間はどれも同じ見た目の画面で揃える。地はほぼ黒の墨色の無地で、ごく控えめに灰の粒が降る。中央やや下に地名（明朝、小さめ・字間広め）を出し、その下に髪の毛ほどの細い進み具合の線（灰白、角丸なし）、さらに下に世界の一節（2〜3 行、控えめな灰色）を置く。ドット絵・グラデーション・スピナー・カード・影・アイコン・絵文字は使わない。

この画面を四つの場面で使う。読み込み（最初のロードとマップ移動）では、一節を `world/town/flavor.ts` から毎回選ぶ（行き先の地のものか、どこでものもの）。読み込みが早く終わっても、すぐには消さずにゆっくり消える。倒れた（[[game-system#8. 戦闘]]）ときは、「倒れた」と失った経験値、文字だけの「町へ戻る」を出す。切断したときは「つなぎ直しています」だけを出し、つなぎ直しは自動で行う。描けなかったときは、一文と文字だけの「読み込み直す」を出す。

それぞれ /dev/screens と /dev/ui?window=loading|fallen|offline|failed で状態を固定して見られる。

### 3.17 吹き出し（一時表示・頭上）— §12

プレイヤー（自分・他のプレイヤー）の発言を頭上に出し、文字数に応じた時間で消す。同じ人の新しい発言は前のものと置き換える。誰に出るかは [[game-system#12. チャット]] の通り。

### 3.18 名札のメニューと申し込み — §10・§11

ほかのプレイヤーの名札をクリックすると、上中央にその人の名前と「取引を申し込む」「パーティに誘う」「糸を交換する」「閉じる」を出す。申し込まれた側には、上中央に「〜から取引の申し込み」「〜からパーティの誘い」「〜がマフラーの糸の交換を申し出ている」と、受ける・断るのボタンを出す。条件と流れは [[game-system#10. パーティ]]、[[game-system#11. 取引]]、[[game-system#1.1 並行する町とチャンネル]]。

### 3.19 取引（開閉・その間は動けない）— §11

取引が始まると開き、持ち物ウィンドウも開く。左に自分が出すもの、右に相手が出すものを同じ数の枠で並べ、それぞれに出すお金と、考え中・決めた・交換を押したの状態を出す。決めた側の枠は縁の色を変える。

出す物は持ち物を右クリックして加え、自分の枠を右クリックして下げる。お金は数を入れて「置く」。下に「決定」「交換」「やめる」を置き、「交換」は両方が決めてから押せる。

### 3.20 作業場（開閉）— §9.1

作業場の前の印をクリックして着くと開く（[[economy#2. 加工と生産]]）。作業場で作れる品を並べ、1 行に、できる物、材料ごとの手持ち / 要る数、要る生活スキル Lv、「作る」ボタンを出す。足りない材料と Lv は赤で出し、作れないときはボタンを灰色にして理由をツールチップで出す。上限より上の Lv でしか作れない品は出さない。下端に使用料、一回に使うスタミナ、所持金を出す。

作業場から離れると閉じる。WASD では歩けないが、クリックでは歩ける。

### 3.21 依頼（開閉・その間は動けない）— §9.1

職人との会話の「仕事を頼む」で開く（[[economy#3. 加工の依頼]]）。上に頼んである物と、できる時刻（できていれば「できている」と「受け取る」）を出し、下に頼める仕事を、材料の手持ち / 要る数、かかる時間、手数料、「頼む」ボタンで並べる。職人から離れると閉じる。

### 3.22 倉庫（開閉・その間は動けない）— §5

倉庫番との会話から開き、持ち物ウィンドウも開く（[[game-system#5. 持ち物・装備・倉庫]]）。預けた物を格子で並べ、右クリックかダブルクリックで引き取る。持ち物からは右クリックかドラッグで預ける。下端に預かり賃と、使っている枠の数を出す。倉庫番から離れると閉じる。

### 3.23 取引の掲示板（開閉）— §6

寄り合い所の掲示板をクリックして着くと開く（[[economy#5. 取引所]]）。左に品の一覧（文字でさがせる）、中央に選んだ品の店の値段、売りと買いの板、二週間分の値動きと出来高の図、出している人を出す。右で自分の注文を出す（買う・売る、一つの値段、数、預ける額か手数料、出品料）。その下に自分の注文と取消、受取箱と「受け取る」を置く。

掲示板から離れると閉じる。WASD では歩けないが、クリックでは歩ける。

### 3.24 糸をつないだ人（開閉・F）— §1

今いる町（自分の町か、訪ねている町か）と、糸を交換した人を新しい順に、名前と町で並べる。人ごとに「糸をたどる」で、その人の町へ渡る。訪ねているときは「自分の町へ帰る」を出す（[[game-system#1.1 並行する町とチャンネル]]）。

### 3.25 チャンネル（モーダル）— §1

システムメニューの「チャンネル」で開く。今の町の今のマップのチャンネルを、人数と定員で並べ、満員でなければ「移る」で移れる。最後に「新しく開く」チャンネルを一つ足して出す。会話や店の最中は移れない（[[game-system#1.1 並行する町とチャンネル]]）。

## 4. 操作

マウスの操作から書く。地面をクリックするとそのマスへ歩き、経路はマス単位で決まる。NPC をクリックすると隣まで歩いて話しかける。採集・会話・戦闘のために移動している途中で別の移動や行動を指示したら、前の到着後の行動は取り消す。停止・行動不能・位置の置き直しでも取り消し、停止後に残りの一歩を終えても採集や会話を始めない。ほかのプレイヤーの名札をクリックすると名札のメニュー（§3.18）を出す。画面を左右にドラッグするとカメラを 45° ずつ回し、ホイールでズームする（§7）。ドラッグは開始したポインターだけが操作し、別の指の移動や終了では回転させない。ポインター操作のキャンセルや画面のフォーカス喪失でドラッグを解除し、画面へ戻っただけでは回転やクリックを実行しない。

WASD と矢印キーでも歩ける。押している間 1 マスずつ進み、向きは画面の上下左右（カメラの回転で決まる）。会話・店・取引・作業場・依頼・倉庫・取引の掲示板が開いている間は効かない。会話や取引など移動キーが効かない画面、モーダル、ロード画面が開いた時点で、次のキー入力を待たずに押していた移動キーを解除する。持ち物など移動を妨げないウィンドウを開いても解除しない。入力欄へフォーカスを移したときや画面からフォーカスが外れたときは、押していた移動キーを解除する。入力を終えても移動は再開せず、改めてキーを押して歩く。カメラの各向きで WASD の上下左右・斜めが画面の方向に一致することは、`scripts/check-walking-directions.mjs` でブラウザのキー入力から歩行後の座標まで確かめる。この検査では歩行の送信を止め、クライアントの移動と投影を検査する。通信による位置補正は別に検査する。

キーでは、Enter でチャットの入力欄を開き、入力中なら送る。Esc は閉じる操作で、閉じる順は §4.1 の通り。1〜9, 0 はショートカットバーを使うが、会話の最後のページで選択肢が出ていれば選択肢を選ぶ。Space かクリックで会話を進める。

ウィンドウは、文字キー 1 つで開閉する。持ち物は I、装備は E、能力は C、スキルは K、頼まれごとは J、糸をつないだ人は F、ワールドマップは M、ミニマップは Tab。持ち物・装備・能力は Alt+E・Alt+Q・Alt+A でも開閉でき、チャットのウィンドウは Alt+C で開閉する。

カメラは Q と E を Shift と一緒に押して回す。E を装備に使うので、カメラを回すのは Shift+Q と Shift+E にしている。Z は座る・立つ。

文字キー 1 つのショートカットは、入力欄に入力している間、モーダルが開いている間、ロード中は効かない。Ctrl や ⌘ と組み合わせたキーはゲームでは使わず、ブラウザに任せる。キーの割り当ては `world/parts/keys.ts` にある。

### 4.1 Esc で閉じる順

Esc は次の順で閉じる。

1. チャットの入力欄
2. モーダル（システムメニューとその先の画面）
3. 申し込みの知らせ（取引・パーティ・糸の交換。断る）
4. 取引（やめる）
5. 名札のメニュー
6. 会話ウィンドウ
7. 店
8. 作業場
9. 依頼
10. 倉庫
11. 取引の掲示板
12. 開閉ウィンドウのうち最前面のもの（ミニマップ、チャット、システムログは Esc では閉じない）
13. 歩いている途中なら立ち止まる
14. 何もなければシステムメニューを開く

## 5. ウィンドウ共通の振る舞い

ウィンドウはタイトルバーをつかんでドラッグして動かす。画面の外には出ず、一部は必ず画面に残る。動かした位置はブラウザに保存し、次に開いたときもそこに出す。クリックしたウィンドウを最前面にし、新しく開いたウィンドウも最前面に来る。

閉じるには、タイトルバーの右端の × か、ショートカットキーをもう一度押すか、Esc を使う。タイトルバーの「－」を押すとタイトルバーだけにたたみ、もう一度押すと戻る。大きさを変えられるウィンドウ（チャットとシステムログ）は右下のつまみで大きさを変え、最小の大きさがある。

覚えることは、位置・大きさ・たたんだ状態がウィンドウごとで、開閉の状態はまとめてブラウザに保存する。店・作業場・依頼・倉庫・取引の掲示板・取引は、相手やその場所があって開くものなので、開閉の状態は覚えない。タイトルバーにはショートカットキーを小さく出す。画面の大きさが変わったら、はみ出したウィンドウを内側へ戻す。

## 6. 見た目

全体に控えめにして、景色を邪魔しない。重い装飾枠・木目・金縁は使わない。

### 6.1 色（`components/game/game.css` のトークン）

色の値は `game.css` のトークンにある。窓の地は黒〜濃紺で、うしろが少し透ける。文字の色は本文・補足・ごく薄い補足の三段。強調と区切りは、真鍮の色ではなく白の半透明で控えめに果たす（トークンの名前は `--color-brass` のまま）。細いバーは HP が赤、SP が青、スタミナが緑、経験値が青。レア度の縁は、灰・緑・青・金。

### 6.2 文字

すっきりしたゴシック体ひとつを使う。見出し・ボタン・数字は太字。ロード画面（§3.16）だけは明朝を使う。

頭上の名前は、白の小さな太字に暗い縁取りを付け、背景は敷かない。住民の名前は、近くにいる人の分だけ出す。

### 6.3 窓

窓は暗い半透明の地に角丸、ごく薄い縁と弱い影を付け、うしろを少しぼかす。タイトルは帯を付けず、白の小さめ太字で書く。右上に「－」（たたむ）と「×」（閉じる）を置き、大きさを変えられる窓は右下につまみを付ける。窓の中のくぼみは、少し明るい半透明の角丸にする。

### 6.4 ボタンの状態

通常のボタンは白の薄い角丸で、ホバーで少し明るくなる。主な操作は青みの半透明にし、無効は文字を薄くする。選択中（タブ・トグル）は少し明るい地と太字にする。丸いボタン（ショートカット・右端）は暗い半透明の丸で、ホバーで少し明るくなり、開いている窓のボタンは青みを帯びる。

### 6.4.1 地面

地面はドット絵として描く（`world/scene/terrain.ts`）。色はその地面の帯（`world/scene/pix.ts` の RAMPS）の数段だけを使い、拡大はぼかさない。

一面を一ドットずつの乱数だけで埋めると、ちらついて砂嵐に見える。そこで小さな形を描いて、ずらした格子に散らす。ただし整えすぎない。色むら・ざらつき・汚れ・欠けは残し、素朴で使い込まれた感じを大事にする。

草は、先が明るく根元に影のある草の房、小さな若芽、花のかたまり（花びらと芯）で描く。土と道は、上が明るく下に影のある小石と土のむらで描き、人の歩くまん中は踏み固められて少し明るくする。道に沿った線（わだち）は、遠目に謎の筋に見えるので描かない。森は、落ちた松葉の筋、苔のかたまり、吹きこんだ落ち葉で描く。

石畳と広場の敷石は、整った綺麗な舗装にせず、古く使い込まれて壊れかけた素朴な道にする。石ごとに色むらとざらつき（左上が明るい）を付け、目地は暗い土にし、湿ったところは苔が目地からはみ出して石の縁にかかる。欠けた石、霜のひび、まわりより沈んだ石、抜け落ちた石（穴に土と草や苔）、黒ずみと泥はねを入れる。道の縁ほど石が抜けて、土や草が食い込む。

広い明暗のむらは二、三段の平らな色にし、段の境目は規則的なディザでなじませる。地面どうしの境目（草と道、苔と松葉）は線で切らず、草や苔の房をはみ出させてぎざぎざにする。霜は草の窪みにだけ、明るい点として置く。灰の積もり方は [[town#灰の降る町]]。

夜はどれも暗くなる。自分で光ってよいのは、窓の灯り・街灯・焚き火と炉の火・炭焼き窯の口だけ。板に貼った絵（畑の作物・軒先の品・散らかった物）もライトの効かない材質なので、時刻の色（昼は白、夕は橙、夜は青暗い）を掛けて暗くする（`world/scene/gfx.ts` の `litSprites`）。

入れない家（人の住まい）は中を見せない。家具は作らず、窓はガラスと鎧戸だけ（夜は灯りの色）にし、プレイヤーが裏に回っても家を透かさない。その代わりにプレイヤーを壁越しに淡い影絵で描く。入れる店や木は、カメラとプレイヤーのあいだにあると薄くなる。

プレイヤーには常に白い 1 ドットの輪郭を付け、屋根越しの影絵の上にも出す。ほかのキャラ（住民・他のプレイヤー・魔物・動物）は、カーソルを当てた時だけ同じ輪郭を付ける（`world/scene/outline.ts`）。

井戸に水面は描かない。縁の内側に内壁の石（上の方は湿って苔むす）が見え、奥へ向かって黒く落ちていく穴にする。

### 6.4.1.1 建物・木・岩

地面と同じ考え方で、1 ドットずつの乱数を使わず、形と平らな色で描く（`world/scene/textures.ts`）。

屋根瓦は一枚ずつ平らな一色（ときどき一段ずれる）にし、上の縁を明るく、足もとに上の瓦の影、横に暗い継ぎ目を入れる。湿ったところには苔の小さなかたまりを付ける。茅葺きは藁の束を段に重ね、一段ごとに上を明るくし、端は長さの揃わない藁でぎざぎざにする。

漆喰は平らな二色の広いむらにする。足もとの汚れと軒下の影は規則的なディザで段にし、雨だれは 1 ドット幅の線、ところどころに細いひびを入れる。木組みは平らな色に、短い暗い線の木目とときどき節を入れる。積んだ石は石ごとに平らな一色で、上を明るく下を影にし、目地は暗くする。

葉は、左上が明るく下が影の小さな葉のかたまりを、奥の暗い葉の上にすき間なく重ね、ときどき日の当たる明るい葉を混ぜる。継ぎ目なく繰り返す。岩は平らな面に割れ、面ごとに明暗を付け、面の境は暗いひびにし、ところどころ白っぽい地衣を付ける。岩には積んだ石の壁とは別の絵を使う。

### 6.4.2 動物と魔物の顔

動物と魔物（スライム、野うさぎ、鶏、猫、豚、羊など）は**目だけ**を描く。口と鼻（くちばし・鼻づら・肉垂れも）は描かない。目はドット絵で、黒に白い 1 ドットのハイライトを入れてよい。とさかや耳のように顔以外の形はそのまま残す。

スライムは低い多角形の丸い体に、ドット絵の肌（体の色の数段の明暗、光沢、中の小さな泡）を貼る。

### 6.4.3 人の顔

人（プレイヤー・住民）の顔は目だけで、口と鼻は描かない。頬に少し赤みを入れる。

目は T 字で、住民もプレイヤーも全員そうする。まぶたとまつ毛を濃い色で横に引き、その下のまん中に瞳の色（住民ごとの `eye`）を縦に置く。まばたきは横棒だけにする。左右の目のあいだには必ず肌を空け、斜めの向きで寄りすぎないようにする。これは `world/scene/eyes.test.ts` が全住民・8 方向・開いた目とまばたきで確かめる。

縦一本だけの目も、見た目の `eyeStyle: 'stroke'`（`world/scene/figure.ts`）で描ける。/dev/eyes で T 字と並べて見比べられる。

### 6.5 アイコンとスロット

アイテムと画面のアイコンはドット絵で、町と同じ色の帯（`world/scene/pix.ts` の RAMPS）から描く。整数倍で拡大して使い、ぼかさない。

アイテムは、全アイテムが定義表に `icon` を持つ（必須）。作り手によって入れ物や盛り付けが変わる品は、その作り手の絵になる（`world/core/makers.ts`）。食べ物は市場の品物と同じ描き方（`world/scene/goods.ts`）、武器は線で描いた剣・斧・槍・メイス、防具と装飾品は手描き（`world/art/pixel-art.ts`、`world/art/item-art.ts`）。画面に使うドット絵のアイコンには、通貨の硬貨、満腹と温まり、空いた装備欄の影絵、座るのショートカットがある（`world/art/icons.ts`）。

右端の丸いボタン（§3.13）だけは、ドット絵ではなく線画のアイコン集（`lucide-react`）の白い線で描く。

スロットの縁はレア度の色にし、空きスロットは暗い凹みにする。

ツールチップには、名前（レア度の色、作られた物なら品質を添える）、種別と部位、説明、作り手ごとの特徴、効果（HP・SP の回復、スタミナ、温まり、満腹）、攻撃力・防御と能力の上乗せ、必要な能力値と生活スキル Lv（足りないものは赤）、レア度、重さ、売値（売れない物は「売れない」）を出す。武器なら、これに持ち方（両手）、攻撃の間隔、能力補正、技が加わる。作り手の名前は品の名前に入る。

## 7. カメラ

見下ろしの斜め視点で、プレイヤーを追う。画面中央の範囲（デッドゾーン）の外に出た分だけ追い、回した直後は中央に置き直す。

回転は 45° ずつで、補間せずにすぐ切り替える。操作はドラッグと Shift+Q / Shift+E。右へドラッグすると地面をつかんで引いたように前方が右へ回り、Shift+Q も同じ向きに回る。左へのドラッグと Shift+E はその逆（`world/scene/turn.ts`、`turn.test.ts` で固定）。

ズームは 2 段。初めは引いた段で、ホイールで寄ると最も寄った段になり、それより寄れない。

画面の縁だけを控えめにぼかす。ぼかしは画面の形に合わせた楕円で、中央の広い範囲は完全にくっきりさせ、縁の外側からなだらかに効かせる。中心は画面の中央に固定する。強さは画面の CSS ピクセルで決め、開始位置・強さ・彩度・コントラストはデバッグパネルで調整する（値は `world/scene/village.ts` の `diorama`）。

## 8. デバッグパネル（dev のみ）

F1 で開閉する（Mac では fn+F1）。`（バッククォート）でも開閉する。`import.meta.env.DEV` のときだけ読み込む。開発用の shadcn（`components/ui`）で作り、ゲームの UI とは見た目を合わせない（`dev/debug-panel.tsx`）。

中身は、FPS、マップ、マスと座標、スプライトの残り、接続の状態と同じマップの人数、プレイヤー ID、時間帯（昼・夕方・夜）、縁のぼかしの入り切りと調整、プレイヤーデータを初期化するボタン。`window.game` と `window.diorama` もこのときだけ出す。

### 8.1 開発用カタログ（/dev）

開発用の shadcn で作ったページ群（`pages/dev/`）で、本番ではミドルウェア（`middleware/01.dev-pages.ts`）が 404 を返す。

/dev はゲームの定義を直接読むデータベースの閲覧画面。カテゴリごとに `/dev/<カテゴリ>`（一覧）→ `/dev/<カテゴリ>/<ID>`（項目・参照先・参照元）と辿る。カテゴリの定義は `dev/db.tsx` にあり、ゲームに新しい表が増えて /dev に出ていないと `dev/sources.test.ts` が落ちる。横スクロールなしとサイドバーの固定は `npm run test:dev-pages` で確かめる。道具のページは `/dev/studio`、`/dev/ui?window=<名前>&shop=<店>`、`/dev/eyes`。

データはゲーム本体と同じ定義を読むだけで、別に持たない。

確認しやすくするために、次の決まりを置く。ゲームのページはクエリで始める場所と状態を決められる。使えるのは `map`, `x`, `z`（タイル座標）, `open`（ウィンドウ名をカンマ区切り）, `debug=1`, `time`（その時刻で止める）と、町を選ぶ `world`（[[game-system#1.1 並行する町とチャンネル]]）。`debug` と `world` は開発中のビルドだけで効く。描き終わると `<body data-ready="1">` になり（ゲームはマップに入った時、カタログはページを描いた時）、スクリーンショットはこれを待つ。

## キャラクター作成と退出

初回は名前と外見を決める画面を開く。確定前は閉じず、保存が成功してから町を操作できる。作成中の入力はブラウザ内に下書きとして残し、再読込で戻す。通信中や切断中は確定を止め、失敗時は入力を残して再試行できる。作成後の変更も成功応答を待ち、編集中の入力を定期的なプレイヤー情報の更新で上書きしない。保存の規則と所有権は [[game-system#13. 永続化]] にある。

初回作成の成功後は、移動・住民との会話・持ち物・地図・チャット・自動保存の短い案内を出す。再開や外見の編集では繰り返さない。キャラクター画面は `components/hud/character-screen.tsx`、初回案内は `welcome.tsx` が受け持つ。

メニューの「ゲームを閉じる」は接続と描画を終了し、「町に戻る」を表示する。キャラクターやブラウザの所有権は削除しない。別の画面へ接続が引き継がれたときは、その理由を通知し、自動で接続を奪い返さない。接続を復元できないときは、描画の失敗と区別して表示する。
