# フエ

## 都市の役割

フエは石畳と煙突、機関の工房が集まる都市（名称・構想は仮）である。都市の位置づけは [[world#場所]] を変更せずに引き継ぐ。

## 設計する生活

食料、水、燃料、衣服、道具、住まい、排水、排泄物と灰の回収を都市内外の経路としてつなぐ。住民は世帯と仕事を持ち、仕事のための建物と眠る部屋を持つ。公共の設備には管理する住民と維持の仕事を割り当てる。

## 地区と建物

現行コードに都市内部の地区や住民はない。以下の図は局所の未配置の区画案であり、既存の自動配置から採った都市図ではない。ファンティエットの世帯を名前だけ変えて流用せず、この都市の産業と供給先から地区と住まいを設計する。門前のマップを都市全体の設計と取り違えない。

## グラフィックへ進む条件

各地区の物流と生活、各建物の全階、各部屋の家具と動線をグリッドで検証し、資料間の参照と矛盾を解消してから描画へ渡す。未設計の対象はメタデータへ残し、完成した都市として扱わない。


## 未配置の区画案

town_district_plan は区画の隣接と道の余地を設計する局所の案である。図の向きと原点はまだ門前へ割り当てていない。D は既存の門前へ結ぶ候補、点は道の余地、# は今回の検討範囲の外であり、実際の城壁を追加した意味ではない。区画の記号は建物の壁や床ではなく、各敷地・建物・部屋の設計を起こすための予約である。


W は機関の工房へ割り当てる。部品を直す仕事と人が扱う小さな機関。住まいと燃料を同じ室へ詰めない。

F は食料の受渡しへ割り当てる。門から来る食料を覆いの下で受け、家庭へ渡す。

H は工房の住民の住まいへ割り当てる。作業場の奥を寝床とせず、家庭の食事・睡眠・収納を持つ。

B は薪と炭・炉灰の受渡しへ割り当てる。乾いた燃料と火を失った灰を別の容器へ分ける。

P は生活用水の受渡しへ割り当てる。灰を避けて水を受け、飲用の容器と汚れた道具を分ける。

C は礼拝と手当てへ割り当てる。修道士が女神を祀り、手当てと記録を行う。

X は汚水と排泄物の一時保管へ割り当てる。食料と水の受渡しを通して運ばず、最終処理へ結ぶ。

L は衣服の手入れと室内干しへ割り当てる。工房の汚れた仕事着と家庭の清潔な布を区分する。

J は家庭と来訪者の住まいへ割り当てる。泊まる来訪者の寝床を、工房の作業台で代用しない。

図の道は区画の使用面同士をつなぐ余地であり、荷役・車輪・人のすれ違い、扉と段差、煙や火の離隔の照合ではない。operator は未割当のまま残し、担当者がいない区画を稼働する設備へ数えない。新しい住民は世帯・寝床・食事・仕事と一日の割当を決め、個別資料を作ってから登録する。

工房を通らずに家庭へ食料と水を渡し、燃料と灰・汚水の運搬を清潔な受渡しへ混ぜない経路を続けて設計する。煙突が並ぶ見た目を先に作らず、機関ごとの持ち主と仕事、薪と炭・灰、掃除と休止の場所を決める。


## 最初の世帯の割当案

H の住宅候補へ [[resident-ルードヴィヒ]] の一人の世帯を割り当てる。[[building-hue-ludwig]] とその六室、[[map-hue-quarter]] は未実装の個別資料であり、都市の門や区画を実装したものではない。寝床と個人収納の固有 ID を持たせ、工房は W に別の仕事場として設計する。担当する作業の全室と量・食料と水・便所と衣服の手入れ・一日の時刻は引き続き未設計である。
