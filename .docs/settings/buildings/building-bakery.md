# マルタのパン屋

## 使い手と役割

パン屋のマルタとハンスの建物である。同居人はマルタ、ハンス、ローザ。パン焼き。粉は風車、薪は木こりから。

## 部屋の構成

1階の[[room-bakery-1]]を持つ。1階の[[room-bakery-2]]を持つ。2階の[[room-bakery-3]]を持つ。2階の[[room-bakery-4]]を持つ。

## 生活と仕事の設計条件

暖を取る炉が必要である。薪の搬入、乾燥保管、煙突への排煙、灰の取り出しを同じ炉の配置で成立させる。調理する場所を持つ。飲用水、食材、配膳、洗い物、残り物と汚水の扱いを部屋の間でつなぐ。

仕事の設備は「パン窯」。材料、仕掛品、完成品、道具の収納と手入れ場所を区別する。

## 現状との差分

現行の家具候補は窯（外）、売り台、粉箱、食卓、寝台×3、衣装箱、椅子×3。これは配置の正しさを示すものではない。各部屋のグリッドで、家具の実寸、使用面、扉の開閉、階段と通路を検証する。便所・排水・換気の配置は本資料ではまだ確定していない。

## 再設計案の寸法と階のつながり

壁を含む外周の寸法は layout に持つ。一階は南を売り場、北を台所とし、共通の壁と戸口を同じセルで重ねる。二階は南に [[room-bakery-landing]]、北に二つの寝間を置く。マルタとローザの寝間は西、ハンスの寝間は東とする。各部屋の origin は建物北西からのセル座標であり、階段の上下は同じ平面の範囲を占める。

この案は現在の外観寸法と一致しないため、実装済みの建物へ無理に押し込まない。隣地・道・屋外窯・入口との干渉を解消して外観を設計し直す必要がある。寝間だけでなく、便所、汚水、洗い物、薪と灰の搬入出が未確定であり、建物の設計はまだ完了していない。

## 客と家族の経路

客は南の戸から売り台と商品棚へ進み、同じ戸から外へ戻る。家族は売り台の奥と台所を行き来し、西側の階段で二階へ上がる。階段は部屋間の扉ではなく、上下階の占有範囲と上端・下端の使用面を一組で記録する。寝間の戸口は共用踊り場にだけ開き、他人の寝間を通路にしない。店の営業時間に家族の階段へ客が入らない区切り方は、客の視線と避難経路を保った戸や建具として検討する。

## 町の設備とのつながり

生活用水は [[facility-square-well]] から蓋付きの桶で運ぶ。リーゼルの配水に常時依存する設計にはせず、家族の仕事前後の水汲みを日課と照合する。粉・薪の搬入と、[[facility-bakery-oven]] へ生地を運ぶ経路を別に確認する。台所の汚水と便所は、町全体の処理方式と場所が決まるまで行き先が確定していない。

## 敷地案と道の照合

室内表示の拡大率を使わず、グリッドの実寸を屋外の一タイルの実寸へ変換する。台所の同時作業と三人の席への出入りを確保するため、北側へ床を広げる。南の売り場と上階の共用通路、二つの寝間も同じ外周へ合わせる。具体的な位置は site_plan に持ち、家・道路・川と庭の占有に照合する。

台所と売り場の共有戸口を東へ寄せ、作業中の人が通路を塞がないよう商品棚を組み直す。地面の高さ、屋根・窓・煙突と屋外窯・台への仕事の接続は引き続き照合する。

## 戸口から道まで

新しい南の戸口を出て東寄りへ折れ、窯の東側から広場の西へ伸びる道へ出る。屋外窯の占有と接続路の幅を照合する。既存のパンを並べる台を動かす必要と、熱い天板を運ぶ面は別に設計する。

具体的な折れ点と通路幅は site_plan.approaches に持つ。敷地の向きを反映した戸口から始まることと道への到達を検査する。路面の高さ、段差、扉の開閉と人や荷を運ぶ姿勢まで確定したわけではない。

## 寝台の使用面による拡幅

マルタとローザの寝台の間に使う床を確保するため、計画矩形を一セル広げた。ハンスの部屋を東へ移し、踊り場の戸口も同じだけ移す。一階の台所と売り場も同じ外周へ合わせる。南の戸口からの接続を位置の調整に合わせ、敷地と道への接続を再検査する。
