# エドガーの家

## 使い手と役割

エドガーとマルグリットの建物である。同居人はエドガー、マルグリット。隠居。エドガーは元の門番で、寄り合いから少し出る。

## 部屋の構成

1階の[[room-h-g6-1]]を持つ。1階の[[room-h-g6-2]]を持つ。

## 生活と仕事の設計条件

暖を取る炉が必要である。薪の搬入、乾燥保管、煙突への排煙、灰の取り出しを同じ炉の配置で成立させる。調理する場所を持つ。飲用水、食材、配膳、洗い物、残り物と汚水の扱いを部屋の間でつなぐ。

仕事場を持たない場合も、日常の掃除・衣服の手入れ・修理道具を置く場所を決める。

## 現状との差分

現行の家具候補は揺り椅子、古い槍、食卓、寝台（二人用）、椅子×2。これは配置の正しさを示すものではない。各部屋のグリッドで、家具の実寸、使用面、扉の開閉、階段と通路を検証する。便所・排水・換気の配置は本資料ではまだ確定していない。

## 地上二室の平面案

壁込み六メートル×八メートルで、北に二人の寝台と衣服、南に食事と揺り椅子・編み物を置く。地上で生活をつなぎ、階段を足さない。西の戸から門の通りへ出る案を持つ。現行より奥行のある室内案であり、外観・地面の高さと排煙、庭と生活設備を照合してから描画を切り替える。
