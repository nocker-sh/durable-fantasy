# フェルディナントの借家

## 使い手と役割

ヴィルヘルムが貸主、地図描きのフェルディナントが借り手である。一人で暮らす。町と道の地図を描いて、寄り合いとテオに納める。ヴィルヘルムの貸家に住む。

## 部屋の構成

1階の[[room-h-m4-1]]を持つ。

## 生活と仕事の設計条件

暖を取る炉が必要である。薪の搬入、乾燥保管、煙突への排煙、灰の取り出しを同じ炉の配置で成立させる。調理する場所を持つ。飲用水、食材、配膳、洗い物、残り物と汚水の扱いを部屋の間でつなぐ。

仕事場を持たない場合も、日常の掃除・衣服の手入れ・修理道具を置く場所を決める。

## 現状との差分

現行の家具候補は地図の束、食卓、寝台、椅子×1。これは配置の正しさを示すものではない。各部屋のグリッドで、家具の実寸、使用面、扉の開閉、階段と通路を検証する。便所・排水・換気の配置は本資料ではまだ確定していない。

## 一室の平面案

壁を含む六メートル四方の一階案を[[room-h-m4-1]]に置く。寝台、衣服、地図の作業と保管、食卓、調理を用途で分ける。これは現行の外形に収まることを確認した寸法ではなく、敷地へ照合する前の案である。貸主の炉と、借り手の机・箱・椅子を区別する。

## 敷地への向き

室内案を四分の一回転し、室内の東の戸を屋外の北の通りへ向ける。元の北西位置を基点に室内実寸の矩形を置く案であり、現行の外観の大きさは変更していない。隣の醸造所・寄り合い所と道幅、戸口から道への接続を平面で照合する。屋根や煙突、窓と地面の高さは別に確定する。
