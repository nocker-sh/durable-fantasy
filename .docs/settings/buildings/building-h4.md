# ヘレナとリーゼルの家

## 使い手と役割

ヘレナと娘のリーゼルの建物である。同居人はヘレナ、リーゼル。ヘレナは繕い物、リーゼルは水汲み。

## 部屋の構成

1階の[[room-h4-1]]を持つ。2階の[[room-h4-2]]を持つ。

## 生活と仕事の設計条件

暖を取る炉が必要である。薪の搬入、乾燥保管、煙突への排煙、灰の取り出しを同じ炉の配置で成立させる。調理する場所を持つ。飲用水、食材、配膳、洗い物、残り物と汚水の扱いを部屋の間でつなぐ。

仕事場を持たない場合も、日常の掃除・衣服の手入れ・修理道具を置く場所を決める。

## 現状との差分

現行の家具候補は縫い物の台、水甕、食卓、寝台×2、椅子×2。これは配置の正しさを示すものではない。各部屋のグリッドで、家具の実寸、使用面、扉の開閉、階段と通路を検証する。便所・排水・換気の配置は本資料ではまだ確定していない。

## 生活から組み立てる平面案

壁を含む外周の寸法は layout に持つ。二階の床は一階と同じ範囲とし、西側の直階段を上下で合わせる。一階の入口から水甕・台所・縫い台・食卓・階段へつながり、二階では二人の個別寝台と衣装箱へ届く。現在の建物外形にこの矩形が入るという確認はまだなく、外観と敷地の調整が必要かを次に照合する。

一階の室内干しは東壁沿いに限定する。灰が降るため屋外には干さず、通路の頭上を横切る縄も作らない。家族の洗濯物を干す場所であり、洗濯を仕事にする世帯へ設定を変えない。

## 敷地の向きと隣家

室内案の南の戸を、屋外では東向きの戸に対応させる。計画矩形を四分の一回転し、site_plan の位置へ置く。元の戸の位置に固定して西へ増築する案は、隣の [[building-h8]] に重なるため採用しない。東側へ位置を調整する案とし、道と隣家の矩形へ重ならないことを検査する。戸口からの接続路を平面で照合し、屋根・窓・煙突の離隔は引き続き確認する。

## 戸口から道まで

新しい東向きの戸口から東へ進み、広場の南へ伸びる道へつなぐ。入口からの水運びと家族の帰宅の経路を同じ幅で扱い、隣の建物の中を抜け道として使わない。

具体的な折れ点と通路幅は site_plan.approaches に持つ。敷地の向きを反映した戸口から始まることと道への到達を検査する。路面の高さ、段差、扉の開閉と人や荷を運ぶ姿勢まで確定したわけではない。

## 階段の断面

以前の階段の平面占有だけでは、両端の踊り場と段を納める長さが足りなかった。西の直階段へ必要な長さを取り、生活空間側へ幅を広げ、家具を東へ組み直す。上下階の高さは floor_levels、階段の段数と踏面・踊り場は stair_sections に持つ。上端・下端の横の使用面を同じ階段へつなぐ。

上階床の開口を直階段の全踏面に沿って取り、上下の天井下面の最低高さを断面案へ置く。各段と両端の踊り場の上の鉛直の空きを計算する。梁・屋根・手すりの干渉、段の端と踊り場のつながりを確認するまで描画へ進まない。屋外では回転した外周と戸口を同じ計算へ合わせた敷地案とし、隣家と道、屋根の張出しを再照合する。

## 頭上の空間と床開口

天井下面の高さは floor_levels の ceiling_elevation_m に計画する。上階は階段と踊り場の上でこの高さを下回らない屋根・梁の納まりを必要とする。床開口は上端の踊り場から下り方向へ取り、踊り場自体の床を抜かない。開口の幅は階段の有効幅と同じとし、縁を横切る梁を足して開口を塞がない。

これは断面の設計値であり、現在の描画や施工状態の実測値ではない。部屋全体の屋根形状、開口の縁の梁と手すりをこの断面へ合わせてから描画する。

## 屋根と手すりの断面案

既存の茅葺きの設定を保ち、室内の南北方向に棟を通す切妻の屋根を計画する。roof_section は屋根の外面ではなく、部材の下へ人が使える最低の面を示す。階段と両端の踊り場、寝具と衣服箱の使用面の上で、この傾斜面が必要な空間を削らないようにする。

階段の占有には両側の手すりの厚みを含め、有効幅はその内側に取る。開口の縁に手すりを立てても、踏面や立つ床へ柱を張り出させない。屋根の張出し、梁と柱の支え、手すりの端と取付けは引き続き立体と敷地で照合する。

## 隣家との敷地調整

[[building-h3]]の四人世帯の平面案と屋根が重ならないよう、敷地案を南へ寄せる。入口から道への接続も同じ移動に合わせる。実行時の建物位置や地形を変更済みという意味ではなく、窓と煙突、地面の高低差や隣家の未設計の屋根は別に照合する。


## 二人が作業する間の出入り

繕い台で準備するヘレナと炉を使うリーゼルが別々の使用面へ届くよう、両階の幅を広げて繕い台と椅子を東へ組み直す。移した収納の使用面は戸の開閉に重ならなくなったため、その収納を待つ条件を外す。戸の軌跡に残る使用面との順序は引き続き検査する。


## 現行の室内の近似と残件

水甕を木樽で描く既存の近似は、[[room-h4-1#飲用水甕の閉じた外形]] の陶器の胴・厚みのある口縁と取り外す蓋へ修正した。現行の表示用の家具の位置と占有は保ち、資料からの投影も同じ種類を使う。閉じた外形の修正だけで、作業容量と水の供給、柄杓と蓋の置場・身体・荷重と床の支持、日課が成立したとは扱わない。
