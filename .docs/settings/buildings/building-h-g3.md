# 空き家（貸家）

## 空き家としての状態

居住者はいない。居間兼台所と寝室の空室を持ち、所有者と鍵・点検と修繕の担当はまだ定まっていない。空き家を新しい世帯の寝床や常設の店として数えない。

## 平面と入居

入口から居間兼台所へ入り、寝室は独立した戸から入る案とする。家具のない現状を維持し、入居者が決まる前に架空の寝台や食卓の人数を作らない。炉と煙突・給排水と便所・換気、敷地と道・構造と外観、家具の搬入と契約・鍵と保守を設計してから入居可能とする。現行の外形へこの案が収まるとは判断しない。
