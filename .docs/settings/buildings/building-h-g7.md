# 衛兵の宿舎

## 使い手と役割

朝番の[[resident-コンラート]]、昼番の[[resident-ヘンリケ]]、夜番の[[resident-ロータル]]の三人の衛兵が暮らす。門と広場と通りを三交代で見回り、給金は町の寄り合いから受け取る。門の詰所のオイゲンたちと組んで番をつなぐ。

## 部屋の構成

1階の[[room-h-g7-1]]に炉と食卓、三人の椅子、槍立てと台所の台を置き、戸口の棚に三人の兜を並べる。2階は[[room-h-g7-2]]・[[room-h-g7-3]]・[[room-h-g7-4]]の三つの個室に分け、階段の上の廊下から別々に入る。

## 三交代と眠り

コンラートは昼過ぎから夜中まで、ヘンリケは夜から朝まで、ロータルは明け方から昼過ぎまで眠る。いつも誰かが眠っている家なので相部屋にせず一人一室とし、起きている者が眠っている者の部屋を通らない。三人が揃って食卓につくことはほとんどなく、食卓と椅子は帰った者から順に使う。

## 現状との差分

現行の家具候補は槍立て、食卓、寝台×3、椅子×3。二階建ての床は一人あたりおよそ二十二平方メートルで、ふつうの暮らしに収まる。遮光と物音、衣服の収納の容量、便所・排水・換気の配置は本資料ではまだ確定していない。
