# 農家の牧草地と入口

## 所有と使い手

[[building-farmhouse]] の農家の世帯が使う牧草地であり、カールとヴァルターが羊の見回りと給水・柵の手入れを担う案にする。飼育している個体の現行定義は entrance_review の stock_source を参照し、ここへ個体数と出現範囲の別の正を作らない。[[building-barn]] の飼料と道具、家での食事・睡眠とつなぎ、農家の生活がここだけで完結した扱いにしない。

## 現行の切れ目と棒の境界

現行の入口は西の柵の切れ目であり、閉じる戸と掛金を持つ門ではない。位置と切れ目の寸法は opening_source と rail_source の定義を正とする。元の道の終端を残しても切れ目の中央へ到達できることや、荷物と家畜が通る幅を確認したことにはならない。[[map-phanthiet#農家まわりの道の付替え案]] と一緒に入退場する面を設計する。

切れ目の中へ柵の棒を残さない。棒の中点だけを見て一本を残す判定では、端が開口へ伸びて通行判定とずれるため、残す棒の全長を切れ目の境界で切る。既存の材質と色、棒の高さと古び方を保ち、入口の修正を柵全体の新しい意匠へ置き換えない。既に省いた棒や通行判定を追加する変更とは分け、検査でそれぞれの範囲を照合する。

## 閉じた門と飼育の残件

常時開いた切れ目の修正だけでは羊の逸走を防げない。閉じる戸と支柱・蝶番と掛金、開閉時の人と家畜・道具の待機と通行、支持と荷重・地面と段差を配列とグリッドで設計してから描画する。現行の個体の移動範囲が制限されていることを、柵が閉じている説明にしない。

草と飼料・水の出どころと有限の量、飼育と給水・補修の一日、糞を回収する道具と保管・最終処理、雨と日陰・地面と疾病時の隔離、羊毛と農家の仕事への量のつながりは未設計である。全周と門を含む平面は grid を未定義のまま保ち、現行の囲いを設計済みとして自動で埋めない。


## 未配置の二重門の前室と順序

前室の局所の格子で、西を外の道、東を牧草地とする。両端に同じ開口の門を置き、外門は前室へ、内門は牧草地へ開く案にする。S はカールが前室の状態を確認して待つ床の予約であり、飼料と道具を積む収納にはしない。敷地の採用は未決定で、後述の stock_lock_site に北西の一部を前室へ分ける候補を持つ。現行の切れ目へこの図を縮めて押し込まない。

初期と終了時は両門の掛金を閉じ、全ての羊を牧草地、カールを外に置く。両門の間を同時に通せる状態を作らず、一方を開錠する前にもう一方の掛金まで閉じる。外門を開錠する前には、内門が掛金まで閉じた状態で前室に羊が残っていないか確認する。内門を開錠したら、その前の確認は無効になる。

羊は群れ全体を一点として扱わず、現行定義の個体ごとの所在を追う。内門が開く間に一頭でも前室へ入った記録があれば、そのまま外門を開けない。戸を閉じたことだけで前室を無人・無畜と推定せず、羊を牧草地へ戻して内門の掛金を閉じた後に改めて確認する。この順序はカールが世話に入り外へ戻る案であり、羊を外へ連れ出す手順ではない。

順序の検査は、実際の所在の観測や戸の開閉動作を証明するものではない。支柱と戸板・蝶番と掛金、動く戸と身体・羊の外形、通行と待機・視認、取っ手への手と力、地面と段差・道への接続、引返す羊の誘導と閉じる際の挟込みを先に照合してから描画する。現行の日課・動物の位置や通行規則には採用しない。


## 戸板と枠・待機面の平面の余地

両方の戸板と枠・金具の寸法を各 gate の leaf に持つ。外門は前室側、内門は牧草地側の枠の面より蝶番の中心を出して回す案にする。板厚だけでなく補強と取っ手の出を両面に含めた厚みを使い、蝶番を枠の端へ置いた回転で板の角が枠を削らないようにする。支持する金具と支柱の実物・力はこの平面の余地の後に設計する。

戸板の長さは格子の開口から両側の枠を差し引いて求め、取っ手はその長さの中へ置く。閉じた板から開き切るまでの全角度で、境界と両方の枠、もう一方の閉じた戸と金具、S の待機床に板が入らないことを照合する。S は戸を動かす前に使用を終える面にはせず、待つ間にも塞がない。

内門が前室の外へ開く範囲は pasture_side に有限の矩形で予約する。前室の東の縁へ接するが、敷地へは未割当であり、実際の牧草地のどこまでも空いた草地を仮定しない。枠と板の平面の干渉だけでは、板の下端と地面・高さと荷重、押す人と引く人・羊の外形、通行と待機・掛金の操作、取っ手と身体の接続を検証済みとしない。現行の描画へは採用しない。

木部は [[resident-ゴットフリート]]、蝶番と掛金・補強の金具は [[resident-ギュンター]] へ製作を頼む案とし、農家が所有してカールとヴァルターが手入れする。現物の木材・鉄と量、加工と接合・納期と費用、重さと支柱・地面の支持は未確定であり、手元に完成品があるとは扱わない。


## 開き切った一方の門を通る身体の経路

この前室は屋根付きの屋内室ではなく、二重門の間を柵で囲う区画の案である。walking は開き切った一方の門だけを通り、他方は閉じたまま保つ空手のカールの平面の経路を持つ。身体の円を同じ半径のまま全区間で掃引し、枠と金具を含む開いた板・他方の閉じた板、柵の境界を残す。S は歩ける待機床であり、身体の円全体を収める hub_m を一つだけ持つ。

外門の経路は外の床から S へ、内門の経路は同じ S から牧草地側の床へ結ぶ。戻るときは同じ静止した門の状態で逆順に使う。外と牧草地側の終点では身体の円全体が前室の外へ出る。両門の前に別の待機点を置いて、その間を移動した扱いにはしない。外の床も outside_side の有限の未配置の矩形へ限り、予約していない壁の外を歩ける床にしない。

これは前室と予約した床が空き、開いた板を所定位置に保持できるとした平面の照合である。押して開く人と引いて開く人の身体、取っ手と S の間の移動、開閉中に境界を越える所在、開位置へ保持する金具と力、羊・荷物との同時使用と誘導、敷地と地面・段差は別に照合する。実際の動物や日課へ採用した経路ではない。


## 取っ手へ戻る経路と門を越えながら閉じる動作

歩行の端点をその場で取っ手へ手が届く操作位置とはしない。operations に取っ手へ近づく経路、戸板と一緒に身体が動く姿勢、掛金を扱った後に立位置へ戻る経路を持つ。外門の内側の立位置と内門の外側の立位置は同じ S とし、外の立位置と牧草地側の立位置も walking の端点を使う。操作のたびに別の場所へ現れた扱いにしない。

入るときは外側から押し開きながら身体も内側へ進み、開位置を保持して立位置へ移る。閉じるときは立位置から取っ手へ戻り、開く側から戸を引いて閉じる。戻るときは内側から引いて開け、押し開きの姿勢を逆にたどり、身体が外側へ出ながら戸を閉じる。戸を通り抜けてから取っ手が届かない側で閉じた扱いにしない。

押し開く姿勢の body_m は蝶番を原点とし、閉じた戸に沿う方向と開く方向の座標である。姿勢の間も角度と身体が連続して変わる。引く動作は蝶番の周りの身体の円弧で定め、逆方向の動作は同じ経路を反転して使う。身体の半径は歩行と同じままにし、板と金具・枠、他方の閉じた戸、支持する床と取っ手への届きを全区間で照合する。

門を越える open と close の記録には motion を付け、身体の所在もその動作の終わりに対応する側へ移す。戸が動く間の個体の越境は stock_crossings に個体ごとに記録でき、前室へ残った羊を消さず、内門の掛金と空の前室の確認の順序へ渡す。掛金の開閉は取っ手へ近づいてから、閉じた後に扱い、立位置へ戻る経路はその後とする。記号上の状態を、途中の実際の位置と同一視しない。

これは空手の円と取っ手の平面の名目上の動作であり、開位置を保持する金具、掛金と指・腕の接触、足裏と地形・段差、荷重と力・姿勢、羊との同時使用や挟込み・観測の実装は別に照合する。実際のゲームの門や日課へ採用しない。

引く円弧の身体角は、戸板の角度を start_deg と end_deg の間へ挟む body_angle_mode とする。その範囲より閉じた側・開いた側では身体の端姿勢を保ち、取っ手への届きを照合する。掛金を両側から扱う方式と指の接触、金具を保持・解除する力の検証はこの角度の規則から推定しない。


## 牧草地の北西を前室へ分ける敷地候補

stock_lock_site は局所の格子を縮めずに町へ投影する候補の原点と、外の床に接続する道の添字・局所の接続点を持つ。現行の西の切れ目へ内門の中心を合わせると北の床が牧草地を出るため、その位置を流用しない。牧草地の北西の一部を前室へ分け、北の境界をそろえ、東の内門と操作床を残る牧草地へ接する案とする。site_status と両側の床の unassigned は実際の敷地と支持の採用が未決定であることを示す。候補の原点があることと実際の配置の完成を混同しない。

残る牧草地の柵は元の北東・南東・南西の境界を保ち、北西の前室の内門側を回る閉じた折線とする。前室の北・西と南の外側はその折線へ両端でつなぎ、共通の内門側の柵を二重に建てない。元の西の上部の柵を前室の中へ残さない。前室に回す牧草地の矩形は同じ原点と寸法から求め、草地が元の全域のまま残るとは扱わない。柵の厚みと柱の接合・高さ、実際に羊が通れない隙間の成立は別に照合する。

外の床は既存の道幅全体を受けられるように広げる。[[map-phanthiet#農家まわりの道の付替え案]] の枝道をこの床の接続点へ結び、道の終端の全幅を収める。道の途中も前室と内門側の操作床へ入れない。他の道・川、建物と屋根・畑や豚の囲いは残して照合する。候補の前室は他の建物と住民の経路の検査にも障害物として渡す。

[[building-h5]] から道へ出る経路と [[resident-アンナ]] の洗濯への往復は前室の西を通る道へ結ぶ。[[building-farmhouse]] からの接近も前室を横切らず西へ回す。道の接続点から既存の外の立位置までを同じ身体の円でつなぎ、道に着いただけで門の前に現れた扱いにしない。

現行の羊の移動範囲は候補の前室と操作床へ重なるため、stock_motion_status を unreviewed のまま保つ。描画や実行時の柵・道・動物の範囲は変更しない。草と飼料の量を減らした土地へ結び直すこと、羊の待機と誘導、地形と支持・排水、家と柵の間の手入れ・荷を持つ移動とすれ違いは未完了である。平面の候補の成功を飼育と敷地の完成に広げない。


## 全個体が世話の間に待つ面

stock_lock_site.waiting はカールが門を操作する間だけ羊が待つ位置の案であり、個体ごとの恒久的な囲いや普段の放牧範囲ではない。現行の羊を一頭も除かず、牧草地の北西を原点とするメートルの位置へ一度ずつ割り当てる。羊の頭を含む身体の円と宣言した余地を柵の内側へ収め、前室と両側の操作床・他の羊の身体から離す。中心だけを空いた点へ置いたことを収容の成立としない。

身体の寸法は `world/town/sheep-shape.ts` と現行の各個体の scale、草を食べる傾きは `world/town/livestock-graze-pitch.ts` を正とする。羊の描画も同じ寸法を使う。胴だけの半径で頭・目・脚を消さず、あらゆる向きと直立から草を食べる間の傾きについて水平の占有を求める。地図のタイルと局所のメートルは別の単位として照合する。

これは全頭がその位置に静止しているという条件での平面の余地の案である。そこへ集める経路と順序、餌や道具・人の待機、羊がその場に留まる理由と観測・誘導は未設計である。arrival_status と behaviour_status、敷地の stock_motion_status は unreviewed を保つ。所在の記録で全頭が牧草地にいることと、この待機の状態を実際に確認できることは別である。確認できないまま外門を開く実装にはしない。

全身の円には寝転び・剪毛・保定や群れの同時移動を含めない。現行の剛体の傾きで脚が実際の地面へ接すること、地形と雨・糞と清潔な待機面、草と飼料・水の量や一日の時間配分も未照合である。待機の配列を描画や現行の移動範囲へ採用せず、生活の設計の未完了を保持する。
