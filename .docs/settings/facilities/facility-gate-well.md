# 南門の井戸

## 用途と使い手

門番、倉庫で働く人、周囲の世帯が使う。外からの荷の点検と水汲みの列を分け、重い荷を下ろす場所を井戸の縁に作らない。動物の飲み水の容器を、人が汲む井戸口へ直接入れない。

門を出入りする荷車が井戸の前を横断する場合は、満水の桶を持った人が安全に待てる床を確保する。共同設備の清掃・蓋・水源の管理は広場の井戸と合わせて設計する。
