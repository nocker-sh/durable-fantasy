# 衛兵の宿舎／2階 ヘンリケの寝室

## 用途と暮らし

[[building-h-g7]]の2階にある昼番のヘンリケの個室で、本人の寝台を一つ持つ。広場の見回りから戻って夕餉をとり、夜八時から朝まで眠る。夜番明けのロータルが帰る明け方に起こされないよう、廊下から直接入る個室とする。

## 未解決の条件

窓と戸の建て付け、隣の部屋との壁の物音、衣服と首巻き・私物の区画の置き場は未照合である。
