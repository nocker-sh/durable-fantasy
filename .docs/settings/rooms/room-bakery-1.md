# マルタのパン屋／1階 店先

## 利用と配置

客の入口を南に置き、売り台の南側に待つ場所を取る。パンの棚は東壁沿いとし、棚板を室内の端から端まで渡さない。売り台の北側は店番の作業域で、北の戸から台所へつながる。西の階段は家族用であり、客の買い物に必要な通路にはしない。荷は南の入口から北の戸へ運べる。

## グリッド

一セルは半メートルで、上が北、左が西である。記号の家具はメタデータの furniture に対応する。access は家具の前で人が立つセルで、入口から到達できることを確認する。占有格子だけで扉の開閉や作業姿勢まで検証できたことにはしない。

## 建物全体との関係

[[building-bakery]] の再設計案に属する。現行の外形と自動配置を追認する図ではない。台所と売り場、各寝間と踊り場を接続し、生活に必要な設備の未解決事項を閉じてから描画へ進む。

## 売買と家族の通行

売り台の北に店番、南に買い物客の受渡し面を置く。冷ましたパンの棚の作業面は売り台の東寄りとし、西の家族用階段の使用面とは重ねない。南の入口から台所へ向かう荷は売り台の東を通す。客の待機人数と、棚へ取りに行く店番・荷を運ぶ家族のすれ違いは確定していないため、この平面だけで同時通行を認めない。

売り台を東へ長く伸ばすとパン棚との間が半メートルしか残らないため、台の長さを一・五メートルに抑える。東の通り道は一メートルとし、戸口から台所へ続ける。棚を使う間はこの通路の一部を占めるため、荷運びとの同時使用は認めたことにしない。
