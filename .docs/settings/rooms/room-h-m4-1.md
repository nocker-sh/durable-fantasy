# フェルディナントの借家／1階 居間兼仕事場

## 一人の暮らしと仕事

[[resident-フェルディナント]]が借りて暮らす一室である。地図を描く仕事、食事、就寝を一人が切り替えて使う。宿で地図を描く日課と矛盾しないよう、家の机は現地で集めた下書きの整理と写しの保管にも使う。家の机を置いたことを理由に宿へ行く日課を削らない。

## 紙と火・水を分ける配置

北東に机と紙の箱、北西に寝台と衣服の箱を置く。紙の箱は蓋をして仕事の紙と完成した地図を収め、個人の衣服や食材の収納とは分ける。地図机の東側に明かりを取る窓を設ける案とし、窓の雨仕舞いと戸を開けたときの風は外観と合わせて照合する。

調理炉・下ごしらえ・水・食材は南側にまとめる。食事を紙の上で取らないよう、中央に小さな食卓と専用の椅子を置く。室内の机を職業の売り場にはせず、地図の納品先は寄り合いとテオのままとする。

## 寝床と持ち物

寝台Bと衣服箱Cを既存の個人寝台・収納IDへ結び付ける。寝台の東側に使用面を取り、紙箱Pを着替えの収納として兼用しない。箱の容量や蓋を開く高さはまだ確定していない。

## 平面案

一セルは半メートルである。東の出入口から中央へ入り、寝台、仕事机、食卓、南の調理域へ到達する。家具の占有と使う人の床を別に記録する。一人の用途切替で使用面を共有する箇所があり、移動中の道具や椅子の動きまでは検証済みとしない。

## 屋外との接続と残る設計

飲用水は[[facility-market-well]]から自分で運ぶ案とする。水の確保を仕事仲間や水汲みの住民の無償奉仕に置き換えない。食材は市場から持ち帰り、地図は乾いた包みで納品する。濡れた外套と靴を置く場所、薪と灰、洗い水と便所の行き先は未設計である。

[[building-h-m4]]の敷地・窓・排煙と入口の高さを照合してから描画へ渡す。平面で紙と炉を離したことだけで、紙を安全に保管できる湿度や火の離隔まで確定したとはしない。
