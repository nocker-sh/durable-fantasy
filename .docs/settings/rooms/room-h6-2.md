# ヨーゼフの小屋／1階 台所兼寝間

## 利用と配置

北西の炉で調理し、中央西側の食卓で食べる。飲用水と食材は北東へ置き、斧の手入れや炭の袋詰めをする面とは分ける。土間から入る経路は食卓の東を通り、椅子をまたがずに寝台の隅へ進める。

部屋名の台所兼寝間は、東側の寝台の隅と生活を一続きに使うという意味である。この部屋にも追加の寝台があると数えない。炉は西外壁沿いに排煙し、寝床との間を煙突が横断する配置にしない。

## 未解決の生活条件

水汲みは [[facility-square-well]] との経路を設計する。便所、灰と汚水の搬出、窓と排煙、濡れた物の乾燥と火との離隔は、敷地と町全体の設計で確定する。

## 調理と食事の使用面

炉の正面と水の容器の前が食卓や食材箱に塞がれていたため、食卓と椅子を南へ、食材箱を南東へ移す。南の戸から東の寝台区画へ入る床は残す。食材を取り出す床と椅子の出入りは一人が用途を切り替えて使い、着席中の調理や食材の出し入れまで同時に成立するとはしない。
