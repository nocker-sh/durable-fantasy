# 納屋／1階 農具置き場

## 物と作業の配置

[[building-barn]] の平面案に属する。鋤と鍬の刃と柄を立てる柵、手入れ台、補修部材の棚と荷車の駐車を分ける。荷車の柄までを床の占有へ含め、置いたまま出入口と農具の使用面を塞がない。無荷の荷車をまっすぐ後退させる平面の範囲は末尾の案で照合し、荷を積んだ移動と荷の重さ、農具の刃の覆いと子どもとの分離は未照合である。現行候補の巣箱は、蜂が入った状態で農具の棚へ常設する扱いにしない。養蜂の場所と管理、空の巣箱の手入れ・保管は農家の屋外設備と合わせて別途設計する。

## 家とのつながり

カールとヴァルターが担当し、世帯の食事と六人の寝床は [[building-farmhouse]] に維持する。南の専用の戸から物を受け、隣室との戸をつなぐ。荷物を持たない身体の平面到達と、一部の二人の取出しを照合する。飼料と農具を畑・牧草地・鶏小屋へ運ぶ量と時間、敷地と段差・立体と描画は引き続き照合する。

## 空の荷車の駐車した形

C はカールが手入れする農家の荷車の駐車範囲である。今回は荷を降ろし、二輪と前側の二本の駐車脚で床へ置く姿を定義する。荷台は底板と四方の低い板を持つ。車輪は木の輪とハブ・放射状のスポークを持ち、鉄の軸が左右のハブをつなぐ。軸を荷台へ受ける木部を置き、荷台が軸の上で浮かないようにする。

左右の柄は荷台の前で終えず、底板の下から軸の上まで通す。駐車脚は柄の下を受け、車輪の接地と同じ床へ下ろす。木部と軸・柄・脚を含む形の正は `world/town/parked-cart-shape.ts` に持つ。駐車の矩形の長い辺を柄までの前後軸とし、長い辺が東西なら柄を西、南北なら北へ向ける。この室の平面案では南の専用戸と同じ南北の軸へ駐車し、柄を北の使用面へ向ける。空の荷車を柄から押して南へまっすぐ後退させ、室内の旋回と横滑りを必要としない。搬入出は南の専用の広い戸を使う計画とし、隣室への狭い室内戸は荷車の通路に数えない。全体を同じ倍率で収め、車輪だけを楕円へ縮めたり、柄を占有の外へ出したりしない。

木箱と袋を荷車の代わりに置かず、保管中の荷も自動では積まない。現行の室内投影の荷車も同じ無荷の形へ直すが、資料の新しい間取り全体を採用した変更とはしない。資料の専用戸の名目上の幅は荷車の幅を超えるが、現行の自動間取りの戸口はこの搬出の計画へ合わせていない。この資料の無荷の後退は末尾の局所の平面案で照合するが、現行の搬出経路へ反映した扱いにはしない。軸受と車輪・木部の実際の接合と強度、駐車脚を離して引く身体、荷を積んだ重心と重量・旋回と搬出、補修と日課は未照合であり、駐車した外形だけで設計ゲートを通過させない。


## 空の荷車の後退と屋外の待機範囲

カールが無荷の荷車の北の柄を持ち、先に南の両開き戸を開いて保持してから、軸を変えずに南へ押す案とする。駐車脚を床から離す持上げと姿勢・力は別に照合し、荷を積んだ状態へ流用しない。駐車の占有から全経路を連続する矩形で掃引し、柄の北には身体の円と取扱いの間隔を残す。他の家具を動かして経路を空けた扱いにしない。

南の戸の先に荷車と操作者が完全に出て止まる局所の矩形を予約する。exterior_apron は確定した敷地へ未割当の案であり、[[building-barn#農家まわりの道と同時に割り当てる敷地案]] には投影して照合するが、実在する屋外の床とは数えない。部屋の外はこの矩形だけを平面検査へ含め、壁を抜けてよい領域や無限に空いた屋外を作らない。開いた戸板と金具・戸枠を残して荷車と身体の全区間を照合する。敷地との接続、段差・地盤と勾配、戸の開閉を行う身体と保持金具、持上げ・重量と強度・日課が未完了のため、計画矩形を実行時の間取りへ採用しない。
