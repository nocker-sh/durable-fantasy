# マティアスの小屋／1階 居間兼台所

## 食事と帰宅

[[resident-マティアス]]が一人で食事と調理に使う。入口の脇に杖と靴を下ろす場所を取り、泥の付いた道具を食卓や寝台の脇へ持ち込まない。食材と飲用水は蓋付きの容器で持ち、靴の泥を払う動作と食事の準備は同時に行わない。手洗いと泥の搬出を含む清潔な動線はまだ確定していない。

## 家庭の炉と羊の仕事

炉は本人の調理と暖房に使う。羊毛の袋詰め、搾乳、チーズ作りをこの家庭の食卓に自動的に割り当てない。羊毛の乾いた保管場所と乳を扱う清潔な面は、羊のいる仕事場と合わせて別に設計する。既存の家具候補に羊毛の袋があることだけを理由に、家の通路へ積まない。

## 配膳と部屋の接続

炉、下ごしらえ台、水、食材箱から食卓へ移る。一人が作業を切り替えて使う面が重なり、配膳中に椅子を使う動作まで同時に成立したとはしない。寝台区画は北の戸から入り、外の戸から寝具の使用面へ直接入る構成にしない。部屋の方角は室内図の方角であり、屋外では[[building-h7]]の回転を適用する。

## 残る生活の設備

飲用水は[[facility-square-well]]から本人が運ぶ案とする。仕事着、薪、灰、洗い水と便所、窓と排煙の設計は残る。戸と椅子の可動域、杖や容器を持った姿勢も平面の到達検査とは分けて照合する。

## 戸口の内側

下ごしらえ台が寝台側の戸口の内側の片側を塞いでいたため、西へ寄せる。戸口の表示幅だけで判断せず、その内側へ人の幅を持つ床を続ける。
