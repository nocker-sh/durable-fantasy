# ヴィルヘルムの家／1階 居間

## 二人の食事と普段の席

[[resident-ヴィルヘルム]]と[[resident-ゾフィー]]が食卓を囲む居間である。台所は東の戸でつなぎ、調理した物を本棚や寝台の上へ仮置きして配膳する構成にしない。南寄りに暖炉と揺り椅子、北側に本棚とゾフィーの鉢植えを置く。

## 暖炉と本・植物

暖炉の煙突は南の外壁の外へ通す案とし、二階の踊り場や寝台を煙突が貫通する配置を避ける。本棚と鉢は火口から離し、水や土を本の上で扱わない。揺り椅子を使う動きと火との離隔、鉢の水受けと本の保管はまだ立体で照合していない。

## 階段と玄関

西に直階段を置き、二階の[[room-h1-stairs]]から共用の[[room-h1-landing]]へ上がる。玄関は階段の下端の南に余地を取り、戸と枠・板厚と操作する身体の動きを別に持つ。室内図の南の玄関は、屋外では建物の回転により西を向く。

## 平面案

一セルは半メートルである。


食卓・階段・戸に到達する平面と、座る・揺れる・配膳・戸を動かす途中の立体を区別して検証する。

## 戸を扱う身体と作業の順番

階段の下端の人が室内か上階へ抜けてから戸を扱う。階段口に人を待たせたまま回転しない。炉に燃料を入れる作業を終えて手を離し、前を空けてから戸を扱う。戸板の回転とは別に、開閉する身体の円弧と家具の使用面を照合する。同時使用できる面としては扱わず、待つ人の位置と道側からの操作・人の移動の連続は別に照合する。

## 二人の身体と食卓

ヴィルヘルムは北側の椅子 A から南へ、ゾフィーは南側の椅子 B から北へ食卓を向く。`household_meal` で常用の席を一人ずつ割り当て、二人の椅子を同じ席として数えない。二人の座面は同じ高さとし、元の座る姿勢と実際の靴底に合わせる。身体や靴を縮小して床へ合わせない。

着席した元の各描画姿勢で、両方の靴底と床、描画する膝の衣服と靴から天板・脚までの離隔を照合する。卓の部材は描画と同じ断面を使い、膝の半径や靴の太さは身体から読む。椅子を引く動作と着席・立上り、スカートや上半身と椅子の背・卓、配膳する手と同時利用は引き続き照合する。

台所の一人分の鉢と匙は本人の席へ配膳し、使い終えた物は [[room-h1-2]] の洗い桶へ戻す。食卓の東側を配膳用に保ち、階段や揺り椅子を配膳の仮置き台にしない。戸を通る身体と荷物、卓へ置く手と食事の日課は未照合である。

## 卓上の一人分と台所の同じ食器

`meal_place_settings` は [[room-h1-2]] の個別の鉢と匙の ID を参照し、寸法や別の食器を居間へ複製しない。ヴィルヘルムの一式は北側の椅子 A の前、ゾフィーの一式は南側の椅子 B の前へ置く。座席の割当と食器の持ち主を一致させ、一つの鉢や匙を二人へ同時に割り当てない。

卓上の位置は天板の北西からの x・z とする。鉢は口を上へ向けて底を天板へ置き、匙は横に寝かせる。外形が天板の内側へ収まり、食器どうしに隙間があることを同じ実寸で照合する。この配置は台所の収納から卓へ運ぶ途中や、本人が手を伸ばす動作を完了した意味にはしない。使い終えた食器は同じ ID のまま台所へ戻す案とし、居間と水切りに同時に出現させない。

## 卓へ手を出す準備姿勢

卓上の元の位置では、元の着席姿勢の肩を動かさずに腕を解くと、二人とも物の上の準備点へ届かなかった。座面の上で座る位置を少し前へ出し、鉢を本人側の卓の縁へ寄せる。匙は本人の右手側へ分け、長辺を南北へ回して鉢と重ねない。脚も内側へ寄せ、同じ二人の靴と膝を全着席フレームで再照合する。座面や身体・靴、器の実寸を縮小して距離を合わせない。

各人の `reach_review` は本人の腕と、元の骨格の座標で肘を向ける `pole`、物の上端から掌の基準点までの `hover_above_m` を持つ。目標は物の外形の中心の真上とし、器と接触する位置や握る位置ではない。元の腕の長さを保って肘と手首を解き、足と腰・反対の腕を変えない。肘は外側かつ上へ逃がす案とし、卓と全員の食器を残したまま両腕・掌と袖口の囲いを照合する。

照合するのは各描画フレームから作る準備姿勢である。元の着席フレーム自体が時間とともに変わる動作、物へ手を下ろす工程と指・手首の接触、上腕や肩・椅子との干渉、物を掴んで使う動作は未照合のままとする。

## 膝元から右脇へ手を引く最初の区間

`reach_review.withdrawal` は、元の着席姿勢から本人の右脇へ手を引く最初の区間だけを持つ。`seat_target_m` の x は座る位置から本人の左を正、z は前を正とし、y は室内の床からの高さとする。水平の位置は本人の向きに合わせて回す。掌は低いまま本人側へ引き、天板の下からそのまま上へ通さない。

各元の着席フレームを固定し、開始する掌の基準点と肘をそのまま読み取る。この区間の肘の向け先には元の肘の位置を使い、開始点で元の肘と手首が再現されることを検査する。肩と根元を動かさず、元の腕の長さで掌の基準点を直線に動かす。卓と全員の食器は残し、反対の腕も元の位置のままとする。

両端だけを調べず、区間全体へ腕が届くことと、肘の移動量の上限から腕・掌と袖口を含む囲いの全区間の離隔を照合する。証明できない区間は分け、限度まで分けても未解決なら通さない。これは身体と椅子・衣服との干渉や、時間と速さを照合した意味ではない。

## 右脇で肘を切り替えて卓上へ寄せる区間

`reach_review.elbow_swivel` は引戻しの終点で掌の基準点を固定し、肘の向け先を開始する肘から `lift.pole` へ連続して変える。`lift.pole` を省略する案は `pole` を共用する。引戻しと同じ骨格・目標を共有し、姿勢を別の候補へ瞬間的に飛ばさない。掌へ向かう軸に対する肘の向け先の射影が消える区間は、曲がる向きが定まらないため拒否する。

`reach_review.lift` は同じ終点から右脇で手を持ち上げる目標を持つ。持上げの終点で掌を止め、肘の向け先を `pole` へ連続して切り替える。`advance` の位置へ前進してから、本人の各食器の上方の準備点へ寄せる。卓だけへ合わせた以前の高い肘の向け先は本人の部材を避けられなかったため、持上げと前進の向け先を分けた。身体や袖の太さ、卓と器の寸法、検査の余裕を減らして解消しない。

元の着席フレームごとに身体を固定し、引戻し・掌を固定した肘の切替え・持上げ・上方への前進を同じ座標で接続する。全区間の到達、卓と全員の食器、動く前腕・掌と袖口から本人の他の描画部材への連続した離隔を照合する。時間・加減速、上腕と肩・椅子、指と手首の接触、準備点から物へ下ろして掴む工程は未照合である。実行時の食事動作へは採用せず、各工程の状態も未確認のままとする。


## 元の着席姿勢の前腕と脚の食い込み

元の着席姿勢について、右前腕と掌・袖口を本人の他の描画部材へ照合すると、二人とも脚の衣服との離隔を満たさない。外接範囲の重なりだけではなく、元の描画の符号付きの面の内部に共通の点があることを確認した。卓と食器への離隔が通ることは、この開始姿勢が全身として成立することを意味しない。

検査は `world/scene/figure/get-forearm-self-clearance-error.test.ts` に再現を持つ。手を外と上・前へ移した固定長の候補は前腕の離隔を満たすが、支えと自然な休み方、上腕と肩、左右の手、卓と椅子、元の着席動作との接続を設計していない。この候補は元の姿勢や実行時へ採用せず、開始姿勢の修正と全工程への再照合を未完了に残す。


## 資料から作る両手の開始姿勢

`reach_review.rest` は左右の掌の基準点を椅子の位置から測る `seat_target_m` と、元の骨格の座標で肘を向ける `pole` を持つ。両手を膝の外側へ下げる開始姿勢とし、膝の衣服を細くして元の手を通す代用はしない。肘を高く横へ張る最初の案から、手を下げて肘も下向きに曲げる案へ直した。

二人の全着席フレームで両腕の骨長と肩・脚・腰・根元を保ち、開始する前腕・掌と袖口を本人の他の部材へ照合する。卓と全員の食器への離隔も同時に照合する。引戻しはこの同じ開始姿勢の掌と肘から始め、反対の腕も資料の位置に保つ。片手だけ直した候補を、二人の開始姿勢の解消と混同しない。

この変更は本室の設計案へ適用する。元の着席クリップ自体や、資料のない住民の姿勢を一律に変更しない。開始する固定姿勢の前腕の離隔は解消したが、上腕と肩・椅子、手を支える休み方、着席と立上り、引戻し以降の上腕と肩を含む全身の離隔、指・手首と時間・食事の日課は引き続き未照合である。部屋と建物の設計を終える前に実行時の姿勢へ採用しない。


## 卓と身体を避ける前腕の準備経路

前腕の自己干渉を照合すると、以前の高い肘の向け先は持上げの途中で本人の部材を避けられなかった。卓を座る身体の肘の高さへ合わせて低くし、器を本人から少し前へ寄せる。器と袖・掌の実寸、検査の余裕を減らして通す代用はしない。椅子の高さと靴の接地・膝の離隔も同じ変更で再照合する。

準備は開始姿勢から低く引き、掌を固定して持上げ用の肘の向きへ変え、本人の右脇で持ち上げる。その終点でもう一度掌を固定し、前進用の肘の向きへ変える。`advance.seat_target_m` は身体の前へ出す位置であり、ここから本人の各食器の上方の準備点へ寄せる。脇から器へ斜めの一線だけで寄せ、頭や衣服の近くを横切る代用にしない。持上げの肘の向きと、前進の向きは別に資料へ持つが、切替えは固定した掌で連続して検査する。

両手の開始位置、引戻しと肘の切替え、持上げと前進、物の上方への移動まで、各元の着席フレームを固定して到達と前腕の連続した離隔を照合する。動かす前腕・掌と袖口から、本人の他の腕、衣服、頭や髪を含む固定した描画部材、卓と全員の食器を避ける。動かす上腕の肩への付根と自己干渉、椅子や時間の変化、指と手首の接触、日課の採用は別の未完了である。


## 椅子の枠と座面の支持

椅子の座面、背もたれ、四本の脚、足置きの部材は `world/town/get-chair-sections.ts` から描画と照合へ共用する。向きが変わっても、座る位置だけを回し、背もたれや脚を元の場所へ残さない。素材と表面の細かさは描画側に置き、部材の寸法を描画だけで別に決めない。

`seated_body_review.chair_frame` の範囲は背もたれと四本の脚である。二人の全着席フレームで、元の姿勢と資料の開始姿勢の身体の全描画部材を照合する。男性の以前の幅では衣服と前脚の離隔が未解決だったため、本人の衣服へ合わせた幅へ直した。椅子は元の家具の格子の中へ収め、身体や脚の太さを減らして通す代用はしない。

座面は身体を支える部材であり、枠の離隔だけで支持を証明しない。以前の男性の描画には、立位の形を残した衣服の面と座面の内部に共通する点があった。現在の裾の修正と検査の範囲は [[room-h1-1#男性の裾を腿へ沿わせる]] にある。衣服を部材の照合からまとめて除外したり、座面へ入ることを許可したりして解決済みとしない。座面の支持と女性の衣服、足置きの接触、着席と立上り、準備動作中の椅子への全身の連続した離隔は未解決であり、部屋と椅子の設計の状態は未確認のままとする。


## 男性の裾を腿へ沿わせる

男性の胴衣は、立った時の腰から下の部分を着席時には腿の前へ回す。上着の裾も同じ二つの区間へ分け、前開きと裏地、裾の縁を保つ。元の裾までの長さを腿に沿う区間へ使い、裾の幅を椅子へ合わせて削らない。椅子の部材で衣服を切り取る方式にせず、腰と膝の姿勢から布の形を組み立てる。

腿に沿う部分は、元のズボンの支持に使う深さまで上下へつぶれる断面とする。女性のスカートとローブ、立位・歩行・運搬と膝をつく時の衣服はこの変更の対象にしない。衣服の色と材質、骨格と腕・足、座る原点と椅子の実寸を変えて離隔を合わせない。

`seated_body_review.garment_seat` は本室では男性の胴衣と上着の裾、ズボンを対象とし、本人を明示する。全着席フレームの実際に描く面を座面の部材へ照合する。支持の圧力や身体全体の接触、女性の衣服、着席や立上りの連続した動作の証明ではない。元の衣服と座面の内部の共通点は、当時の立位用の衣服を着席の骨格へ当てた再現として保持し、現在の描画からは取り除く。


## 座面へ接する腿の衣服

座る時のズボンは腿の下側を支持面に沿わせる。元の丸い断面を膝まで下げた形では、男性の腿の前側が座面の前端へ沈んでいた。腰の高さと靴底、座面と床を動かさず、腿の下側だけを既存の支持高さで平らにする。膝から下の脚は元の断面を保ち、板の高さで脚全体を切らない。

支持面は身体の腰と衣服の深さから作り、椅子の形状で身体を切り取らない。この修正は座った腿の衣服の形を対象とし、体重の配分や座り心地の証明ではない。女性の重ねたスカートにも座面への重なりが見つかった。修正と照合は [[room-h1-1#座ったスカートの布の経路]] に続く。


## 座ったスカートの布の経路

腰から尻、水平な腿の上、膝の前で下へ垂れる裾の順に布を分ける。元の立位の腰から裾までの長さをこの経路へ配分し、短い裾は膝より手前で終える。長い衣服ほど膝の前に垂れる部分へ長さを回す。座面を避けるために裾幅を縮めたり布を消したりせず、腿の上では断面の上下、膝の前では前後を平たくする。身体の腰と膝から形を決め、椅子の形で切らない。

上のスカートは前開きと元の幅、少し短い裾を保つ。下の白い縁は元の裾の前後にまたがる帯とし、衣服全体を白く覆う形にしない。前掛けと既存の色、縁の模様は同じ布の経路に沿わせる。立位と膝をつく形は保つ。体重と圧力、着席と立上りの時間を含む動作は別に設計する。


`seated_body_review.skirt_seat` は `skirt_layers_and_trousers` の範囲でゾフィーを明示する。描画が返す基布・重ね布・白い縁と左右のズボンを、全着席フレームの実物の座面へ照合した。以前の傾いた重ね布の内側へ座面が入る点は再現として保持する。板を上げたり下腿まで伸ばす案、衣服の種類に合わない照合を拒否する。支持力・圧力、時間を含む着席と立上り、食事の実行時への採用は未完了のままとする。


食卓へ並べる器は [[room-h1-2]] の meal-dishes の組を source_group で参照する。その組の全ての鉢と匙を本人の席へ一度ずつ割り当て、別の茶器の組を同じ食事に無条件で並べない。茶の杯の卓上の位置と食事との入替えは [[room-h1-1#茶の杯を置く席と食事からの入替え]] に分ける。杯の運搬と飲む動作は未照合である。


## 茶の杯を置く席と食事からの入替え

`tea_place_settings` は [[room-h1-2]] の tea-cups の組の同じ二つの杯を、食事と同じ本人の席へ割り当てる。取っ手を含む外形を卓の囲いへ使い、寸法を居間へ複製しない。北の席の杯の取っ手を西、南の席の杯の取っ手を東へ向け、本人の右側へ出す。位置は回転後の囲いの北西とし、卓上の局所座標で持つ。これは取っ手を持つ指と手首の成立を意味しない。

食事と茶の配置は同時に使わない。食事の鉢と匙を全て台所へ戻し、卓を清潔にして乾かしてから茶の杯を置く。茶を終えた杯も台所へ戻し、天板を清潔にしてから次の食事の器を置く。元の器の乾燥と収納は台所の同じ組へ戻し、居間へ別の杯を常設したことにしない。

照合するのは卓上の占有と各人の割当である。支度台から卓への運搬、杖を含む手と身体・熱・湯の量、着席と杯を持って飲む全身の動作、回収と洗浄・乾燥の所要時間と日課は未照合であり、食事の前腕の準備経路の通過を茶の動作へ流用しない。
