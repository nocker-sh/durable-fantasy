# インゴとカルラの家／1階 居間兼台所

## 用途と暮らし

[[building-h-g8]]の地上階で、炉と台所の台、三人の食卓と椅子を持つ。三人は夕方に揃って戻り、同じ食卓で夕餉をとる。カルラは食卓で運んだ荷の書き付けを確かめる。

## 戸口と仕事の道具

西の戸を入った土間に水甕と薪入れ、木箱を置き、荷縄の束を壁に掛ける。汗で湿った肩当ては炉のそばで乾かし、寝室へ持ち込まない。倉庫の預かり荷は家に置かない。
