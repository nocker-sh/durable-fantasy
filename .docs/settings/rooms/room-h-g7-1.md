# 衛兵の宿舎／1階 居間兼台所

## 用途と暮らし

[[building-h-g7]]の地上階で、炉と台所の台、三人の食卓と椅子、槍立てを持つ。帰った者が炉の火を足して食べ、次の者の分を鍋に残す。食卓は三人の席を持つが、三人が同時に座る前提にしない。

## 戸口と装備

北の戸を入った土間に水甕と薪入れを置き、戸口の棚に三人の兜を番の順に並べる。槍は居間の壁際の槍立てへ立て、寝室へ持ち込まない。磨きかけの防具と交代の刻を書いた石板は、眠っている者を起こさずに確かめられる1階に置く。
