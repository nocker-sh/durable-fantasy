# 共同の作業場／2階 屋根裏の物置

## 軽い共用工具の物置

[[building-h-c2]] の屋根裏で、乾いた共用工具、修理待ちの軽い部品、掃除と手入れの道具を分ける。[[resident-ゴットフリート]] が点検する案とする。長材や炭、大量の原料の置場として数えない。利用者の未完成品を期限なく預かる倉庫にも変えない。

## 運ぶ量と屋根

[[room-h-c2-upper-stairs]] から棚へ進み、荷を持ったまま戸を扱う範囲を照合する。棚の奥行と頭上の高さの静的な検査とは別に、床と梁の荷重・棚の固定、屋根の漏れと灰・湿気、工具箱の重さと持つ姿勢が未照合である。

現行の敷地と外形への収容、構造と給排水・便所、日課と立体の照合を終えるまで描画へ採用しない。
