# ヤコブとエルザの家／1階 土間（網と桶）

## 濡れた仕事と家庭の入口

川と浜から帰ったヤコブとパウルが荷を下ろす土間にする。網は水を切ってから仮掛けし、魚桶には蓋をして食材や清潔な衣類と接触させない。魚の処理や売り場を家庭の食卓へ移さない。魚の洗浄と網の乾燥は仕事場の資料で別に設計する。

エルザの家庭用洗濯桶は自家の衣類に使う。客の洗濯物と魚の水、飲用水を同じ桶で扱わない。洗濯の仕事は既存の日課が指す場所で行い、家庭の桶だけで仕事の設備が足りることにしない。土間で靴と濡れた上着を下ろし、東の台所へ進む。西の階段は両親の寝室へ上がる。
