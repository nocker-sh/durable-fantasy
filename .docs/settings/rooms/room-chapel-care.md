# 広場の礼拝堂／手当ての小部屋

## 手当てと休息

本堂から直接入り、横になる台と修道士が立つ側を分ける。これは短い手当ての台であり、住民の普通の寝台や宿泊の枠として数えない。清潔な布と道具の収納、使用した物の蓋付きの受け台を別々に置く。

洗浄・乾燥・補充と水・汚水の経路、患者と同伴者の立つ場所、視線と戸の開閉は未設計である。収納を分けたことを衛生や治癒の仕事全体の確認済みという意味にしない。病人がいるときの祈りと記録の仕事の切替も日課と照合する。

## 平面案

一セルは十四センチメートル。本堂の既存外形へ合わせ、外壁と室内の仕切りを区別する。戸口は同じセルで隣室へつなぐ。
