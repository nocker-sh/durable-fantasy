# ヴィルヘルムの家／2階 ゾフィーの部屋

## 私室と共用の動線

[[room-h1-landing]]から直接入る本人の寝室である。他人の寝室を通り抜けて自分の寝台へ行く構成にせず、入口から寝台の長辺と衣服箱に立てる床を取る。寝台と個人収納の固有IDは本人の資料と相互に対応する。

## 寝床と持ち物

寝具、衣服と首巻き・私物を自分の場所へ収める。食材・灰・汚水や貸家の荷物を私室の収納へ積まない。屋根の下面と立つ場所の高さを確認し、梁、換気と暖気、夜の灯り、着替えの目隠しを別に設計する。

## 平面案

私室の戸を開ける途中や寝具を広げる姿勢、箱の容量と開閉はまだ確定していない。

## 寝台の骨組みとマットレス

ゾフィーは北を頭にして横になり、西の長辺から寝台へ出入りする。庭と夜市の荷は共用部へ分け、土の付いた道具や作業着を寝具へ置く日課にしない。着替えと衣服の手入れ、寝具を清潔に保つ動線は続けて設計する。

骨組みはゴットフリートへ頼み、ヨーゼフから木材を受け取る案とする。四本の脚と四辺の枠、床板でマットレスを受け、頭側の板を北へ置く。格子の寝台の占有と bed の厚み・高さから同じ部品を作り、描画だけに別の寸法を持たせない。

マットレスはマティアスからの羊毛を洗って乾かした詰物とし、ベルタの織った毛織布をマグダレーナが仕立てる案とする。羊毛の処理量と手入れの工程はまだ照合していない。枕と掛布は [[room-h1-4#整えた寝台の枕と掛布]] の別の持ち物へ結ぶ。替えの寝具と、畳んだ収納・清掃・乾燥と交換は別に設計する。骨組みとマットレスが描けることは、寝室全体と睡眠の日課の完成ではない。

## 整えた寝台の枕と掛布

bed の linen は、本人の寝台に属する枕と掛布を固有 ID の配列で持つ。寝台 ID と種類を結んだ ID を使い、別の人の寝具を同じ物として数えない。位置はマットレスの頭側から足側、頭側を向いた面の左から右へ測り、寝台の向きを変えると同じ基準で回す。枠の板や頭板を寝具の支持面へ含めない。

枕は頭側へ載せ、掛布は足側を覆う整えた形とする。枕と掛布は重ねず、それぞれ全体をマットレスへ載せる。枕は毛織布の側へ乾いた羊毛を詰め、掛布は毛織りの一枚として、同じ織手と仕立て手・羊毛の供給元へ結ぶ。掛布の描画は既存の青い布の素材を使い、寝具だけ別の配色へ作り替えない。

これは人が横になる前の静止した形である。身体を掛布へ入れる動き、寝返りと起き上がる時の形、畳んで収納する寸法、替えと手入れの水・場所・時間は未設計であり、寝具を配置しただけで睡眠の日課を完了しない。

## 衣服箱の内寸と持ち物

衣服箱はゴットフリートに依頼し、ヨーゼフの木材を用いる案とする。格子の占有を外寸とし、板厚と蓋を除いた内側へ personal_storage の packing を置く。位置は内側の北西の底を原点に、西から東、底から上、北から南の順で測る。箱の外側の容積を収納量に数えない。

替えの衣服一組、替えの首巻き一枚、本人の押し花の包みを別々の固有 ID と外包寸法で記録する。いずれも箱の底に直接置き、他の包みを支持台へ扱わず、互いに間隔を空ける。衣服を着ている状態と収納中の替えを同じ物として二重に数えない。これらは畳んだ寸法の案であり、衣服の仕立て、私物の紙と包みの調達・防湿は続けて設計する。

寝台上の枕と掛布はこの箱の中身へ含めない。替えの寝具や畳んだ掛布を追加する場合は、実際の寸法で再配置する。空いた容積だけで追加可能とは判断しない。汚れた作業着、土の付いた道具、食材を清潔な衣服へ混ぜない。

閉じた箱への静止した収まりだけを照合し、蓋の開閉と仮置き、衣服を取り出す手・身体と着替えの動作は未照合である。衣服箱の描画と日課への採用もまだ行わない。

## 衣服箱の蓋の経路

衣服箱の蓋は蝶番で回さず、箱から外す一枚板の案とする。閉じた位置から真上へ持ち上げ、水平のまま南へ運び、箱の南側の専用の受け台へ下ろす。rest_center_m は室内の北西の床を基準とする板の中心と下面の高さであり、箱の内側の座標とは分ける。閉じるときは同じ経路を逆にたどり、同じ蓋を元へ戻す。

底と側板、衣服・首巻き・私物の包みは箱に残す。移動中の蓋を薄い線へ置き換えず、板の厚み全体を、箱本体・中身・壁と他の家具へ照合する。他の家具の未確定の高さは通れる空間に数えず、床から天井までの障害物として保守的に扱う。建物の階の高さは使うが、未設計の梁や屋根の下面まで照合済みとはしない。

これは板だけの連続した平行移動案である。両手の把持と身体、本人の支持、受け台の横で衣服を取り出す姿勢、蓋を持ち上げ直す手と手入れは続けて設計する。蓋の経路が通ることを人が使えることの代わりにしない。

## 蓋の縁へ届く本人の低い姿勢

本人の実際の体格では、立った姿勢から今の蓋の西の縁へ両手を下ろす案は届かない。腕や肩を伸ばす補正を入れず、既存の低い姿勢から右膝と靴の接地を解く候補を比較する。骨の長さと本人の体格を保ち、旧案の箱の縁の二点と、現在の木の取っ手の横棒の二点を両手の到達先として比較する。

reach_review は同じ蓋の各端の状態だけを比較する未解決の候補である。身体の位置はその状態の板の中心から指定するため、各端に身体を置けても、その間を膝で動いて運べることを意味しない。旧案の床に下ろした板の縁を拾い直す到達は成立しなかったため、現在は専用の受け台へ置く案へ改める。台への到達だけで日課へ採用しない。

掌と板の縁の接触・指の逃げ、重さと力、膝へ入る・立ち上がる動き、箱と衣服・脚の離隔、本人の身体の支持は未照合である。静止した腕の到達だけでこの低い姿勢を日常の動作に指定しない。受け台の高さと保持方法はこの不成立を踏まえた案であり、身体と荷重を続けて照合する。

## 衣服箱の蓋を受ける低い台

R は本人の衣服箱の南に置く専用の受け台であり、箱と同じ木材の供給元と木工師へ依頼する。天板と四本の脚を持ち、蓋の板全体を天板で受ける。板の中心の高さだけを合わせず、天板の端からはみ出さないことと、天板・脚に移動中の蓋が入らないことを照合する。箱と台の西側は同じ本人が順に使う床とし、蓋を運ぶ最中に別の人へ重ねて割り当てない。

受け台は蓋のために空け、衣服や売り物・食材を常置しない。箱の中の容量を増やしたことにも数えない。床に置いた板を拾い直す不成立を解消するため、板の下面が閉じた位置と同じ高さになる天板を持つ案とする。旧案の床への仮置きと不成立の検査は残し、台が無いのに高さだけを設定した案は通さない。

本人の低い静止姿勢で台上の縁へ届いても、掌と板の接触、板を持つ力、移動中の膝と靴・衣服、本人の立上がりは未照合である。台を置いたことで部屋全体と日課の設計を通過にしない。

腕の到達とは別に、壁と寝台、箱の底・側板と収納物、受け台の天板と脚を固定した障害物として本人の全ての描画部位へ照合する。蓋を持ち上げた途中の二つの端は固定家具を避けるが、縁を直接つかむ旧案の閉じた箱の上縁と台へ置いた終点では腕の離隔が成立しない。腕や袖口を除外して通さず、旧案を否定例として保持する。現在の木の取っ手へ到達先を上げる案では全ての端で固定家具を避ける。動く蓋・取っ手と掌の接触はこの検査と別に残す。水平な天井も本人の頭と髪・衣服の上限へ照合するが、未設計の屋根や梁を補完した扱いにはしない。

## 蓋の西側の木の取っ手

蓋に属する木の取っ手を本人の箱 ID へ結び、箱と同じ木工師と木材の供給へ依頼する。北南へ延びる横棒を二本の支柱で板へ接合し、板の西寄りへ置く。支柱が板からはみ出さず、取っ手だけが宙へ浮く形にしない。接合の強度と荷重は別に照合する。

取っ手の位置は板の中心から、横棒の向きと奥行の順で指定する。箱の高さは取っ手の頂部までを含み、内部の容量は取っ手の高さを引いた板の下面から求める。取っ手を付けても、元の底と側板・蓋の板と収納物を変えず、握る高さの分を収納量へ追加しない。

到達先は描画と移動検査に使う実際の横棒の内部の二点から求め、板から無指定に浮いた目標を使わない。取っ手の支柱と横棒は同じ蓋と一緒に全経路を移り、箱の中身を動かさない。縁を直接つかむ旧案の否定例と、床から拾い直せない旧案も保持する。

低い静止姿勢では全ての端で横棒へ両手が届き、箱の上縁・受け台の天板と脚・中身と壁から全ての身体部位が離れる。これは掌が横棒を正しく囲むことや、動く蓋・支柱・横棒と腕の離隔、荷重と握力、膝へ入る・立上がりと身体の支持、連続した運搬を証明するものではない。静止した掌の接触と可動部からの離隔は [[room-h1-4#横棒全体を囲む掌の静止した接触]] で別に照合する。

## 横棒全体を囲む掌の静止した接触

木の横棒の実際の断面の全ての角を含む囲いを、本人の接地した人物座標へ移す。掌が囲む範囲を、棒の一部だけへ切り詰めて扱わない。肘は横棒に垂直な掌を通る平面へ置き、上腕・前腕の長さと肩、靴と膝の接地を保つ。曲げる側の指定は grip_review の elbow_poles にあり、板へ腕が下がる側を無指定に採用しない。

棒全体が元の掌の内側の範囲へ収まり、袖口と手首の面より前にあることを照合する。掌や腕を広げる補正は使わない。この接触の証明がある横棒だけを掌が触れる物とし、上腕には別の離隔を求める。頭・髪・胴・衣服・脚は横棒も避け、蓋の板と支柱は腕・袖口を含む全ての部位を避ける。

高く持ち上げる旧案では頭まわりの離隔が通らないため、板が箱と受け台を越せる高さへ持上げ量を抑える。旧案の不成立の検査も保持する。現在の持上げ・水平移動・仮置きの各端は、同じ身体のまま固定家具と動く板・支柱・横棒の条件を照合する。通常の設定検査もこの宣言した静止した接触案を検査する。

これは静止した各端の接触と離隔の照合であり、その間の連続した骨と掌の動き、膝へ入る・立上がりと身体の支持、握力と荷重、滑りと接合の強度を証明するものではない。身体が端の間を飛んで移る日課へは採用しない。

## 蓋の上下の標本と床を滑らせない支持

持上げと台へ下ろす区間の途中は、端と同じ板・支柱・横棒を元の経路の位置へ置き、同じ本人の骨長と掌の接触を解く。端とは別の人物や補正した板を作らず、箱の底・側板と中身を残す。motion_review の標本数はこの有限の確認の指定であり、標本間の全区間を証明する数とは扱わない。

靴の実際の丸い底と、衣服を含む指定の膝の接地点を室内の同じ座標で比較する。上下の区間は両靴と右膝の位置を保つ。人物全体を床に沿って平行移動するだけの横移動は、足と膝の点が床の別の場所へずれるため拒む。接地点の高さが床にあるだけで、その場に足や膝が残ることの代わりにしない。靴は最下点だけでなく、描画する踵から爪先までの丸い形全体を室内座標で固定する。最下点を軸に回す案も、支持を外した足運びがない限り拒む。

横へ運ぶ足と膝の順序、支持を外して次へ置く区間、左右と前後の姿勢の接続は未設計である。現在の途中の標本をつないだだけで蓋を運べる日課へ採用せず、横移動の全区間と自己離隔、荷重と支持を続けて照合する。

## 枕の側布を交換する裁断案

本人の枕は羊毛の詰物を保持する内袋と、交換する外側の側布を分ける案とする。pillow_cover_cutting は使用中と替えの側布をそれぞれ一枚分とし、同じ枕の外包から上下面・長い側面・短い側面を各二枚求める。各辺へ縫い代を加えた六面を切り出し、厚みを無視した平たい二枚だけで詰物を包める扱いにしない。裁断面の配列は仕上がりの枕から寸法を求め、本人の枕を小さくして布へ合わせない。

この原布は掛布の原布と別の固有 ID を持つ。出所は sleeping_materials の羊毛の供給者・織手・仕立て手に従うが、必要量と工程の受渡しはまだ成立していない。内袋と詰物、側布の実際の厚み・角の縫目と着脱口はこの六面の平面配置には含めない。枕の外形が維持される実物の適合を照合してから描画へ進む。

替えの側布の置場の案は [[room-h1-4#替えの枕の側布を分ける上面の区画]] に分ける。原布の cloth_thickness_m は裁断片の名目上の体積を求めるための仮の厚みであり、実物を測った値ではない。側布の実際の折返しと包み、使用後の側布を分けて洗い乾かす場所、交換する手と日課は未設計である。使用中の一枚を外した間に汚れた側布へ詰物を直置きせず、内袋の衛生と一時的な置場も続けて設計する。


## 替えの枕の側布を分ける上面の区画

spare_pillow_cover は本人の枕の替えの側布だけを、前面収納の上面の北寄りへ置く案である。掛布の区画と重ねず、元の衣服・首巻き・私物の箱内の配置も変えない。position_m は収納の上面の北西から測り、側布の名目外包は [[room-h1-4#替えの側布を保護する蓋付きの小箱]] の箱内へ収め、箱の底を上板へ直接載せる。上面の外縁と掛布との隙間、室内の障害物と天井への離隔を同じ配置で検査する。

size_m は側布を折って確保する候補の外包であり、六面を縫った側布を実際に折って収まることは未証明である。本人の裁断案の替えの六片と原布を参照し、裁断片の面積と仮の布厚から求めた体積よりも小さな外包を拒む。ただし体積が収まるだけで折り方や縫目・角の積層、箱への実物の収まりが成立した扱いにはしない。

箱を含む外包は戸と付属品の全移動、箱内の包みの取出し、戸を使う人の全区間の離隔へ同じ障害物として渡す。側布が無い場合の検査を流用しない。清潔に分ける木箱の製作と接合、実際の折返しと把持・置戻し、上板の荷重・強度、防塵と通気、使用後の布の置場と洗浄・乾燥・交換の日課を続けて設計してから採用する。


## 替えの側布を保護する蓋付きの小箱

container は本人の替えの側布に専用の木箱であり、元の衣服箱や掛布の包みとは別の固有 ID を持つ。木材はヨーゼフ、箱の製作はゴットフリートへ結び、寝台の木材供給と同じ担当でも製作量や納品が成立した扱いにはしない。布の覆いを未設計のまま必要としていた案はこの蓋付きの箱へ置き換え、同じ用途の覆いを別に調達済みとはしない。

箱は底・四方の側板・蓋を持ち、板厚と蓋厚を引いた内寸を側布の収納へ使う。側布の候補の外包は箱の底へ直接載せ、左右・前後と蓋の下へ余白を残す。箱そのものの外包が掛布と隙間を保ち、収納の上面からはみ出さないことを照合する。

蓋は北側の下辺を軸に閉じた状態から垂直まで回す案とする。蓋の厚みを含む全ての角の全回転の囲いを求め、閉じた位置と開き切った位置だけで途中を省かない。囲いを室内・水平な天井と掛布へ照合し、箱の底と側板が動かない条件を保つ。蝶番の実物と接合、板の反り・すき間と防塵・通気、蓋を持つ指と身体、強度と清掃・補修、実際の側布の折り方と出し入れ・交換の日課は続けて設計する。


## 寝具の原布へ割り当てる原料の予算案

各裁断案の material_budget は、原布の全体の面積と仮の目付から必要な乾いた布の重さを求める案である。原布に含まれる端の余りを製品だけへ消費した扱いにせず、裁断片の面積と残る布を分ける。準備・紡ぎ・織りの歩留りも仮の条件であり、必要な糸と準備した羊毛・未洗浄の乾いた原毛へ逆算する。

本人の原布は raw_lot が指す供給者の有限の予算へ一度だけ割り当て、他の原布と同じ原毛を重複して使わない。これは実物の原料を確保した記録でも、発注・納品・在庫への入庫でもない。共通の収支と全体の割当の規則は [[town#寝具の原料予算と工程の収支]] に従い、詰物と内袋・保護する箱や掛布の覆いをこの原布に含めない。
