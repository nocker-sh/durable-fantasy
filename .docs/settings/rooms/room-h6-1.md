# ヨーゼフの小屋／1階 土間（斧と薪）

## 利用と配置

南の戸から入り、まず靴と濡れた仕事着を東側へ下ろす。斧は西側で刃を覆って掛け、食卓や寝台の横へ持ち込まない。自家用の薪だけを西の乾いた置き場に置き、町へ売る大量の原木や炭を自宅の通路へ積まない。

拭くための水桶は飲用水と分ける。薪くずと泥を土間で落としてから、北側の戸で生活の床へ上がる。自宅で炭を焼く場所ではなく、炭焼き窯は森の入り口の仕事場として別に設計する。

## 未解決の生活条件

水汲みは [[facility-square-well]] との経路を設計する。便所、灰と汚水の搬出、窓と排煙、濡れた物の乾燥と火との離隔は、敷地と町全体の設計で確定する。

## 帰宅と出発の切替

薪を取る、斧を外す、手を拭く操作は西側の床を共有し、一人が順に使う。濡れ物は東へ下ろしてから乾いた生活域へ入る。共有面を複数人の作業場所として数えず、斧を持った姿勢や薪束の幅は別に照合する。
