# 共同の作業場／1階 機織りと糸紡ぎ

## 糸から布まで

[[building-h-c2]] の機織りと糸紡ぎの室である。閉じた棚から毛と糸を取り出し、糸車と機織り機を使い、織りかけの布を受けへ戻す。[[resident-マグダレーナ]] が設備を手入れする案とする。材料を利用者が持ち込み、貸出設備と本人の材料を区別する。

## 織る姿勢と出入り

機織り機の前に作業面を取り、糸車の操作面とは分ける。張る糸の長さ・踏み板と座る高さ・糸車の回転部、織りかけを外さず交代できるかは未照合である。[[room-h-c2-mixing]] 側の戸を通る構成のため、かまどの煙と蒸気・火の粉が繊維へ達しない区画と換気を照合する。

現行の敷地と外形への収容、構造と給排水・便所、日課と立体の照合を終えるまで描画へ採用しない。

## 道具の形と素材

機織り機は経糸と布を張る四本の支柱を持つ。糸車は別の道具として、木の動輪と放射状のスポーク、軸受け、糸巻きと伝動紐、足元の踏み板を持つ。布を張る四角い枠を糸車の代わりに描かない。木と鉄・紐と毛の既存の素材を使い、台座と動輪は家具の占有の中へ収める。

この形の修正は現行の家具の見間違いを直すものであり、新しい平面案の敷地と配置を採用する意味にはしない。保守の担当はマグダレーナ、共用品の所属と利用の規則は [[building-h-c2]] を参照する。

## 寝具用の糸を紡ぐ利用案

[[resident-ベルタ#寝具用の糸を紡ぐ工程]] の原布への割当は S の糸車とその使用面を使う案である。織機 L の使用面で紡げる扱いにせず、利用する人と設備を手入れするマグダレーナを分ける。users はこの利用案を表し、設備の管理者や雇われた職員へ数えない。ベルタの現行の日課に訪問を追加した意味ではない。原毛と糸・織りかけを別の人の材料へ混ぜず、保管容量と本人の区画、利用時間と交代・清掃、繊維を整える場所と給排水、身体の操作を照合してから採用する。
