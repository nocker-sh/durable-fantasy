# 空き家（貸家）／1階 寝室の空室

## 寝室という用途の空室

[[room-h-g3-1]] から専用の戸で入る。人も寝台も置かず、用途名だけで常用寝床として数えない。ここを別の住人や働き手の通り道にはしない。

## 入居者に合わせる条件

入居する世帯が決まってから、個々の寝台と衣服箱・寝具の保管、着替えの視線と夜の灯りを設計する。暖房と換気・窓と戸の開閉、寝床へ至る身体と家具の搬入、修繕と鍵の担当は未照合である。

現行の敷地と外形への収容、構造と給排水・便所、日課と立体の照合を終えるまで描画へ採用しない。
