# 広場の礼拝堂／本堂

## 来訪者の祈りと応対

南の入口から前後の長椅子と祈る台へ歩ける。長椅子の両脇と二列の間に通る床を残し、祈りの列を記録室や手当ての部屋へ通り抜けさせない。長椅子は待つ人と祈る人が使う。記録室と手当ての部屋の戸は本堂側へ開き、開閉する人の身体と長椅子・手洗い台を離す。南の外壁の戸は壁内の通路を確保し、内側の面から本堂へ開く。室内から開ける身体を照合し、屋外からの開閉と施錠、閉じ直しはまだ照合していない。人数と身体の割当、行列と配膳はまだ検証していない。

西の戸から [[room-chapel-records]] と [[room-chapel-care]] へ別々に入る。炉の熱と煙、灯りと窓、手洗いの給水と排水はこの平面だけで成立したことにしない。寄進の粥は調理と器の回収・洗浄まで別に設計し、本堂の炉をそのまま大量調理の設備と扱わない。

## 平面案

一セルは十四センチメートル。本堂の既存外形へ合わせ、外壁と室内の仕切りを区別する。戸口は同じセルで隣室へつなぐ。
