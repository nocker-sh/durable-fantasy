# 広場の礼拝堂／記録室

## 記録を守る小部屋

本堂から戸を開けて入り、記録を探す棚と書く机、椅子を置く。来訪者や手当ての道具をこの部屋へ通り抜けさせず、記録を粥や洗い物の置台に使わない。町の記録と祈りの言葉は二人が手入れし、私物と寝具は [[building-h10]] に保管する。

鍵と閲覧の手順、灯り・窓と灰への覆い、紙と綴じる材料の保管量、机と戸の開閉は未照合である。

## 平面案

一セルは十四センチメートル。本堂の既存外形へ合わせ、外壁と室内の仕切りを区別する。戸口は同じセルで隣室へつなぐ。
