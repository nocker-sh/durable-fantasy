# 睡蓮の沼

## 場所の役割

睡蓮の沼は町の外の場所である。周囲とのつながりはメタデータの exits を持つ。出入口は通行のための場所であり、別の目的地への経路の途中で意図せず踏ませない。

## 使う人と物の流れ

高原の南の低い湿地。四つの沼に睡蓮が浮き、道は沼のあいだの低い土手を通る。南東の沼に桟橋があり、平底の舟がつないである。町の人が舟で睡蓮の根(食用、提案)と沼の魚を採りに来る。住む人はいない。

道の脇の祠は、昔ここで道が沼に消えて人が迷ったことの印として旅人が手を合わせる場所である。

## 地形

沼の底は水面(WATER_Y)より下に沈めてあり、岸は浅く棚になる。桟橋は絵だけで、歩いて先まで出ることはできない(通行格子では水の上は通れない)。

## 生き物との関係

モンスターの出現は登録されていない。生き物を置く時は、餌・水・休息地の根拠になる地形を先に決める。

## 配置の設計条件

入口、主な通路、作業と休憩の場所を先に配列で定義する。灰・雨・煙・火・水の行き先を決める。現行の通行格子は現状の記録であり、生活の成立を承認した配置図ではない。
