# 南の草原

## 場所の役割

南の草原は町の外の場所である。周囲とのつながりはメタデータの exits を持つ。出入口は通行のための場所であり、別の目的地への経路の途中で意図せず踏ませない。

## 使う人と物の流れ

建物の所属資料と照合し、管理する人とここへ来る目的を確定する。

## 生き物との関係

現在の生息種は[[monster-slime]]、[[monster-blue-slime]]、[[monster-hare]]。人の通る道、採集する場所、生き物の居場所を同じ配置図で確認する。

## 配置の設計条件

入口、主な通路、作業と休憩の場所を先に配列で定義する。建物の外周と扉、荷の大きさ、人がすれ違う幅を合わせ、装飾を置いてから通路を残す順序にしない。灰・雨・煙・火・水の行き先を決める。現行の通行格子は現状の記録であり、生活の成立を承認した配置図ではない。

## 果樹園・畑・草むらを使い分ける

オットーの果樹園とぶどう畑は、町へ果物と醸造用の実を渡す仕事の場所である。落果はスライムを寄せる理由になるが、収穫・荷運びの床と、休む草むらを同じ場所へ重ねない。野うさぎは見回りに気づけば低木側へ逃げる余地を持つ。青いスライムには湿った場所が必要で、現在の出現範囲を水場のある設計として追認しない。

生息条件は ecology_zones に記録する。placement が null の条件はまだ地形に割り当てていない。出現矩形があることだけで、その条件を満たした配置としない。

## 生き物の移動と障害物

現行の出現範囲には通れないセルが混在する。休憩地点の両端だけを確認して直線で渡らず、共通の通行格子で途中の全セルを照合し、必要なら格子の経路へ迂回する。出現数と範囲を狭めて障害物を避けた扱いにはしない。これは移動の中心の足場の検査であり、身体の外形、餌と水、休息地の配置が済んだ意味ではない。

身体の大きさから求めた囲いでは、中心が通れる位置でも障害物に重なる場合がある。共通の寸法と移動全区間の円形の囲いを通行格子へ照合し、休憩地点の選択と経路の生成へ採用する。探索を細かくして身体が通れる隙間を保ち、出現範囲と個体数は変えない。通行格子への採用を、実際の障害物の形や生態の配置の完成とは扱わない。

## 青いスライムの湿った窪地の配置案

`ecology_zones` の青いスライムの `placement` に、現行地形の低い側を使う湿った土の案を持つ。池の実装は現在なく、常在する水面や湧水のある場所として描かない。降水と露が残る地面、水分を含む草、風を避ける草の覆い、退く草地を別の記号で配置する。W は歩ける湿った地面であり、深い水や人の水汲み場ではない。

グリッドの原点と単位は同じメタデータに持つ。# は現行の障害物を残す制約、. は空く地面である。既存の出現範囲と身体の大きさを使い、各接近位置が通れることを先に照合する。配置案の成功を水と餌の成立とは扱わず、集水域・浸透・溢水と乾燥期、灰と植生、実際の行動と描画が揃うまで proposed と未通過を保つ。


## 野うさぎの草地の配置案

北東の開けた草地に、採食する葉、水分を含む草、休む覆い、退く草地を分けて置く案を `ecology_zones` に持つ。既存の古木と岩の東側を使い、幹や岩に身体を重ねて休ませない。各面の位置と利用位置は同じ格子で決め、既存の出現範囲と通行格子を保つ。ここは果樹園の柵内でも、南側の薬草と花の採集位置でもなく、人が通る幹線道路を常用の寝床にしない。

水分面は葉に露と雨が残る候補であり、飲水できる常在する池ではない。雨や露がない日にも同じ水分を得られると仮定しない。乾燥時の水分の供給先と移動、灰の付着と草の再生、覆いの高さと風、警戒と逃走の動作と複数個体の間隔、現在の植生との照合が残る。配置を提案したことを、これらの成立や実装の証明としない。


## スライムの東西の草地の配置案

東西の出現範囲にそれぞれ独立した `sites` を持つ。西側は薬草の採集位置より北西の野草を採食面とし、採集する人が立つ位置を常用の休息面に数えない。東側は花の採集位置の東、薬草の採集位置の北に採食と休息を分ける。青いスライムの湿った地面の案を、東西すべてのスライムの水場に流用しない。各区画で餌・水分・休息・退避を揃え、道路を渡ってもう一方の区画へ行く経路は暗黙に作らない。

現在の出現範囲は果樹園の柵から離れている。ここでの餌は野草の葉と草の残りを中心とする案で、落果を恒常的な餌に数えない。果樹園へ寄る性質と、この場所で日常の餌を得られる根拠を区別する。灰と乾燥、植生の更新と採食量、草の覆いの断面、個体の間隔と人の採集との共用、実際の採食・休息と警戒・退避の動作、植生描画が残る。
