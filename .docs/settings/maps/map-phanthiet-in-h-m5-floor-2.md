# ファンティエット ― 町の寄り合い所 ― 2階

## 記録室の階

[[building-h-m5]] の上階である。[[room-h-m5-upper-stairs]] の踊り場から入り、[[room-h-m5-2]] の卓と記録の棚へ行く。街へ直接出る戸は持たず、地上階の階段と入口を経由して戻る。

## 使う人と物の流れ

エーリヒが記録を受け、分類と照合を行う。炉から上がる煙道の区画には紙を置かない。上階の床開口と手すりを同じ断面から描き、開口へ平面移動できるセルを作らない。書類の運搬量と受渡し・保管、利用時間と灯り・火気、維持と給排水は引き続き照合する。
