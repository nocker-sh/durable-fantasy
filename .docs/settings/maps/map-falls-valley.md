# 滝の谷

## 場所の役割

滝の谷は町の外の場所である。周囲とのつながりはメタデータの exits を持つ。出入口は通行のための場所であり、別の目的地への経路の途中で意図せず踏ませない。

## 使う人と物の流れ

沼の南の谷。北西の湧き水から流れが出て、二段の岩の段を滝になって落ち、南東の淵にたまる。道は北から入り、段の東を切り通しで下って東の塩の原へ抜ける。塩を運ぶ人が下の滝の上の段で水筒を満たして休む(焚き火の石の輪がある)。住む人はいない。

## 地形

段は水の通る所だけ切り立ち、ほかは登れない岩の斜面。流れは地面に描いた帯で、滝の足もとにしぶきが立つ。流れには通れる面がなく、通行格子でも入れない。

## 生き物との関係

モンスターの出現は登録されていない。生き物を置く時は、餌・水・休息地の根拠になる地形を先に決める。

## 配置の設計条件

入口、主な通路、作業と休憩の場所を先に配列で定義する。灰・雨・煙・火・水の行き先を決める。現行の通行格子は現状の記録であり、生活の成立を承認した配置図ではない。

## 生き物

[[monster-moss-slime]] は道の西の湿った岩陰で苔を食べて休む。生息条件は ecology_zones に記録し、placement が null の間は地形への割り当てを済ませた扱いにしない。
