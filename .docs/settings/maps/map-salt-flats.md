# 塩の原

## 場所の役割

塩の原は町の外の場所である。周囲とのつながりはメタデータの exits を持つ。出入口は通行のための場所であり、別の目的地への経路の途中で意図せず踏ませない。

## 使う人と物の流れ

谷の東の、白い塩の殻が板に割れた平原。薄く塩水が張る所があり、塩の柱が林のように立つ。道は西の谷から入り、塩の作業場で行き止まりになる。

作業場では板で囲った浅い塩田に塩水を引いて干し、かき寄せた塩を山にして袋に詰め、町へ運ぶ。町の塩漬けニシンの塩はここから出る(提案。食料の資料と照合して確定する)。差し掛け小屋は道具置き場で、塩をかく人は日中の暑い時にここで休む。夜は町へ帰り、ここには住まない。道沿いの石積みは、塩水が上がって道が見えなくなった時の目印である。

## 地形

北と東は閉じた端で、枯れ木と岩で縁取る。塩水の張った所は水面より下で通れない。

## 生き物との関係

モンスターの出現は登録されていない。生き物を置く時は、餌・水・休息地の根拠になる地形を先に決める。

## 配置の設計条件

入口、主な通路、作業と休憩の場所を先に配列で定義する。灰・雨・煙・火・水の行き先を決める。現行の通行格子は現状の記録であり、生活の成立を承認した配置図ではない。
