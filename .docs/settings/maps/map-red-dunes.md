# 赤い砂丘

## 場所の役割

赤い砂丘は町の外の場所である。周囲とのつながりはメタデータの exits を持つ。出入口は通行のための場所であり、別の目的地への経路の途中で意図せず踏ませない。

## 使う人と物の流れ

建物の所属資料と照合し、管理する人とここへ来る目的を確定する。

## 生き物との関係

現在の生息種は[[monster-sand-slime]]。人の通る道、採集する場所、生き物の居場所を同じ配置図で確認する。

## 配置の設計条件

入口、主な通路、作業と休憩の場所を先に配列で定義する。建物の外周と扉、荷の大きさ、人がすれ違う幅を合わせ、装飾を置いてから通路を残す順序にしない。灰・雨・煙・火・水の行き先を決める。現行の通行格子は現状の記録であり、生活の成立を承認した配置図ではない。

## 残骸を訪ねる人と砂の風陰を使う生き物

砂に埋もれた大戦の残骸を調べる人が、風陰の窪みへ入ることで砂スライムと出会う。古い鉄片は残骸に由来し、砂や生き物が金属を生産する設定にはしない。砂だけの画面に出現枠を載せるのではなく、食べ物・湿り・休息の根拠となる地形を設計する。残骸の鋭い割れ目を人や生き物の通常の通路にしない。

生息条件は ecology_zones に記録する。placement が null の条件はまだ地形に割り当てていない。出現矩形があることだけで、その条件を満たした配置としない。
