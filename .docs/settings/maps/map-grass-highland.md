# すすきの高原

## 場所の役割

すすきの高原は町の外の場所である。周囲とのつながりはメタデータの exits を持つ。出入口は通行のための場所であり、別の目的地への経路の途中で意図せず踏ませない。

## 使う人と物の流れ

南の草原から西へ抜けた先の、すすきが波打つ高い草地。町の茅葺き屋根はここで刈ったすすきで葺き替える(提案。茅葺きの家の資料と照合して確定する)。秋の終わりに刈り手が町から通い、刈った束を道の南の小道沿いに立てて干し、道端の干し台で穂を落としてから荷車で町へ運ぶ。住む人はいない。

北西の丘の上には大戦の歩く機械が倒れたまま残っている。刈り手は丘へ登る小道の先、機械の手前の石積みで休み、それより奥へは入らない。

## 地形

北西に機械の丘、南東に低い高まり、北東にくぼ地。道は東の草原の出入口から入り、くぼ地の脇を通って南へ下り、睡蓮の沼へ続く。すすきは風で揺れる(sway)。

## 生き物との関係

モンスターの出現は登録されていない。生き物を置く時は、餌・水・休息地の根拠になる地形を先に決める。

## 配置の設計条件

入口、主な通路、作業と休憩の場所を先に配列で定義する。灰・雨・煙・火・水の行き先を決める。現行の通行格子は現状の記録であり、生活の成立を承認した配置図ではない。
