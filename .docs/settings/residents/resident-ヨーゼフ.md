# ヨーゼフ

## 暮らしの立場

ヨーゼフは木こり。木こりのヨーゼフに属し、同居人なしという世帯構成で暮らす。仕事と収入のつながりは薪と炭と原木。町じゅうの暖炉と炉の燃料。森のきのこを宿へ。

## 人柄と話し方

性格は無口、実直、森が好き。話し方は「おれ。言葉少な。「……おう」」。口癖は「森は嘘をつかない」。

## 一日の居場所

日課の時刻・場所・行動は routine_source が指すコードの定義を正とする。活動を始める前の食事・身支度、活動中の食事、帰宅後の片付け、就寝を、建物と部屋の資料へ結び付ける。単に予定の座標へ移動できるだけで生活の成立としない。

## 寝床と持ち物

衣服、首巻き、仕事道具の個別収納を、固有の寝台の使用面と一緒に設計する。帰宅先の建物に属する仕事場と寝間を混同しない。

## 描画へ渡す条件

外見は appearance_source が指す実際の描画定義を基準とする。日課中に持つ道具、仕事着の汚れ、寒さへの備えは職業と作業場所に根拠を持たせる。部屋と動線が未確認のため、現時点では生活の整合を検証済みとしない。

## 固有の寝床

常用の寝床は [[room-h6-3]] の bed-h6-3-1 に割り当てる。客室や仕事場の休憩用家具を、本人の寝床の代わりに数えない。衣服、首巻き、私物の収納は storage_ids の個人区画へ割り当て、寝台の使用面と合わせて容量・開閉を照合する。

## 二人の寝台へ供給する案

[[room-h1-3#寝台の骨組みとマットレス]] と [[room-h1-4#寝台の骨組みとマットレス]] で、二人の寝台の骨組みに使う木材を、木工師のゴットフリートへ供給する案へ結ぶ。寝台そのものの製作者にはせず、原木から乾いた部材までの処理・保管と搬入は別に設計する。

## 二人の衣服箱へ供給する案

[[room-h1-3#衣服箱の内寸と持ち物]] と [[room-h1-4#衣服箱の内寸と持ち物]] の個人の木の箱へ、寝台と同じ木材供給と木工の担当を結ぶ。板と蓋を含む箱の製作と、収納する衣服の仕立ては別の仕事とする。乾燥・加工と納品の工程は未照合である。

箱の蓋を受ける専用の台も [[room-h1-3#衣服箱の蓋を受ける低い台]] と [[room-h1-4#衣服箱の蓋を受ける低い台]] の同じ供給・製作の案へ結ぶ。衣服や食材を置く共用台としては数えない。

蓋に属する木の取っ手も [[room-h1-3#蓋の西側の木の取っ手]] と [[room-h1-4#蓋の西側の木の取っ手]] の同じ供給・製作の案へ結ぶ。接合部の強度と荷重、納品と補修の日課は続けて設計する。


## 替えの枕の側布の小箱

[[room-h1-3#替えの側布を保護する蓋付きの小箱]] と [[room-h1-4#替えの側布を保護する蓋付きの小箱]] の各人の小箱へ、寝台と同じ木材供給・木工の担当を結ぶ。寝台や衣服箱の原料・製作量をそのまま小箱にも重複して使わない。板と蓋、蝶番の接合と耐久・強度、乾燥と加工・搬入、製作・補修の日課は未照合である。側布そのものの仕立てと洗浄・乾燥は別の担当と工程に残す。
