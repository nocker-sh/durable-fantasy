# マリー



## 暮らしの立場

マリーは茶売り。代書屋のエーリヒに属し、エーリヒ、ハンナという世帯構成で暮らす。仕事と収入のつながりは手紙と証文の代書、寄り合いの記録。マリーは戸口で薬草茶を売る（薬草はイルムガルトから）。

## 人柄と話し方

性格は穏やか、もてなし好き、心配性。話し方は「わたし。おっとりした女言葉。「〜かしら」」。口癖は「温かいうちにどうぞ」。

## 一日の居場所

日課の時刻・場所・行動は routine_source が指すコードの定義を正とする。活動を始める前の食事・身支度、活動中の食事、帰宅後の片付け、就寝を、建物と部屋の資料へ結び付ける。単に予定の座標へ移動できるだけで生活の成立としない。

## 寝床と持ち物

衣服、首巻き、仕事道具の個別収納を、固有の寝台の使用面と一緒に設計する。帰宅先の建物に属する仕事場と寝間を混同しない。

## 描画へ渡す条件

外見は appearance_source が指す実際の描画定義を基準とする。日課中に持つ道具、仕事着の汚れ、寒さへの備えは職業と作業場所に根拠を持たせる。部屋と動線が未確認のため、現時点では生活の整合を検証済みとしない。

## 固有の寝床

常用の寝床は [[room-h-m1-2]] の bed-h-m1-2-2 に割り当てる。客室や仕事場の休憩用家具を、本人の寝床の代わりに数えない。衣服、首巻き、私物の収納は storage_ids の個人区画へ割り当て、寝台の使用面と合わせて容量・開閉を照合する。
