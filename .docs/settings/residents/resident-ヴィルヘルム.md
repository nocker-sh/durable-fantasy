# ヴィルヘルム

## 暮らしの立場

ゾフィーの祖父で、[[building-h1]] で孫と二人で暮らす。隠居し、[[building-h-m4]] を地図描きのフェルディナントへ貸す。世帯の生活は貸家の賃料を基盤とし、昔話を語ること自体を有償の仕事にしない。借り手から地図の写しを受け取る関係は `world/town/people.ts` にある。

孫が扱う花は売り物として尊重する。自分の部屋に飾る花は `world/core/errands.ts` の依頼で別に求める。ベネディクトへ昔の話を聞かせる関係も、町に残る話を伝える交流であり、大戦を本人が経験した設定にはしない。

## 人柄と話し方

性格は穏やか、昔話好き、物忘れ。話し方は「わし。老人言葉。「〜じゃ」「〜のう」。相手は「若いの」」。口癖は「どこまで話したかのう」。

## 一日の居場所

日課の時刻と場所は routine_source が指すコードを正とする。家で茶を淹れ、外のベンチで休み、家の昼寝を挟んで宿の暖炉へ話しに出てから帰宅して眠る。常用の寝床は [[room-h1-3]] であり、宿へ通うことを宿泊や寝台の割当と混同しない。

茶の支度は [[room-h1-2]]、自宅での食事と休息は [[room-h1-1]] に結ぶ。本人の描画で持つ杖は、荷物と両手を同時に空けて使える設定にはしない。茶の湯と器を運ぶ手、階段を使う時の手と杖、休む椅子への着席と立上りは未照合である。

孫が菜園や夜市へ出ている間も本人は家や宿へ移動する。介助を常時受ける日課を一律に当てず、助けが必要な動作を個別に確かめる。家庭の汲水は [[room-h1-2#飲用水を汲んで保管する一つの容器]] で孫へ割り当てる案とし、本人へ杖と満水の壺を同時に持たせない。運搬と在庫、便所・衣服の手入れの動線はまだ成立を確認していない。

## 寝床と持ち物

衣服、首巻き、仕事道具の個別収納を、固有の寝台の使用面と一緒に設計する。帰宅先の建物に属する仕事場と寝間を混同しない。

## 描画へ渡す条件

外見は appearance_source が指す実際の描画定義を基準とする。日課中に持つ道具、仕事着の汚れ、寒さへの備えは職業と作業場所に根拠を持たせる。部屋と動線が未確認のため、現時点では生活の整合を検証済みとしない。

## 固有の寝床

常用の寝床は [[room-h1-3]] の bed-h1-3-1 に割り当てる。客室や仕事場の休憩用家具を、本人の寝床の代わりに数えない。衣服、首巻き、私物の収納は storage_ids の個人区画へ割り当て、寝台の使用面と合わせて容量・開閉を照合する。

## 家の共用部と私室

一階の居間と台所で食事と普段の支度を行い、二階は階段区画と共用の踊り場から本人の寝室へ入る。別の人の寝室を通り抜けずに常用寝台と衣服箱を使う案とし、夜の移動と日課、戸と目隠し、収納容量と立体は引き続き照合する。

## 食事の器と片付け

食事は [[room-h1-1]]、食材と器の支度・洗い物は [[room-h1-2]] に結ぶ。棚と桶を使う順序は台所の資料に従い、二人へ重なる使用面を同時に割り当てない。器と布を実際に運ぶ日課、乾燥と収納量は未照合である。

## 本人の寝台と寝具の供給案

寝台の骨組みとマットレスは [[room-h1-3#寝台の骨組みとマットレス]] の本人の実寸と出所へ結ぶ。枕と掛布の整えた形は [[room-h1-3#整えた寝台の枕と掛布]] にある。替えの寝具、衣服箱の容量と開閉、夜の移動・着替えと寝具の手入れは未照合であり、寝台の描画だけで睡眠の日課を完了しない。

## 本人の衣服箱へ収める案

替えの衣服と首巻き、清潔な私物は [[room-h1-3#衣服箱の内寸と持ち物]] の本人の箱へ結ぶ。着用中の物と収納する替えを分け、仕事の汚れた荷を清潔な包みへ混ぜない。静止した収まりと、開閉・着替え・手入れの日課の成立を区別する。

衣服箱の板への到達候補は [[room-h1-3#蓋の縁へ届く本人の低い姿勢]] にある。低い静止姿勢を本人の日課や身体能力へ採用せず、床に置いた板を拾い直せない不成立から [[room-h1-3#衣服箱の蓋を受ける低い台]] へ置く案とする。受け台上の縁への到達と、板の把持・荷重と運搬の成立は区別する。

本人の衣服箱の蓋は [[room-h1-3#蓋の西側の木の取っ手]] の横棒へ届く案とし、箱と受け台を腕が通り抜けない形を先に確認する。端ごとの掌の接触と動く板からの離隔は [[room-h1-3#横棒全体を囲む掌の静止した接触]] にある。連続した運搬、力と日課への採用は未照合である。

本人の日常の収納は [[room-h1-3#前から開ける収納への変更案]] の片手で使う前面の引き戸を優先して照合する。低い姿勢のまま蓋を運ぶ候補の標本検査を、本人の身体能力や日課への採用へ読み替えない。同じ衣服と私物を移す案であり、持ち物を二重に割り当てない。

本人の片手の把持の候補は [[room-h1-3#孔の代わりに木の取っ手を握る別案]] に結ぶ。元の掌が板へ入る形を許さず、実際の縦棒と支柱を用いる。静止した握りと、足運びの全区間の到達・外部離隔、握る前腕の自己離隔を区別する。全区間の範囲は [[room-h1-3#立位の足運びの脚先と曲げる側の全区間]] から後の各節に従う。上腕の付け根・脚同士と衣服の自己離隔、戸を動かす力と釣合い、包みの把持と日課への採用はまだ成立を確認していない。

替えの掛布一枚は [[room-h1-3#前面収納の上面へ収める替えの掛布]] の別の固有 ID へ結ぶ。寝台上の物と二重に数えず、元の衣服と私物を小さくしない。名目上の外包と支持の案であり、畳む実物と持上げ、洗浄・乾燥と日課は未照合である。


自宅で茶を飲む席と本人の杯は [[room-h1-1#茶の杯を置く席と食事からの入替え]] へ結ぶ。食事の器を下げた後の配置案であり、二人が必ず同時に在宅する日課や、熱い杯を運ぶ手と飲む動作が成立したとは扱わない。
