# ゾフィー

## 暮らしの立場

ヴィルヘルムの孫で、[[building-h1]] で祖父と二人で暮らす。本人は庭仕事と夜市の花売りを行う。世帯の暮らしの基盤は祖父の貸家の賃料であり、花の売上だけで二人の生活を説明しない。貸主と借り手の関係は [[building-h-m4]] にある。

売り物の花と家に飾る花を分ける。祖父が自分の部屋の花を依頼する設定は `world/core/errands.ts` にあり、本人の売り物を無断で家の飾りへ回さない。

## 人柄と話し方

性格は優しい、祖父思い、花好き。話し方は「わたし。柔らかい口調。「〜かしら」」。口癖は「春になったら」。

## 一日の居場所

日課の時刻と場所は routine_source が指すコードを正とする。家で祖父の世話をした後に菜園へ出て、家へ戻ってから [[map-phanthiet-market]] の花の売り場へ向かい、帰宅して眠る。祖父はその間に外のベンチや宿へ出るため、二人が終日同じ室内にいる設定にはしない。

売り場と品物は `world/core/shops.ts` の flowers が定義する。菜園の隅に咲く花を扱うが、本人が使う畝と採花の範囲・水・花を運ぶ容器は未設計であり、[[building-h1]] に専用の庭が配置済みとは扱わない。花を摘み、選び、夜市へ運ぶ工程と季節による供給は日課の表示だけでは成立しない。

食事と支度は [[room-h1-1]]・[[room-h1-2]]、就寝は [[room-h1-4]] に結ぶ。家の水は [[facility-square-well]] から本人が台所の壺で運ぶ案とする。容器・量と仮の荷重は [[room-h1-2#飲用水を汲んで保管する一つの容器]] にあり、井戸の受渡しと往復、鍬を置く場所、消費を満たす回数と身体・日課への採用は未照合である。庭仕事の手袋や道具を食器と同じ棚へ戻さず、作業後の汚れを落としてから食事の支度を行う動線を設計する。

## 寝床と持ち物

衣服、首巻き、仕事道具の個別収納を、固有の寝台の使用面と一緒に設計する。帰宅先の建物に属する仕事場と寝間を混同しない。

## 描画へ渡す条件

外見は appearance_source が指す実際の描画定義を基準とする。日課中に持つ道具、仕事着の汚れ、寒さへの備えは職業と作業場所に根拠を持たせる。部屋と動線が未確認のため、現時点では生活の整合を検証済みとしない。

## 固有の寝床

常用の寝床は [[room-h1-4]] の bed-h1-4-1 に割り当てる。客室や仕事場の休憩用家具を、本人の寝床の代わりに数えない。衣服、首巻き、私物の収納は storage_ids の個人区画へ割り当て、寝台の使用面と合わせて容量・開閉を照合する。

## 家の共用部と私室

一階の居間と台所で食事と普段の支度を行い、二階は階段区画と共用の踊り場から本人の寝室へ入る。別の人の寝室を通り抜けずに常用寝台と衣服箱を使う案とし、夜の移動と日課、戸と目隠し、収納容量と立体は引き続き照合する。

## 食事の器と片付け

食事は [[room-h1-1]]、食材と器の支度・洗い物は [[room-h1-2]] に結ぶ。棚と桶を使う順序は台所の資料に従い、二人へ重なる使用面を同時に割り当てない。器と布を実際に運ぶ日課、乾燥と収納量は未照合である。

## 本人の寝台と寝具の供給案

寝台の骨組みとマットレスは [[room-h1-4#寝台の骨組みとマットレス]] の本人の実寸と出所へ結ぶ。枕と掛布の整えた形は [[room-h1-4#整えた寝台の枕と掛布]] にある。替えの寝具、衣服箱の容量と開閉、夜の移動・着替えと寝具の手入れは未照合であり、寝台の描画だけで睡眠の日課を完了しない。

## 本人の衣服箱へ収める案

替えの衣服と首巻き、清潔な私物は [[room-h1-4#衣服箱の内寸と持ち物]] の本人の箱へ結ぶ。着用中の物と収納する替えを分け、仕事の汚れた荷を清潔な包みへ混ぜない。静止した収まりと、開閉・着替え・手入れの日課の成立を区別する。

衣服箱の板への到達候補は [[room-h1-4#蓋の縁へ届く本人の低い姿勢]] にある。低い静止姿勢を本人の日課や身体能力へ採用せず、床に置いた板を拾い直せない不成立から [[room-h1-4#衣服箱の蓋を受ける低い台]] へ置く案とする。受け台上の縁への到達と、板の把持・荷重と運搬の成立は区別する。

本人の衣服箱の蓋は [[room-h1-4#蓋の西側の木の取っ手]] の横棒へ届く案とし、箱と受け台を腕が通り抜けない形を先に確認する。端ごとの掌の接触と動く板からの離隔は [[room-h1-4#横棒全体を囲む掌の静止した接触]] にある。連続した運搬、力と日課への採用は未照合である。

本人の日常の収納は [[room-h1-4#前から開ける収納への変更案]] の片手で使う前面の引き戸を優先して照合する。低い姿勢のまま蓋を運ぶ候補の標本検査を、本人の身体能力や日課への採用へ読み替えない。同じ衣服と私物を移す案であり、持ち物を二重に割り当てない。

本人の片手の把持の候補は [[room-h1-4#孔の代わりに木の取っ手を握る別案]] に結ぶ。元の掌が板へ入る形を許さず、実際の縦棒と支柱を用いる。静止した握りと、足運びの全区間の到達・外部離隔、握る前腕の自己離隔を区別する。全区間の範囲は [[room-h1-4#立位の足運びの脚先と曲げる側の全区間]] から後の各節に従う。上腕の付け根・脚同士と衣服の自己離隔、戸を動かす力と釣合い、包みの把持と日課への採用はまだ成立を確認していない。

替えの掛布一枚は [[room-h1-4#前面収納の上面へ収める替えの掛布]] の別の固有 ID へ結ぶ。寝台上の物と二重に数えず、元の衣服と私物を小さくしない。名目上の外包と支持の案であり、畳む実物と持上げ、洗浄・乾燥と日課は未照合である。


自宅で茶を飲む席と本人の杯は [[room-h1-1#茶の杯を置く席と食事からの入替え]] へ結ぶ。食事の器を下げた後の配置案であり、二人が必ず同時に在宅する日課や、熱い杯を運ぶ手と飲む動作が成立したとは扱わない。
