# ベルンハルト


## 暮らしの立場

ベルンハルトは煙突掃除。煙突掃除のベルンハルトに属し、モニカ、トビアスという世帯構成で暮らす。仕事と収入のつながりは煙突掃除と屋根の灰下ろし。集めた灰はモニカが陶工と畑に売る。トビアスは住み込みの弟子。

## 人柄と話し方

性格は陽気、高い所が平気、煤だらけ。話し方は「おれ。大声で快活。「〜だぜ！」」。口癖は「上から見りゃ町は小さい」。

## 一日の居場所

日課の時刻・場所・行動は routine_source が指すコードの定義を正とする。活動を始める前の食事・身支度、活動中の食事、帰宅後の片付け、就寝を、建物と部屋の資料へ結び付ける。単に予定の座標へ移動できるだけで生活の成立としない。

## 寝床と持ち物

衣服、首巻き、仕事道具の個別収納を、固有の寝台の使用面と一緒に設計する。帰宅先の建物に属する仕事場と寝間を混同しない。

## 描画へ渡す条件

外見は appearance_source が指す実際の描画定義を基準とする。日課中に持つ道具、仕事着の汚れ、寒さへの備えは職業と作業場所に根拠を持たせる。部屋と動線が未確認のため、現時点では生活の整合を検証済みとしない。

## 灰と煙突の仕事

屋根の降灰と煙突から取る煤を、出どころを区別して扱う。仕事の後に道や食品へ撒かないよう、受ける布や容器を置く場所を持つ。屋根へ上がる経路と、冷ました灰を集める場所、モニカへ渡す対象を決める。便所や汚水の処理まで、既存の煙突掃除の仕事に暗黙に含めない。

## 固有の寝床

常用の寝床は [[room-h-c5-3]] の bed-h-c5-3-1 に割り当てる。客室や仕事場の休憩用家具を、本人の寝床の代わりに数えない。衣服、首巻き、私物の収納は storage_ids の個人区画へ割り当て、寝台の使用面と合わせて容量・開閉を照合する。
