# ゲームシステム仕様

アクション要素のない、マス目とクリックで遊ぶ多人数オンライン RPG。プレイヤーは町や野外のマップを行き来し、NPC と話し、店で売り買いし、対象をクリックして自動で戦い、育つ。

すべての前提は [[README#完全な生活]]。この文書はシステムの約束ごとを決める。画面の作りは [[ui]] にあり、どの画面もここに書いたものだけを表示・操作する。数・式・表は `world/core/` にあり、ここには写さない。

## 0. 前提と設計の原則

**サーバーが正しい**。位置、所持品、所持金、能力値、戦闘の結果はサーバーが決める。クライアントは表示し、操作を送るだけ。クライアントは同じ規則の関数で「押せないボタン」を灰色にするが、それは表示のためで、結果はサーバーの返事で確定する。

**規則は純粋な TypeScript**（`world/core/`）で書く。規則は状態とコマンドを受け取り、`accept`（新しい状態と出来事）か `reject`（理由コード）を返す。拒否されたら何も変わらない。サーバーとクライアントで同じ関数を使う。

**状態は ID だけを持つ**。名前・価格・能力などの定義は定義表（アイテム表、NPC 表、マップ表）から引く。**乱数と時刻は外から渡す**。テストで同じ結果を再現できるようにするためである。**理由コードは文字列の列挙**で、UI は理由コードから文言を選ぶ。**規則ごとにテストを書く**（vitest、`*.test.ts`）。

## 1. 世界とマップ

世界はマップの集まりで、外のマップは世界の升目（[[town#世界の升目]]）に一マスずつ並ぶ。隣のマスとは向かい合う辺のつなぎ目でつながり、乗るとロード画面を挟んで移る。地続きに歩いて移動する世界ではない。

**1 マップ = 1 Durable Object**（`routes/map/[mapId].ws.ts`、処理は `world/server/map-room/`）。チャンネル（§1.1）があるので、部屋は一つのマップの一つのチャンネルごとに一つできる。部屋はそこにいるプレイヤーの位置を接続ごとに持ち、マップ内の出来事を配る。NPC の居場所は時刻から決まるので部屋は持たない。生き物の HP は部屋ごとの `wild` Durable Object が持つ（§8）。

マップの定義は `world/maps/` に置く。定義は名前と種類（町・屋内・野外・ダンジョン）、歩けるマス、NPC の配置、ワープ、出現位置を持つ。歩けるマスはクライアントの地形生成から書き出したもの（`scripts/export-map.ts`）で、サーバーはこれで経路を検証する。外のマップどうしのワープは升目（`world/maps/grid.ts`）から、屋内の扉は屋内マップの定義から作られる。

マップを移るときは、サーバーが移動を許可し、クライアントがロード画面を出して今の部屋から切断し、次のマップのアセットを読んでから次の部屋に入る。出口に近づくと、その先の部屋のチャンネルを決めて接続を先に開いておき、隣のマップのアセットも先に読んでおく。

**今行けるのは、町と、町のまわりの草原と森だけ**（`world/maps/index.ts` の `OPEN_FIELDS`）。ほかの外のマップは、地図と中身は作ってあるが通れない。部屋はそこへのワープを断り（`ROAD_CLOSED`）、画面は「この先はまだ通れない」と出す。通れないマップの採集場所と出入口はそのまま残し、道を開けたときに使う。

### 1.1 並行する町とチャンネル

世界はいくつかの並行する町に分かれている（[[world#いくつもの世界]]）。プレイヤーは一つの町をホームタウンに持ち、どの町かは id から決まる。経済（店の棚と取引所）はどの町も共通である。採集場所の残りは町ごとに持つ。町の数と、id から町を決める式は `world/channels.ts`。

友達の町を訪ねることができる（[[world#マフラーと糸]]、`world/core/threads.ts`）。訪ねるにはまず糸を交換する。そばにいる人の名札から「糸を交換する」を押し、相手が受けると、お互いに相手の糸（名前と町）を持つ。同じ人と交換し直すと新しい糸に替わる。「糸をつないだ人」の窓で「糸をたどる」を押すとその人の町の広場に渡り、「自分の町へ帰る」で戻る（マフラーが引き戻す）。部屋は、自分の町か、持っている糸の町にしか入れない。ただし開発中のビルドでは `?world=` でどこへでも行ける。糸にはプレイヤー ID を書かない。ID から作った、元に戻せない印と名前と町だけを持つ。

町の中では、マップごとにチャンネルがいくつでも開く。一つのチャンネルが一つのマップの部屋（Durable Object）で、定員がある。ただしパーティやフレンドを追って入るときは、少しだけ定員を超えてよい（定員と超えてよい数は `world/channels.ts`）。

どのチャンネルに入るかは町ごとのディレクトリ（`directory` Durable Object）が決める。頼まれたチャンネルに空きがあればそこ、なければ友達のいるチャンネル、それもなければ空きのある中でいちばん人の多いチャンネル、それもなければ新しいチャンネルになる。満員なら部屋が断り、別のチャンネルに入り直す。

部屋は誰もいなくなると何も持たずに閉じる。ディレクトリも空になったチャンネルを忘れる（自動で閉じる）。

計測（2026-10-21）では、定員いっぱいの一つのチャンネルで描画は 60fps を保ち、定員を超えた人は次のチャンネルに入り、全員が抜けるとチャンネルは閉じた。

## 2. 移動

マップは 1 マス = 0.5 タイルの格子で、8 方向に 1 マスずつ歩く。

クリックした地点までの経路はクライアントが探し、マスの列としてサーバーに送る。サーバーは、各歩が隣のマスであること、歩けないマス（壁・水・建物）を通らないこと、今いるはずのマスの上か隣から始まっていることを確かめ、通らなければ受け付けない（`world/protocol.ts` の `validPath`）。

歩く速さは決まっているので、サーバーは前の経路と開始時刻から、今いるはずのマスの範囲を計算できる（`cellsReached`）。斜めの一歩は時間が長いので、一点ではなく範囲で持つ。

NPC をクリックすると、その隣の空いたマスまで歩いてから話しかける。

## 3. キャラクター

職業（ジョブ）とジョブ Lv はない。戦うための職も作らない。何ができるかは、能力値と生活スキルの Lv と、持っている道具で決まる。

戦い方は、能力値の条件を満たした武器と魔法を手に取って決める。筋力を上げれば重い斧と剣、技量なら短剣と弓、知力なら結晶の術、信仰なら祈りになる。一方、木こり・釣り・料理などの暮らしの腕は、生活スキル（§9.1）として一つずつ Lv を持つ。道具さえあれば誰でもいつでもできる。

### 3.1 能力値

能力値は六つあり、それぞれに主な効き目がある。体力（VIT）は最大 HP、防御、HP の自然回復に効く。精神（MND）は最大 SP と SP の自然回復に効く。筋力（STR）は重い武器の条件と威力、持てる重さに効く。技量（DEX）は技の武器の条件と威力、命中、回避、会心、攻撃の速さに効く。知力（INT）は結晶の術の条件と威力に、信仰（FTH）は祈りの条件と威力に効く。

新しいキャラクターは振り分けポイントを持って始まり、Lv が上がるごとにポイントをもらう（`world/core/growth.ts`）。振ったポイントは戻せない（振り直しは将来、アイテムで行う）。

武器・魔法・一部の防具は「必要な能力値」を持ち、足りなければ装備できない（§4.3）。条件は振った能力値だけで見る。装飾品で足した分は数えない。

### 3.2 レベルと経験値

キャラクターの Lv には上限（`world/core/growth.ts` の `MAX_LEVEL`）があり、将来引き上げる。経験値は生き物を倒して得る（倒すクエストはまだない。§7）。Lv が上がると能力ポイントを受け取り、HP と SP が全快する。次の Lv までに要る経験値は `world/core/growth.ts` の表で決める。上限の Lv では経験値はそれ以上たまらない。

### 3.3 生活スキルとの関係

生活スキルの Lv（§9.1）はキャラクターの Lv とは別で、その仕事をした分だけ上がる。戦っても生活スキルは上がらず、木を切ってもキャラクターの Lv は上がらない。

一部の武器と戦技は、生活スキルの Lv も条件にする。たとえば木こりの斧は、木こりの Lv と筋力が足りれば武器として振れる。

### 3.4 能力値から決まる値

最大 HP・SP、攻撃力、防御、命中、回避、会心、攻撃間隔、持てる重さは能力値・Lv・装備から決まり、式は `world/core/stats.ts` にある。何に効くかは §3.1 のとおり。

武器は、どの能力で威力が伸びるかを、能力ごとに E〜S の段階で持つ。その能力が初めの値を超えた分（ここは装飾品で足した分も数える）だけ、段階に応じて攻撃力が足される。

### 3.5 HP・SP・自然回復

倒れていなければ、HP と SP は時間で少しずつ戻り、座っていると倍になる（`world/core/player.ts` の `settle`）。座るのは誰でもいつでもできる（§9.2）。戻った分は、使うときと読むときに、経った時間からまとめて数える。そのためサーバーが毎秒数える必要はない。食べ物でも戻る。

HP が 0 になると倒れる（§8）。

### 3.6 スタミナ・満腹・温まり

**スタミナ**は HP・SP と並べてステータスに出す。採集・生産・戦闘・町の外へ出る道のりで減る。採集と町の外へ出る道のりは、温まっていなければ（下の温まり）寒さで余計に減る。足りなければ、採集・生産・戦闘・町の外へ出ることができない。歩く・話す・売り買いはできる。スタミナは時間では戻らず、食事で戻る。宿で眠って全部戻すのはまだない。

**満腹**は食べるたびに料理ごとの量だけ増え、時間で減る。満腹を超える量は食べられない（「もうお腹いっぱい」）。食べ過ぎを止めるためである。

**温まり**: 温かい料理と飲み物は、決まった分だけ体を温める。温まっている間は、寒さでスタミナが余計に減らない。時間が来ると切れる。重ねると長い方が残る。

満腹の減りと温まりの期限に使う時刻は、サーバーが渡す。値は `world/core/player.ts` と `items.ts`。

## 4. アイテム

### 4.1 種別

アイテムの種別は六つある。消耗品（薬草・水薬・食べ物）は重ねて持て、使うと HP・SP・スタミナが戻ったり体が温まったりする。何も変わらないときは使えない。装備品は重ねられず、装備欄に付けて使う。道具（斧・釣り竿など）は重ねられず、採集に使うたびに耐久が減り、一部は武器として装備できる（§4.3）。素材は重ねて持て、魔物が落とすか採取して手に入れ、売るか作るのに使う。大事なものは手紙などのクエスト用で、売れず、捨てられず、預けられず、渡せない。結晶は世界樹のふもとで掘られる石で（[[world#結晶と魔法]]）、魔物は落とさない。今は杖などを作る材料に使い、魔法を使っても減らない。

全アイテムの一覧は `world/core/items.ts`。

### 4.2 レア度

レア度はアイテムの格を表し、枠の色で見分ける（普通・上質・希少・至宝）。

レア度は定義表で決まる値で、同じアイテムはいつも同じレア度になる。一つずつの違いは、作られる物の品質・作り手と、道具の耐久（§4.2.1）だけが持つ。精錬や付加能力で個体差をつけるのは将来で、装備に個体 ID はまだない。

### 4.2.1 品質と作り手

作られる物（回復薬、料理、パンなど）は、一つずつに**品質**と**作り手**がある。

品質は並・良・上・極の四段階で、効き目と値段が品質で変わる。

作り手の名前は品物の名前に付く（「イルムガルトの回復薬」）。プレイヤーが作った物は、作った時点の名前で固定される。住民の作り手には、性格から来る癖がある（`world/core/makers.ts`）。癖が出るのは、品質の出方、効き方、値段、説明文、瓶の色である。

同じ品物・同じ品質・同じ作り手のものだけが重なる。取引所での扱いは [[economy#5. 取引所]]。

### 4.3 装備部位

部位は 頭・首巻き・体・武器・盾・足・装飾品 1・装飾品 2（`items.ts` の `SLOTS`）。両手武器を装備すると盾の欄が使えない。首巻きは主に見た目のための欄で、巻いた物がキャラクター画面で選んだ首巻きの代わりに見える。少し守りの付く物もある。

装備品ごとに「必要な能力値」と「必要な生活スキル Lv」を持てる。持たない品は誰でも装備できる。足りなければ装備できない（`STAT_TOO_LOW`・`SKILL_TOO_LOW`）。

武器は攻撃力・攻撃の間隔・能力補正（§3.4）・戦技（§9.3）を持つ。道具（木こりの斧など）にも武器として振れるものがある。装備している斧でも木を切れ、耐久は装備したまま減る。

装備した品は、品質・作り手・耐久を持ったまま欄に入り、外せばそのまま持ち物に戻る。

### 4.4 重さ

アイテムには重さがあり、持てる重さの上限は筋力で決まる（§3.4）。上限を超えて店で買う・倉庫から引き取る・取引で受け取ることはできない（`TOO_HEAVY`）。採集と倒した生き物の落とし物は、重さでは止めない。重さが上限の 50% を超えると自然回復が止まり、90% を超えると攻撃できない、という段階の制限はまだ入れていない。

## 5. 持ち物・装備・倉庫

**持ち物**はスロットでできている。将来は重さだけで制限する方式に移すかもしれないので、規則は関数の中に閉じておく。同じ回復品・素材は上限まで重ねる。ドラッグで並べ替える。

**装備**は §4.3 の部位に 1 つずつ付ける。付け替えると、外したものは持ち物に戻る。そのため持ち物が一杯なら付け替えられない。

**倉庫**は南門の町の倉庫で、倉庫番のヒルデに話しかけて開く（`world/core/storage.ts`）。プレイヤーごとに一つ持つ。

預けるたびに、一つの品につき預かり賃がかかり、引き取りはただ。開けるたびに払う形は始めの所持金に比べて重すぎるので、預けた分だけ払う。預かり賃はヒルデの暮らし（`houses.ts` の生業）に合わせてある。額と倉庫の広さは `world/core/storage.ts`。

倉庫が開いているのは、ヒルデが帳場にいる間だけ。部屋も、ヒルデがそこにいてプレイヤーがそばに立っているかを確かめる。品は預けたときのまま戻り、使い減った道具は減ったまま戻る。大事なものは預けられない。

**ショートカット**（ショートカットバー）は持ち物の中身やスキルへの参照で、物そのものは動かさない。持っている数が 0 になっても登録は残り、灰色で表示する。登録はプレイヤーのデータとしてサーバーに保存する。

## 6. 所持金と売り買い

通貨は G（ゴールド）。新しいキャラクターは少しの G と食べ物を持ち、HP が減った状態で始まる（旅の疲れ。`world/core/player.ts`）。

**NPC の店**は、店主に話しかけ、会話の選択肢「買い物をする」から開く。どの店もどの品でも買い取る（大事なものは除く）。値段の決まり方は [[economy#4. NPC の店の価格]]。サーバーは、店主のそばにいるか、品揃えにあるか、所持金と持ち物に余裕があるかを確かめる。

プレイヤー同士の取引は §11。

## 7. NPC・会話・クエスト

NPC は町の住民で、定義は [[README#文書の置き場所]] の定義表にある。

話しかけると会話ウィンドウが開く。ページを 1 枚ずつ送り、最後のページで選択肢を出す。選択肢は、その人の役目とその時刻から決まる（`world/parts/dialogue.ts`）。店番をしている間の店主は「買い物をする」、加工を受ける職人は「仕事を頼む」、帳場にいるヒルデは「荷を預ける・引き取る」、その日の頼まれごとがある人は「頼まれごとを聞く」と渡す品の選択肢を出し、最後はいつも「さようなら」である。

会話と店（会話から開く）の間はプレイヤーは動けない。部屋は会話相手を覚え、その間の移動とワープを断る。会話は NPC のそばでしか始められない。閉じると動ける。

**クエスト**は、引き受けて、条件（何かを倒す・集める・届ける）を満たし、報告して報酬（経験値・G・アイテム）を受け取る流れで進む。今あるのは住民の日替わりの頼まれごと（持ってくる・届ける）で、報酬は G である（[[economy#6.1 実装（日替わりの頼まれごと）]]）。倒すクエストと、経験値やアイテムをくれるクエストは、まだない。

## 7.5 時刻と昼夜

ゲームの時刻は日本時間の現実の時刻と同じで、全プレイヤーで同じ時刻を見る。

明るさは時刻だけで決まる、なめらかな曲線にする（`world/core/clock.ts`）。夜が長く昼が短いのは [[world#気候と灰]] による。夜でも見えるように、月明かりの青い環境光、家々の窓の暖かい灯り、街灯、焚き火を置く。

住民の一日は [[town#暮らしの時間]]。

灯りは一斉に点かない。窓の灯りは、その家の人が起きている暗い時間だけ点く（`world/town/schedule.ts`）。その結果、夕方に家々が順に灯り、夜通し点き、明け方から昼にかけて順に消える。昼に寝ている家が鎧戸を閉めるのは、まだない（[[backlog]]）。

街灯は、衛兵が夕方に順番に点けて回る（街灯ごとに点く時刻が少しずつずれる）。日が差すと順に消す。

開発用に、URL の `?time=HH:MM` でその時刻に固定できる。

## 8. 戦闘

**アクション操作はない**。生き物をクリックすると、射程まで歩いて自動で攻撃を繰り返す。別の場所をクリックするか Esc を押すと止まる。

判定はサーバーの時刻で進む。攻撃間隔ごとに 1 回振り、命中・被害・会心を決める（式は `world/core/combat.ts`）。

**戦技と魔法**（§9.3）はショートカットバーから使う。手に持った武器（杖）に付いていて、条件を満たしていれば使える。SP を使い、使ったあとは再使用までの待ち時間がある。

生き物の種類と強さは `world/core/monsters.ts`。どれも襲ってこず、自分の用事をしているだけである。叩かれると叩き返すものと、逃げるだけのものがいる。倒した生き物の扱いは柔らかくする（[[world#魔物]]）。スライムは小さく弾けて散り、しばらくするとまた集まる。

生き物の居場所は時刻だけで決まる。ふだんはその場で揺れているだけで、ときどき休み場所のまわりを少し動き、ときどき縄張りの中の別の場所へ移る。一匹ずつ拍子がずれている。サーバーも全員の画面も同じ場所に描くので、位置は送らない。HP と、戻ってくるまでの時間は部屋ごとの `wild` DO が持つ。

攻撃の流れは次の通り。

1. 画面は攻撃間隔ごとに `attack` を送る。
2. 部屋が検証する。間隔を守っているか、スタミナがあるか、届く距離か。戦技なら、その戦技が手の武器に付いていて条件を満たし、SP と待ち時間が足りているか（`player` DO の `art` で SP を払う）。
3. `swing` で当たりを決め、`struck` を全員に流す。
4. 倒したら `loot` を `player` DO に送る。経験値と落とし物が入り、スタミナが減る。

叩き返しは、部屋がプレイヤーの一撃ごとに、生き物の一撃も振って決める。当たれば `hurt` を `player` DO に送り、全員に `hitback` を流す。

新しいプレイヤーは木の棒を持って始まる。素手ではほとんど通らないので、道で拾った枝を持っている、という扱いにする。

獲物は、最初に叩いた人のものになる。その人の最後の一撃からしばらくは、ほかの人が叩いても「ほかの人が戦っている」と断られる。放っておかれると、生き物は息を整えて HP が満ちる。倒した経験値と落とし物は、そのまま倒した人の持ち物に入り、地面には落とさない。持ち物に入りきらない落とし物は残らない。パーティでの分け方は §10。

**倒れたとき**: HP が 0 になると倒れ、動けず何もできない。部屋も移動と攻撃を断る。「町へ戻る」で `revive` を送ると、戻る場所（プレイヤーデータの `savePoint`）で HP 半分で目を覚ます。戻る場所は今は誰でも広場の決まった場所（`world/core/player.ts` の `TOWN_SPAWN`）で、書き換える仕組みはまだない。次の Lv までに要る経験値の一部を失う。ただし旅に慣れない低い Lv のうち（`world/core/combat.ts` の `SAFE_LEVEL` まで）と、Lv の上限では失わない。

戦闘で使える動作（座って休む、応急手当）と戦技は §9 を参照。

## 9. スキル

スキルは三つに分かれる。どれも覚えるための「スキルポイント」はない。

生活スキル（§9.1）は木こり・釣り・採取・料理・調合・木工・鍛冶・仕立ての八つ。その仕事をするたびに経験が入り、Lv が上がる。道具さえあれば Lv 0 からでもできる。

動作（§9.2）は座る・応急手当の二つ。誰でもいつでもできる。

戦技と魔法（§9.3）は武器・杖に付いた技。その武器を手に持ち、能力値と生活スキル Lv の条件を満たせば使える。

### 9.1 生活スキル

生活スキルは一つずつ Lv を持つ。Lv 0（未経験）から始まり、最終の上限は Lv 64。節目は Lv 2・4・8・16・32・64 で、節目を越えるたびに、採れる素材・作れる品・使える戦技が大きく変わる。節目の間の Lv では、品質と失敗の少なさが少しずつ良くなる。**v0.1 は Lv 8 で止める**ので、節目は 2・4・8 の三段になる。上限と節目は `world/core/life.ts`（`LIFE_FINAL`・`LIFE_CAP`・`MILESTONES`）。

**合計の上限**: 生活スキルの Lv の合計には上限がある（`LIFE_TOTAL_CAP`）。v0.1 の値は、八つのうち三つを Lv 8 まで上げきれる量にしてある。上限に届くと、どのスキルも次の Lv に上がらない（経験はその Lv の終わりで止まる）。何でも自分でやるより、専門を決めて残りを買うほうが暮らしやすくするためである（[[economy#0. 原則]]）。最終（Lv 64）での合計の上限（`LIFE_TOTAL_FINAL`）は、二つを 64、一つを 32 まで上げられる量で、[[economy#7.2 最終（Lv 64）での合計の上限（節目の品を入れて、2026-10-21）]] の試算で決めた。上げたスキルを忘れて合計を空ける仕組みは、まだない。

経験は採集と加工でたまり、作りそこねても半分入る。採集の量、加工の品質と失敗、経験の量と次の Lv までに要る経験は `world/core/life.ts` にある。各節目で採れる物・作れる物・使える戦技は `world/core/gather.ts`・`crafting.ts`・`skills.ts` の定義から決まり、スキルの窓にも出る。

### 9.2 動作

**座る**は、いつでも腰を下ろせる動作。座っている間は HP と SP が倍の速さで戻る。歩く・叩く・叩かれると立ち上がる（部屋が立たせる）。

**応急手当**は、SP を使い、持ち物の薬草を一つ使って傷を洗って当てる。薬草をそのまま噛むより多く戻り、調合の Lv と体力で増える。使ったあとは少し待たないと次を使えない。薬草がないときと、HP が満ちているときは使えない。

取引やパーティなど、ほかの操作に条件はない。

### 9.3 戦技と魔法

戦技と魔法は武器（と杖）に付いている。その武器を手に持ち、戦技の条件（能力値と生活スキル Lv）を満たしていれば使える。条件は武器を装備する条件より高いことがある。

打つ戦技と術は、いま戦っている相手に一撃を入れる（ショートカットを押すと、近くの生き物に向かう）。部屋が通常の一撃と同じように検証し、SP と待ち時間は `player` DO が確かめて払う（`art`）。祈りは相手に向けず、自分の HP を戻す。距離の検証は要らないので、応急手当と同じ `cast` コマンドとして `player` DO が確かめて払う。

魔法には二つの系統がある。知力の「術」は杖の先の結晶の力を借りて相手を打ち、外れず、鎧が半分しか効かない。信仰の「祈り」は昔の祈りの言葉で、自分の傷を癒やす（[[world#結晶と魔法]]）。どちらも杖を持って使う。

戦技と魔法の一覧と条件・効き目は `world/core/skills.ts`。

## 10. パーティ

パーティには人数の上限がある。リーダーが誘い、相手が承諾すると加わる。メンバーの HP と居場所（マップ名）が見える。実装は `world/core/party.ts` と `party` DO にある。

誘うときは、ほかのプレイヤーの名札をクリックし、「パーティに誘う」を押す。誘えるのはリーダーだけで、パーティがなければ誘った人がリーダーになる。

抜けるときは自分で抜ける。リーダーが抜けたら、次に入った人がリーダーになる。一人になったらパーティはなくなる。

仲間の様子は、それぞれの部屋がときどき `party` DO に知らせ、ほかの仲間の様子を受け取る。しばらく知らせのない仲間は薄く出る。

経験値の分け方はリーダーが選ぶ。各自なら、倒した人がすべて受け取る。均等なら、同じマップの同じチャンネルにいて倒れていない仲間のうち、倒した人と Lv 差が大きすぎない人（`world/core/party.ts` の `SHARE_LEVELS`）で頭割りする。一人分は切り捨てで、割り切れない余りは倒した人がもらう。そのため合計は元の経験値を超えない。どちらでも、落とし物は倒した人に入る。

プレイヤー ID はサーバーの外に出さない。仲間に見せるのは名前と様子だけである。

## 11. 取引

そばにいるプレイヤー同士で取引を申し込み、承諾されたら開く。両方が品物と G を置き、両方が「決定」を押してから「交換」を押すと成立する。実装は `world/core/trade.ts` と、部屋の `trade-*` にある。

申し込むときは、ほかのプレイヤーの名札をクリックし、「取引を申し込む」を押す。そばにいて、どちらも会話中・取引中・倒れていないことが条件である。開いている間は、どちらも歩けず、戦えず、移れない。どちらかが出す物を変えると、両方の決定が取り消される。

両方のデータは別々の `player` DO にあるので、一つの書き換えにはできない。そこで部屋は次の順で進める。

1. 両方のデータを読み、両方が出せて受け取れるかを確かめる（`checkTrade`。持ち物の空き、重さ、所持金）。
2. A の品を取る（`trade-out`）。
3. B の品を取る。取れなければ、A に返す。
4. B に A の品を渡す（`trade-in`）。
5. A に B の品を渡す。
6. 途中で失敗したら、それぞれに自分の品を返す。取引中はどちらも動けないので、1 で確かめた結果が変わることはまずない。

品は出したときのまま渡る。使い減った道具は減ったまま、作り手の名前もそのまま渡る。大事なものは渡せない。どちらかが部屋を出たら、取引は取りやめになる。

## 12. チャット

チャットの範囲は四つある。**周囲**（ふつうの発言）は、同じマップで近くのプレイヤーに届く。**叫ぶ**は `/s 本文` で、同じマップの全員に届く。**パーティ**（`/p`）と**ささやき**（`/w 名前 本文`）は将来。

プレイヤーの発言はチャットに残り、届いた相手には頭上の吹き出しでも出る。NPC は吹き出しを使わない。

長さと連投には上限がある。

## 13. 永続化

**プレイヤーデータ**は 1 プレイヤー = 1 Durable Object（`durable-objects/player.ts`）に置く。中身は名前、見た目、Lv・経験値・能力値、HP・SP・スタミナ・満腹・温まり、生活スキルの経験、所持金、持ち物、装備（品質・作り手・耐久ごと）、倉庫、ショートカット、住民との親しさと頼まれごと、加工の依頼、パーティ、糸、倒れたときに戻る場所で、形は `world/core/player.ts` の `PlayerState`。位置をまだ記録していないセーブは広場から始まる。コマンドを 1 件ずつ順番に実行するので、同時に買っても所持金が二重に使われない。データの形は版番号付きで、版が変わったら読み込むときに移行する（古いセーブの生活スキルの熟練は、このとき Lv に移す）。

**マップの部屋**（Durable Object）は、そこにいるプレイヤーの位置を接続ごとに持つ。永続化はしないので、全員が抜ければ空になる。

**アカウント**は今はない。ブラウザごとの秘密値を HttpOnly・SameSite の Cookie に保存し、プレイヤーの Durable Object がそのハッシュを照合する。HTTPS では Secure を付ける。接続時に所有者を確定し、メッセージに別のプレイヤー ID を入れても所有者は変わらない。HTTP と WebSocket の入口は同じ Origin からだけ受け付ける。実装は `world/server/session.ts` にある。

以前のブラウザ内 ID は、まだ秘密値が登録されていないプレイヤーだけ一度移行できる。移行前の ID は従来の私有の認証情報として扱う。移行の応答が途切れても再試行できるよう、要求前に作った秘密値を確認成功までブラウザ内に残し、成功したら消す。登録後は ID だけでは復帰できず、Cookie を失ったときに持ち物を初期化して代用しない。別端末への引継ぎと Cookie 消失時の本人確認は、アカウントを導入するまで未対応である。

新しいプレイヤーは、名前・姿・首巻きを決めて保存してから町の操作に参加する。保存前は他のプレイヤーへ姿を表示しない。既存セーブは作成済みとして読み、名前や持ち物を変えない。名前は表示のためのもので、同名を許す。新しい入力は NFC に正規化し、前後の空白を除き、制御文字・不可視の書式文字・孤立したサロゲートを拒む。長さと外見の候補は `world/core/player.ts` とコマンドのスキーマで決める。

プレイヤーの Durable Object は、状態本体と分けて最後の世界・マップ・受理した経路・歩き始めた時刻・有効な接続を保存する。復帰位置は `world/core/location.ts` が経過時間から求める。参加要求の座標は採用せず、別マップへは部屋が許可したワープか復活だけで移る。別世界を訪ねるときはその町の広場から始める。接続を開き直すと新しい接続へ操作権を渡し、古い接続の操作を拒む。退出後の古い接続による後始末は、新しい接続の位置を消さない。

ランキングのように、プレイヤーをまたいで検索する機能を作るときに D1 を足す。

## 14. サーバー権威と検証

操作ごとに、サーバーは次のことを確かめる。移動では、隣のマスずつであること、歩けるマスであること、前の経路から続いていること。NPC との会話・店では、NPC のそばにいること。売り買いでは、品揃え、所持金、持ち物の空き、売れる品か。使う・装備では、持っていることと、使える・装備できること（能力値・生活スキル Lv・部位）。ワープでは、ワープのマスに立っていること。チャットでは、長さ、連投、範囲。戦闘では、射程、攻撃間隔、戦技の条件・SP・待ち時間を確かめ、命中と被害はサーバーで振る。

クライアントから来るメッセージは zod で形を確かめる。範囲外の値（存在しないアイテム、負の個数）はその時点で捨てる。

店やワープのように位置が関わる操作は、マップの部屋が受け取る。部屋が位置を確かめ、プレイヤーの Durable Object に規則の実行を頼み、結果を本人に返す。位置が関わらない操作（持ち物の並べ替えなど）も、同じ経路で送る。
