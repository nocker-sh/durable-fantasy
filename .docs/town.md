# 町の地区と店

前提は [[README#完全な生活]]。都市と人の名前の付け方、気候は [[world]]。

最初の都市ファンティエット（id の頭に `phanthiet`）は、広場を真ん中に、商店通り・職人通り・南門の 4 つのマップに分かれている。どの地区も 1 マップ = 1 Durable Object（[[game-system#1. 世界とマップ]]）。地区どうしのつながりは「世界の升目」で決まる。

## 地区

広場は町の真ん中で、井戸と市場の屋台、鍛冶場、パン屋、宿、礼拝堂、川と洗い場、畑と牧場、風車がある。商店通りは石畳の通りと小さな井戸の広場に、酒場・薬屋・道具屋・仕立て屋・結晶屋・買取所が並ぶ。職人通りは工房の並ぶ通りで、共同の作業場と、裏庭の共同の炉がある。南門には城壁と門、門番の詰所、町の倉庫がある。

## 店

店の店主・品揃え・買取の倍率は `world/core/shops.ts`、アイテムは `world/core/items.ts`。結晶は結晶屋でしか買えない（[[economy#0. 原則]]）。買取所は売り物を持たず、素材を高めに買う。

## 世帯と建物

住民はみな、どこかの世帯に属する。世帯には住まいが一つあり、住人の数だけ寝床がある。年中寒い町なので、人の住む建物にはどれも暖炉があり、煙突から煙が出る。職業に要るもの（パン窯・炉と金床・調合台・機織り機・なめし場など）は、その家の作業場か裏庭にある。

建物の外見（間口・階数）は間取りから作る。階数は部屋のある階の数である。

入れるのは店と公共の建物（宿・酒場・寄り合い所・倉庫・共同の作業場）だけ（`houses.ts` の `enterable`）。民家と仕事場（鍛冶場・窯場・醸造所）には入れない。民家の扉は開かず、夜は窓に灯りがともり、住人は家に入ると姿が見えなくなる。

空き家は、いずれ借りられるように貸家として残しておく。

暮らしの出どころは、食料が町の農家・漁・羊飼い・猟師と市場、燃料が木こりの薪と炭（炭焼き窯は樹海の入り口）、水が各地区の井戸である。

どの家も、間取りの家具を実寸で並べて通路が取れ、住む人数に比べて広すぎないことを確かめる（`world/town/fit.ts`、`fit.test.ts`）。

人の住む家には、仕事にかかわらず暮らしの道具が揃う。人数分の寝台と椅子のほか、食卓、水甕、薪入れ、衣装箱、食べ物の置き場（保存食の棚や籠）を必ず置き、間取りの中に場所を取る（`world/town/house-plan.ts` の `ESSENTIALS`。家の表に書いていなければ足す）。灯りは部屋ごとに吊りランプを描く。入れない民家の中も同じ間取りから作り、/dev/view で見られる（`phanthiet-in-h3`、2 階は `phanthiet-in-h3@1`）。

世帯と建物の一覧は `world/town/houses.ts`、間取りは `world/town/floorplan.ts`。

## 家の見た目

同じ家を並べない。どの家の見た目も、住む世帯の仕事と暮らし向きから決める（`world/town/style.ts`）。乱数の種は、そのなかでの選び方を変えるだけ。

壁の材は仕事で決まるものがある。火の粉を使う仕事、金目の物を置く店と倉庫、酒蔵を冷やす酒場は石積みにし、木を扱う仕事と農家・羊飼いは板張りにする。それ以外は暮らし向きで決め、ゆとりのある家ほど木組みや石積み、慎ましい家ほど漆喰や板張りになる。窓と扉も暮らし向きと建物の用途で変わる。煙突は暖炉と仕事の火の数だけ付き、炉のない納屋や小屋には付かない。

隣り合う家は、屋根の形・壁・屋根の色・窓の組み合わせが必ず違う（`style.test.ts`）。小物も同じ物を並べず、樽・木箱・柵は置き場所ごとに形と傷み方が違う。

二階建ての家の多くは、正面の扉と反対の側の二階に張り出し窓を持つ。張り出し窓は自分の腕木と小さな屋根を持つ。空き家でない家のおよそ半分は、横か裏の壁に下屋を差し掛け、その下に薪か樽を置く。下屋は、空いた地面で、道から離れ、どの扉からも離れた壁にだけ付ける（`world/scene/build.ts`）。張り出し窓と下屋のあるなしと、下屋の下が薪か樽かは、今は家の種で決まる。

## 屋内マップ

全建物の各階を昼夜で撮るスクリプトは `scripts/shoot-building-floors.ts`。開発サーバーを起動して実行すると、民家と仕事場も含めた建物詳細の3D表示を `public/tmp/interiors/` に保存する。`manifest.json` で建物・階・昼夜と画像を対応させる。生成画像は Git に含めない。入場可能な室内を実際のゲーム画面から撮る従来のスクリプトは `scripts/shoot-interiors.ts` に残す。

入れる建物は、それぞれが一つのマップで、サーバーでは一つの部屋 = 1 DO になる。マップ id は `phanthiet-in-<建物 id>`。通りの扉の前の青い輪を踏むと中へ入り、部屋の扉を踏むと外の扉の前（一歩外）へ出る。

部屋の大きさ・扉・カウンター・店主の立ち位置・家具は、建物の定義と間取りから決まる（`world/town/interiors.ts`）。サーバーの歩ける格子と画面の部屋は同じ定義から作るので、ずれない。室内は外と同じ実寸で描き（1 マス = 1.4 m）、中のマス数と外から見た家の大きさが一致する（[[decisions#2026-10-29 室内を実寸にする]]）。間取りは、ゲームの歩くマス（0.7 m）そのものの上で、扉から炉・食卓・階段・二階の寝台まで歩けることを確かめて置く（`world/town/floorplan/geometry.ts` の `walkCells`）。扉から二マス入った所は、入ってきた人が立つので空けておく。

家具は間取りの名前ごとに形を描き分け（`world/scene/construction/furnishings.ts`）、もたれている壁から部屋の内側を向けて置く。木は世帯の暮らし向きで決まり、慎ましい家は松、ふつうの家は樫か白樺、ゆとりのある家と公共の建物は胡桃・黒樫・樫になる。塗りの文化のある家（建物の seed で決まる）は、衣装箱・長椅子・揺りかごを青・赤・緑に塗る。同じ家具の一覧は /dev のオブジェクトで見られる。

室内は家具だけでなく、暮らしの跡で埋める（`world/scene/interior.ts` の `dress`、`world/scene/construction/belongings.ts`）。1 階の各部屋の奥と左右の壁に掛け場所を割り、間取りの壁掛けの品（干し網、吊るした革、斧掛けなど）を先に、残りに部屋の使い道に合った物（台所なら鍋とひしゃく、作業場なら道具、売り場なら値札の板）を掛ける。窓の前と背の高い家具の前には掛けない。台所・貯蔵・作業場・住まいの梁からは薬草や玉ねぎの束を吊るし、食卓の下と炉の前には敷物を敷く。床の暮らしの跡（脱いだ靴、繕いかけの服、遊び道具など）は平らな板ではなく物の形で描く。店の開いた棚は 1.2 マスほどの区画に分け、店の品（パン屋はパン、薬屋と結晶屋は壺、酒場と宿は瓶、道具屋は壺・袋・縄・蝋燭）を、下の段ほど多く、上の段は売れて空いた所を残して並べる。

店主はカウンターの奥に立つ。ただし店先でも売る店は、売り子が外に残る（パン屋の店先の売り台など）。鍛冶場は庭に開いた作業場なので、中には入らない。

画面では、カメラ側の壁を腰の高さまで切り下げて、部屋の中が見えるようにする。カメラを回すと切る壁も替わる。暖炉と吊りランプが灯り、窓は外の明るさで少し光る。

店内での飲食は後回しにする（[[economy#4.5 食事]]）。

テスト（`interiors.test.ts`）では、扉は両側とも歩ける場所にあり着いた場所が扉に重ならないこと、扉から店主に話しかけられる距離まで歩けること、店主が通りに残っていないことを確かめる。

入れる建物の室内の絵は、開発サーバーを動かして `bun scripts/shoot-interiors.ts` で撮る（既定の置き場は ~/Pictures/durable-fantasy-houses/）。

## 軒先と路地

家の周りの物は、手で置かず、世帯の定義から決める（`world/scene/dressing.ts`）。暖炉の薪の山・水桶・植木鉢は暮らし向きと家族から、網干し・薪割り台・革干し・粉袋などは仕事から決まる。灰の始末の道具・蓋をした桶・籠・梯子・荷車のような暮らしの小物は、世帯ごとに持つ物の表がある（`world/scene/things.ts` の `THINGS_BY_HOUSEHOLD`）。灰が降るため、屋外に物干しは置かない。洗濯を仕事にする住民は、洗い終えたものを帰宅して室内に干してから、夕餉や夜市の支度に移る。日課は `world/town/routines.ts`、室内干しの台詞は各世帯の台詞定義にある。洗濯を仕事にする世帯の家は、土間の壁沿いに縄と洗濯物を描く。配置は `world/town/interiors.ts`、描画は `world/scene/construction/indoor-laundry.ts` にあり、通路を塞がず、縄と布を一つの静止した面にまとめる。住む人のいる家は、裏の地面が空いていれば低い柵で裏庭を囲い、一か所を出入りの切れ目にする。裏庭か家の横には、その世帯が自分で食べる野菜の畝を一つ置く。扉が道から離れている家は、扉から一番近い道まで踏み石を敷く。店の家は、扉の上に業種ごとの色の縞の日よけを張り、扉の横に鉄の腕で業種名の看板を道に沿う向きに吊る。売り物を描ける店（酒場・宿・薬屋・パン屋）は、営業中だけ扉の横の長椅子に売り物を並べる。並べるのはその店が売っている物に限る。柵は道・扉の前・住民の立ち位置・ほかの家の扉にかからない深さにし、かかるなら置かない。空き家には「貸家」の札だけを立て、煙突から煙は出ない。どの家も、扉の前と、扉からまっすぐ二タイル分は空けておく。住民の立ち位置にも物を置かない。

テスト（`things.test.ts`）では、どの世帯にも自分の軒先の物があり、どの種類の物も誰かが持っていることを確かめる。

商店通りの北の並びの裏に路地があり、酒場と仕立て屋の干し物、醸造所へ返す空き瓶の箱、雨水の樽がある。

物の一覧は /dev/objects（3D のプレビュー）。

## 町の文字

町の看板・札・立て札に書く字は、日本語ではなく町の言葉にする。町の言葉は、声調記号やほかの記号を外したアルファベットだけのベトナム語で、大文字と数字、空白とダッシュだけで書く（例: 店の札は MO CUA と DONG CUA、貸家の札は CHO THUE、酒場の看板は QUAN RUOU）。人の名前は町の言葉の中でもドイツ語圏風の名前のまま綴る（VUON QUA OTTO）。プレイヤーが読む画面（UI・台詞・説明）は日本語のままにする。

書く言葉は `world/scene/lettering.ts` の表にまとめ、字はそこで一つの書体で描く。あとで町独自のアルファベットのドット絵に差し替えるときは、書体をそこで替えるだけで町じゅうの字が変わる。表にない字や日本語を書こうとすると描く前に止まり、`lettering.test.ts` が表の字と、ほかの場所で直接字を描いていないことを確かめる。

## 道

道はまっすぐに引かない。地形と暮らしに沿って曲げ、幅を揺らし、縁を崩す。道の真ん中には物を置かない（広場の井戸とベンチ、建物の中は除く）。マップの渡り口は描かれた道の上に置く。どの道も地図のほかの部分から歩いて行け、扉・渡り口・採集場所・住民の立ち位置には道から届く（`world/maps/paths.test.ts`）。町の地面には、人の住む家の扉から一番近い道まで、踏まれて土の出た跡を描く（`world/maps/layouts.ts` が家の表から足す。描くだけで、歩ける場所は変えない）。草地は広い範囲で乾いた草と青い草がまだらになり、日陰のくぼみには霜が残る。

## 町の並び

家は外から見た大きさのまま中に入り、中のマス数が外と同じになる（[[town#屋内マップ]]）。家どうしの間は、人ひとりが歩ける路地（1 マス）より狭くしない。壁は道の縁から 0.3 マス、広場の縁から 0.2 マス離し、川・洗濯場・橋・畑・囲い・菜園・墓地にかけない。仕事の庭（鍛冶場の庭、パン屋の庭など）は、その家の壁まで来てよい。扉の前の一歩は、ほかの家や囲いの中に出ない。道の端がその家の扉で終わる小道だけは、壁のそばまで来てよい。ここまでを `world/maps/siting.ts` で確かめ、外に立つ人がどの家の壁の中にもいないことと合わせて `siting.test.ts` で縛る。

広場の地区は、広場を囲んで店と宿が向き、裏の小道（北の家並みの裏、南西の家並みの間）に住まいが並ぶ。商店通りは、北の並びが店、南の並びが酒場と醸造所と寄り合い所で、その裏に路地がある。

家や地形を動かしたら、開発サーバーを動かしたまま `scripts/export-map.ts` で歩けるマスを書き出し直す。書き出しは /dev/view のマップ（`window.view`）から読むので、ゲームを起こさなくてよい。

## 暮らしの時間

住民一人ひとりに一日の予定がある（`world/town/routines.ts`）。予定は「何時から、どこで、何をしているか」の並びで、その時間帯はその場所に立っている。家にいる時間は姿が見えない。予定は世帯と仕事から決まり、乱数を使わないので、同じ時刻なら全員に同じ住民が同じ場所に見える。

町の大半は夜型で、日が落ちるころに起きて夜通し働き、朝に帰って眠る。昼は短く暗い世界なので、灯りの下で暮らすのが普通だからである。昼の通りは夜より人が少なく、昼は町の過半数が眠っている。昼に働く少数派には、それぞれ生業からの理由がある。日の光が要る仕事（畑・家畜・羊・洗濯・木を伐る・猟）、夜明け前の漁、朝の焼き上がり、昼番の衛兵がそれにあたる。

店は、店番がカウンターにいる間だけ開いている。サーバーも、その時刻に店番がいなければ売り買いを断る。それでも、いつ来てもどこかは開いているようにする。交代制の店は時間帯で店番が替わり、店の手伝いは二人目の店番としてカウンターに立つ。店の扉の脇の札は、店番がいる間は「営業中」、いない間は「準備中」になる。屋台は、売り手がいる間だけ品を並べ、いない間は布をかけておくか、屋台ごと片付ける。

酒場の席は、同じ時刻に飲む人の数より多い。

ここに書いた時刻の決まりは `routines.test.ts` で確かめる。一覧は /dev/npcs（一人ずつの一日）。

## 人柄と台詞

頼まれごとの台詞は、その日の引き受け状況と持ち物に合わせて選ぶ。材料が揃った状態と受け渡し完了は区別し、受け渡す前に完了のお礼を言わない。配達は頼んだ人と受け取る人だけが話題にし、期限を過ぎた頼まれごとの台詞は出さない。条件は `world/town/lines/line.ts`、進み具合の判定は `world/core/errands.ts` にある。

住民それぞれの性格（数語）・話し方・口癖と、住民どうしの関係（家族・友人・仕事仲間・師弟・幼なじみ・距離のある関係など）は `world/town/people.ts` にある。悪人はいない。テスト（`people.test.ts`）では、関係が実在する住民どうしで一組につき一度だけ書かれていること、家族は同じ世帯に住み親子と祖父母と孫の年齢が合うこと、何人かの世帯の全員が家族か何かの関係でつながっていること、誰にも誰かがいること、家族と友人と幼なじみが一日のどこかで顔を合わせること（わざと離れている組を除く）を確かめる。

台詞は地区ごとのファイル（`world/town/lines/` の `square.ts`・`market.ts`・`craft.ts`・`gate.ts`）に、住民ごとに書く。一行ごとに、合う時間帯・していること・近くにいる人・親しさ・その日の出来事（`world/town/events.ts`）・初めて話すときか、を条件に持てる。条件を多く満たす行ほど先に言う（`world/town/lines/line.ts`）。テスト（`lines.test.ts`）では、誰にも十分な数の台詞があること、同じ行が二度出ないこと、世界観に合わない言葉を使わないこと、近くにいる人の条件は関係のある相手だけで、していることの条件はその人の一日にあることだけであること、時間帯の条件は起きている時間であること、「おはよう」は起きたばかりの時間帯に言うことを確かめる。

/dev/npcs で一人ずつの人柄・一日・台詞を、/dev/lines で台詞を条件ごとに見られる。

## 都市と旅の道

都市はファンティエット・クイニョン・フエの 3 つ（[[world#場所]]）。クイニョンとフエは、まだ門の前まで。門は閉じていて「この先は工事中」の札が立つ。外のマップの並びは「世界の升目」、どこまで行けるかは [[game-system#1. 世界とマップ]]。町から実装済みの屋外マップと両都市の門前まで往復できることを `world/maps/maps.test.ts` で確認する。

外のマップは、町の暮らしの出どころと、大戦の跡を置く場所である。南の草原にはオットーの果樹園とぶどう畑（ぶどうは醸造所へ）があり、スライムと野うさぎがいる。浜の網小屋はヤコブの海の漁の場所、樹海の入り口はヨーゼフの炭焼き場で町の炭と原木の出どころ、樹海の奥は宿のきのこの出どころ。赤い砂丘・樹海の奥・海沿いの崖道には、半分埋もれた機関、苔むした砦、崩れた見張り塔のような大戦の跡がある。峠道には誰もいない祭壇がある。

木・岩・枯れ草・切り株・きのこはインスタンス描画にして、マップあたり数十の描画呼び出しに収める。どのマップも 60fps を保つ。

## 世界の升目

世界は升目（`world/maps/grid.ts` の `WORLD`、北が上）で、外のマップは一つが一マスで、大きさはどれも同じ。町は 4 マスにまたがる。まだ作っていない都市もマスを持ち、地図には描くが入れない。

隣り合うマップは、向かい合う辺でつながる。西の端から出ると西隣の東の端に出て、端に沿った位置は同じ。つなぎ目（地面の光の輪）は辺ごとに一つで、両方のマップで歩ける所のうち、描いた道（`world/maps/ground-layouts.ts` の `roads`）がその辺に出る所に近い所に自動で決まる（`world/maps/index.ts`）。通れない辺（町の壁、崖、海）はマスの属性 `walls` で表す。したがって手書きのワープは屋内の扉だけになる。

ワールドマップ（ゲームの全体地図）も /dev/maps の升目の図も、この表から描く。

テスト（`maps.test.ts`）では、外のマップがどれも升目に一マスずつあり大きさが同じであることを確かめる。開いた辺ごとにつなぎ目が一つあり、向かいのマップの向かいの辺の同じ位置に出て、帰り道は出た所に戻る。壁の辺は何も通さない。ワールドマップの向きも升目と同じ。どのマップも、出現位置とつなぎ目が歩ける場所にあり、出現位置からすべてのつなぎ目へ歩いて行ける。

## 灰の降る町

降っているのは雪ではなく世界樹の灰で、灰の暮らしは [[world#気候と灰]]。画面では、灰色の細かい粒がゆっくり降り、夜は灯の色を少しだけ帯びて見える（`world/scene/ash.ts`）。

空を向いた面には灰が積もる。平らなところほど厚く、まだらに積もる。物ごとに灰の板を足さず、材質のシェーダーで面の向きから決める（[[decisions#2026-10-25 灰はシェーダーで積もらせる]]）。屋内には積もらない。

地面には薄い灰の膜がどこにでもあり、風の溜まりで厚くなる。道は掃かれていて、道の両脇に掃き寄せた灰の土手ができる（`world/scene/terrain.ts` の `ashen`）。

住民の一日には、屋根の灰下ろし、店や倉庫の前の灰掃き、灰をふるって灰汁を作る仕事が入っている（`routines.ts`）。軒先には灰掃きの箒・灰かきのシャベル・掃き寄せた灰の山・屋根の灰下ろしの熊手・灰ふるいの笊と台・戸口の灰落としの筵・筵をかけた荷・蓋をした水桶と雨水樽を置く（`things.ts`）。
