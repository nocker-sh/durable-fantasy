# 厚い鉄片

砂丘の残骸に由来する鉄片であり、スライムが体内で鉄を作るわけではない。[[monster-iron-sand-slime]] の体表からはがれたものを集める。既存の砂スライムからもまれに得られるので、装備を更新する前から持ち帰れる。

[[resident-アルノルト]] が買い取り、手持ちの鉄の剣を補強し、さらに鍛え直す材料にする。入手量と買取先は `apps/main/world/core/monsters.ts` と `shops.ts`、加工と依頼は `recipes/hunting-recipes.ts` と `hunting-commissions.ts` に定義する。価格と必要数をここへ重ねて持たない。

金属そのものを餌にする生態は作らず、残骸から身体へ付着した鉄を、人が回収して使う経路とする。狩りの成果と職人の仕事の関係は [[economy#狩りの材料から装備を更新する経路]] に従う。
