# 根元の樹脂

樹海の倒木の傷口から出た樹脂が、スライムの身体へ付いたもの。[[monster-resin-slime]] と [[monster-old-moss-slime]] から持ち帰れる。既存の苔スライムからも集められるので、上位の杖を持つことを最初の入手条件にしない。

[[resident-ゴットフリート]] が買い取り、樫の杖の木部を継ぎ直す。樹脂継ぎの杖と根巻きの杖は、既存の杖の結晶をそのまま使う。樹脂から新たな結晶を作らない。[[resident-アルノルト]] も鍛え直した剣の柄巻きに使う。

入手、買取、加工、依頼の数値は `apps/main/world/core/monsters.ts`、`shops.ts`、`recipes/hunting-recipes.ts`、`hunting-commissions.ts` を正とする。加工経路は [[economy#狩りの材料から装備を更新する経路]] に従う。
