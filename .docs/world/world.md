# 世界観

「案」「仮」「未決」と書いたもの以外は決まっている。ほかの文書とコードはこの文書に合わせる。

## あらまし

女神が去ったあとの世界で、人々が普段どおりに暮らしている。争いも悪人もいない。魔王も大きな組織もない。困りごとは寒さ、老い、別れ、世界の不安定さから来る。女神の祝福は少しずつ薄れていて、いずれなくなる。それで世界が壊れるわけではなく、祝福に頼らない人間の時代になるだけである。今日明日の話ではない。

昔、この世界には女神の祝福があった。雨も、気候も、生き物の命も、食べ物の実りも、女神の祝福だった。あるとき女神は出ていった。なぜ女神が人に愛想を尽かしたのかは分かっていない。人々が祝福を奪い合って世界中を巻き込む戦争になり、それを見た女神が出ていった、という話が神話として伝わっているだけである。神話でも、女神は怒って滅ぼしたのではなく、ただ出ていったことになっている。祝福は女神が去ってもすぐには消えず、世界樹に残った分だけが続いている。世界はそれから少しずつ貧しくなっている。戦争は、燃料にしていた結晶（後述）を掘り尽くし、女神もいなくなったことで続けられなくなり、勝者のないまま終わった。

それは 200 年以上前のことで、今は誰も実際のことを知らない。女神も戦争も、おとぎ話や祭りの由来として残っているだけである。人々はその後、火と蒸気で暮らしを立て直した。石畳の町には煙突の蒸気が漂い、機械が少しずつ広まっている。

世界の真ん中には、女神が住んでいた世界樹が立っていて、どのマップからも遠くにその影が見える。世界樹は女神が去ってから枯れつつあり、枯れたところから崩れて灰になって、その灰が世界中に降っている。世界樹はとても大きいので、枯れきるまでには長い時間がかかる。世界樹が完全に枯れると、祝福も魔法もなくなる。

タイトルの Durable には二つの意味がある。一つは、祝福がなくなっていっても人の暮らしは続くということ。もう一つは、サーバーに Cloudflare の Durable Objects を使っていること（[[#世界の作りと Durable Objects]]）。

## いくつもの世界

女神は一つではなく何本もの世界を作り、そのあいだの境目を保っていた。どの世界も地形は同じで、住人と暮らしが少しずつ違う。女神がいなくなって境目を保つ者がいなくなり、今は境目のあちこちに歪みができる。歪みがあるあいだは、そこで別の世界と行き来できる。

住人にとって歪みは生まれたときからあるものなので、知らない顔の人が通りにいても不思議に思わない。

プレイヤーは、どれか一つの世界の住人である。その世界の町がホームタウンで、マイホームもそこに建てる（案）。同じ世界には何人ものプレイヤーが暮らしていて、町で顔を合わせる。別の世界のプレイヤーとは、糸をたどって訪ねたときか、世界樹のふもとでしか会わない。

歪みで偶然に別の世界の人と行き合い、歪みが消えると別れ、また会えるかは分からない、という出会いも置きたい（案）。自分の世界とよく似た別の世界の町で、自分の家に知らない人が住んでいる、同じ顔の住人が自分を知らない、といった場面はここから生まれる。今の作りにはまだない。

## マフラーと糸

誰もが自分の世界の糸で編んだマフラーを首に巻いている。マフラーは、別の世界に出ても持ち主を自分の世界へ引き戻す。持ち物もマフラーと一緒に持ち主の世界へ戻る。だから別の世界へ行っても、帰りの心配がない。マフラーを持たない動物や魔物、巻き忘れた人が別の世界に取り残される話は、昔話や怪談によくある。

マフラーはふつう家族が編んで子に贈り、初めてのマフラーは大人になった印になる。自分で編み直す人もいる。首に巻くものなら形は自由（マフラー、スカーフ、ストール、首飾りの紐）で、見た目の個性が出るところになる。他人のマフラーを取ることは、どこでも許されない。

別れ際にマフラーの端をほどいて糸を交換する習わしがある。交換した糸をたどれば、相手の世界へ自分から渡れる。帰りは自分のマフラーが引き戻す。これがフレンドと、友達の町を訪ねる仕組みの説明になる。糸でつながった人が友達で、それ以外は「すれ違った人」と呼ぶ。マフラーを装備の枠にするかは [[game-system]] 側で決める（未決）。どのキャラクターも首に何か巻いていることは決まっている。

## 世界の作りと Durable Objects

世界の決まりは、サーバーの作りと対応させている。Durable Object は名前ごとに一つだけあり、届いた頼みを一つずつ順に処理する。サーバーの詳しい作りは [[game-system#1.1 並行する町とチャンネル]] と [[game-system#13. 永続化]] にある。

一つの世界は、並行する町の一つにあたる。今は町が 8 つあり、プレイヤーの ID からどの町の住人かが決まる。採集の場所の残り（`nature`）は町ごとに持つので、木や薬草の減り方は世界ごとに違う。住人（NPC）は今はどの町も同じで、世界ごとにどう違えるかは未決。

マフラーは、一人に一つの `player` Durable Object にあたる。名前、持ち物、お金はここにあり、どの町のどのマップにいても本人と一緒に動く。別の世界へ行っても持ち物ごと帰れるのは、持ち物がマップではなく本人の Durable Object にあるからである。手渡した品が相手の世界に残るのは、品が相手の Durable Object に移るからである。

糸は `world/core/threads.ts` にあたる。入れるのは、自分の町と、糸を持っている相手の町の部屋だけである。

世界樹のふもとは、すべての世界とつながっている唯一の場所で、全部の町で一つの取引所（`exchange`）にあたる。店の棚（`market`）も全部の町で一つなので、値段と通貨はどの世界でも同じになる。

同じ町の同じマップに人が多いときは、部屋をチャンネルに分ける（`directory` が決める）。これは世界観では説明しない。

## 暮らしと経済

ゲームは暮らすことだけで、ストーリーはない。主な遊びは経済で、道具を作る、加工を頼む・引き受ける、木を伐る、作物を育てる。戦闘は脇役である。女神の祝福がなくなり、食べ物も道具も人の手で作るしかなくなったので、「作る」「直す」「頼む」が暮らしの中心にある。

手仕事を大事にする。作り手の名前は品物に残る（例: 「ギュンターが打った片手剣」）。

経済はどの世界でも共通で、値段も通貨も同じ。世界樹のふもとがすべての世界とつながっていて、そこの市場で物の値打ちが決まるからである。ふもとの市場には、どの世界からも見える掲示板があり、依頼を置いておけば会ったことのない別の世界の誰かが引き受ける（案）。結晶は通貨ではなく、燃料と素材である。

## 結晶と魔法

結晶は、世界樹の根から地下に染み出した女神の力が、ふもとの地中で固まった石である。世界樹のふもとで掘られる。掘っても少しずつ増えるので、ふつうに使う分にはなくならないが、使いすぎれば減る。大戦はこれを掘り尽くした。結晶ができるのは世界樹に女神の力がまだ残っているからで、世界樹が枯れきれば新しい結晶はできなくなる。住人はその理由を知らない。修道士は結晶を「女神さまの情け」と呼び、いつか女神が戻る証だと信じている。

結晶を砕くと、中の力が一度だけ出てきて魔法になる。火や蒸気よりずっと強い力が出る。昔、人は自分では魔法を使えず、祈って女神に叶えてもらっていた。結晶の力は今もそのころと同じように祈りの言葉に応えるので、呪文は昔の祈りの言葉がもとになっていて、古く正確な言葉ほどよく効く（案）。応えているのは女神ではなく結晶に残った力だが、住人の多くはその違いを知らない。魔法を使うには、結晶と言葉の両方が要る。結晶は結晶掘りが掘り、言葉は修道士が受け継いでいる。杖の先にはめた結晶は砕かずに使うので、出る力は小さいが、唱えるたびに減ることはない（案）。ゲームでは、魔法は SP を使って唱え、結晶は杖の材料になる（[[game-system#9.3 戦技と魔法]]）。呪文をゲームに出すかは未決で、出す場合は短い決まり文句にする。

結晶の力を人に向けてはいけない、という古い決まりがある。理由を正確に知る人はいないが、「女神さまが出ていくから」と言い伝えられて守られている。今は魔物と仕事にしか使わない。

結晶に触れると、女神がいた頃の景色が一瞬見えると言われている（案）。

世界樹は一本だけで、周りに小さな樹は置かない。枯れかけた灰色の巨木で、光らない。世界樹に登れるか、中に何があるかは未決。

## 気候と灰

どこにでも、いつも世界樹の灰が降っていて、空は薄く灰色にかすんでいる。灰が日を遮るので一年中寒い。ただし作物が育つ程度の寒さにとどめる（案）。夏は短く涼しく、冬が長い。住民が扱うリンゴ、スモモ、ぶどう、キャベツ、カブは寒い土地でも育つ。

ゲームの時刻は現実の時刻に合わせる。灰のせいで夜が長く、10 時ごろにようやく日が差し、18 時には真っ暗になる。昼は 8 時間ほどしかないので、灰の薄い日に日が差すと、人々は外に出て日なたに集まる。夜は窓の灯り、街灯、焚き火、結晶の光で過ごす。

灰があるので、屋根の灰下ろし、道掃き、窓拭きが毎日の仕事になり、洗濯物は家の中に干す。灰は畑の肥料や焼き物の釉薬にも使う。降る灰を「女神のいなくなった空のため息」と呼ぶ言い回しがある。

画面では寒さと灰を目立たせる。白い息、舞う灰、焚き火、湯気の立つスープ、機関の蒸気、灰でにじむ窓の灯り。

## 魔物

魔物は、大戦で作られた生き物の兵器の子孫が、200 年のあいだに変わっていったものである。大戦のころの個体はもういない。今はほとんど普通の生き物で、群れで暮らし、縄張りを持ち、人を見ると逃げるものもいる。兵器だったころの性質は少し残っているだけで、本人たちはそれを知らない。大戦のころの兵器は、結晶を大量に砕き、戦いのための祈りを唱えて作られた。魔物が体の中に結晶を持つかは未決。

戦闘はあるが脇役で、狩りや害獣よけとして暮らしの中に置く。畑を荒らすスライムを追い払う、食材や素材を獲る、といったものである。スライムのような、どこか愛嬌のある魔物がいる。魔物も悪者ではないので、倒したときの扱いは柔らかくする（案）。スライムははじけて小さく分かれて逃げていき、獣は気を失って森へ帰る、など。

## 動力と機械

ふだんの動力は火と蒸気で、燃料は薪と炭である。かまど、粉挽き、ポンプ、街灯、渡し舟に使う。結晶は強い力が要るところに使う。戦い、大きな機関、機関船がそうである。

歩き釜（仮）は、人が乗って歩く小さな機関である。ふだんは蒸気で歩き、結晶を燃料にすると戦える。ゲームに入れるかは [[game-system]] 側で決める（未決）。

機械には一台ずつ癖があり、持ち主が名前を付ける。機械は、女神がいなくなってから人が自分たちで作ってきたものとして、明るく描く。工場の煤や搾取は描かない。

## 場所

マップは地域の中の区画ごとに切り替わる。地域は六つある。ファンティエットは最初の町で、畑と市場と鍛冶場があり、プレイヤーのホームタウンになる。フエ（仮）は石畳と煙突の町で、機関の工房が集まる。クイニョン（仮）は機関船の港町で、交易で成り立っている。外の森には魔物が住む。旧神殿（仮）は女神がいた頃の神殿の跡で、ダンジョンになる。世界樹のふもとはすべての世界とつながる場所で、結晶の採掘場と、全部の世界で共通の市場と掲示板がある。

町の外ほど、戦争と女神のいた時代の跡が多く残っている。崩れた砦、錆びた兵器、草に埋もれた戦場、止まった風車、誰もいない祭壇などである。怖い場所としてではなく、人のいなくなった場所として描く。

ベトナムの名前を使うのは都市の名前だけで、都市はファンティエット、クイニョン、フエの三つ。それ以外の場所（森、神殿など）は普通の言葉で呼ぶ。人の名前はドイツ語圏風にする。都市の名前だけ響きが違うのは、女神が世界を作ったときに付けた古い名前が残っているから、とする（案）。

## 人々の集まり

大きな組織はなく、町の小さな集まりだけがある。町の寄り合いは、住民どうしの助け合いの場である。修道士は小さな礼拝堂を守り、女神を祀り、いつか戻ると信じている。病人やけが人を診ることと、世界の記録を残すことも修道士の仕事である。結晶掘りは世界樹のふもとで結晶を掘る職人たちで、組合ではなく顔見知りの仲間うちであり、掘りすぎないよう互いに気をつけている。

種族は人間だけで始める。

## 歴史

年表は次の順になる。

1. 女神の時代。女神が世界樹に住み、人と共にいた。
2. 大戦。結晶を奪い合う戦争で、結晶は掘り尽くされた。
3. 女神が去り、戦争が終わる。女神が去った理由は分かっておらず、大戦が原因だというのは神話である。
4. 記録のほとんど残っていない時代。
5. 人が自分たちで暮らしを立て直し、村ができる。
6. 蒸気機関が広まり、結晶から力を取り出す技術が見つかり、町ができる。ゲームはこの時代から始まる。

## 伝え方とトーン

世界のことは語らない。住人の世間話、アイテムの説明、景色、昔話、祭りの由来、廃墟に残った物から、少しずつ分かるようにする。全部を知る必要はなく、女神も大戦も祝福の行く末も、気づいた人だけが気づけばよい。住人の頼まれごとはあってよいが、一本の筋にはせず、それぞれ小さな日常の話にする。時間制限や取り逃しは置かない。自分の町はいつ戻っても同じように残っている。

全体は落ち着いていて、のんびりしていて、少し可笑しい。暗くしないし、泣かせにいかない。大戦や女神の話は 200 年前の昔話なので、重く扱わない。女神のことを、人々は出ていった家族のように話す。恨み言が半分、懐かしさが半分である。今起きる別れは、人と人との小さなものにとどめる。

夕暮れ、季節、焚き火、雨宿り、機関の音のように、時間が流れているのが分かるものを置き、何もせずに眺めていても見るものがあるようにする。家族、隣人、動物、道具を誰かが大事にしている様子を、町のあちこちに置く。

見た目は、ポリゴンの少ない昔風の 3D に粗いテクスチャを貼り、落ち着いた色にする。

## 未決

上の各節に「未決」と書いたもののほかに、次のことが決まっていない。世界樹が枯れきって祝福と魔法がなくなるときをゲームで描くか、描くならサービスの終わりと重ねるか。祝福が薄れていくことを、ゲームの中でどう見せるか（遠くの世界樹が少しずつ崩れる、など）。言い伝えと本当にあったことのずれを、旧神殿で見つかるものなどで見せるか。女神は戻ってくるのか（今は戻らない前提で書いている）。プレイヤーは何者か（今の考えは、特別な役目のない住人の一人）。歪みは何をきっかけにできるのか（場所、時間帯、結晶の力の濃さなど）。
