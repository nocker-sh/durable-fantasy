# 言葉

仕様書とコードで使う言葉の意味をここで決める。ほかの文書はこの意味で使い、言い換えない。世界観の側の説明は [[world]]、サーバーの側の説明は [[game-system#1.1 並行する町とチャンネル]] にある。

## 世界と場所

世界は、女神が作った何本もの世界の一つである。ゲームでは並行する町の一つにあたり、サーバーではコードの `world` 番号で区別する。町は、ある世界の中にある人の住む都市のことで、今あるのはファンティエットだけである。並行する町と言うときは、別の世界にある同じ町を指す。ホームタウンは、プレイヤーが住人として属する世界の町で、プレイヤーの ID から決まる。

マップは、ロード画面を挟んで切り替わる場所の単位である。町のマップ、外のマップ（野外）、屋内マップ（入れる建物の中）、ダンジョンがある。地区は、町を分けた一つ一つのマップのことで、ファンティエットには広場・商店通り・職人通り・南門の四つがある。外のマップは世界の升目（[[town#世界の升目]]）に一マスずつ並び、隣のマスと辺でつながる。マップの中の位置はマスで数え、1 タイルは 2 マスである。

ワープは、乗ると別のマップへ移る地面の輪である。外のマップどうしの出入口は升目から決まり、屋内の扉は建物の定義から決まる。

世界樹のふもとは、すべての世界とつながっている唯一の場所である。全部の世界で一つの取引所と市場がある。

## サーバー

部屋は、一つのマップの一つのチャンネルを受け持つ Durable Object で、そこにいる人どうしが互いを見て話せる。チャンネルは、同じ世界の同じマップに人が多いときに部屋を分けた番号で、世界観では説明しない。ディレクトリは、町ごとに、どのチャンネルに誰が何人いるかを持つ Durable Object である。プレイヤーの Durable Object は、プレイヤー一人ごとに一つあり、持ち物・お金・能力値などを持つ。

## 人

プレイヤーは、遊んでいる人が動かすキャラクターである。住民は、町に住む NPC のことで、どの住民も世帯に属し、一日の予定（日課）を持つ。世帯は、一つの住まいに暮らす住民のまとまりである。店主は店を受け持つ住民で、売り子は店先や屋台で売る住民である。プレイヤーを「旅人」「旅の人」と呼ばない。ファンティエットはプレイヤーの町でもあるからである。

糸は、マフラーの端をほどいて交換したもので、相手の名前と世界を持つ。糸を持つ相手が友達で、相手の世界の町を訪ねられる。マフラーは世界観での呼び名で、装備の欄としては首巻きと呼ぶ。

## 暮らしと経済

生活スキルは、木こり・釣り・採取・料理・調合・木工・鍛冶・仕立ての八つの暮らしの腕である。節目は、生活スキルの Lv のうち、採れる物・作れる物・使える戦技が大きく変わる Lv のことである。

頼まれごとは、住民が毎日プレイヤーに頼む小さな用事（持ってくる・届ける）である。依頼（加工の依頼）は、プレイヤーが材料と手間賃を住民の職人に渡して品を作ってもらうことである。クエストは、頼まれごとを含む、条件を満たして報酬を受け取る仕組みの総称である。

店の棚は、全部の世界で共通の、NPC の店の在庫である。作り置きは、パンや煮込みのように時刻を決めてまとめて作られ、棚に並ぶ品である。路上販売は、決まった時間帯だけ出る屋台や行商の売り物である。取引所は、プレイヤーどうしが値段を付けて売り買いする仕組みで、町では寄り合い所の掲示板から使う。取引（手渡しの取引）は、そばにいるプレイヤーどうしが品とお金をその場で交換することである。

## 戦いと魔法

戦技は、武器に付いた技である。魔法は杖に付いた技で、知力で使う術と、信仰で使う祈りの二つがある。結晶は、世界樹のふもとで掘れる石で、ゲームでは杖などの材料になる。生き物は、外のマップにいる魔物と動物をまとめた呼び名である。

## 体の具合

スタミナは、採集・生産・戦闘・町の外へ出る道のりで減る体力である。満腹は、食べた量で、時間とともに減る。温まりは、温かい料理や飲み物で体が温まっている状態で、そのあいだは寒さでスタミナが余計に減らない。
